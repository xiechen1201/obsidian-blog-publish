首先要知道什么是域名？为什么需要域名？

域名就像网站的“地址”，方便人们找到目标网站。比如，访问一个网站时，输入 baidu.com 就可以直接找到百度。有了域名，人们更容易记住和访问网站，也便于品牌宣传和推广。另外选择一个好的域名对网站的运营和推广非常重要！

域名的类型有以下几种：

- 根域名：.
- 顶级域名：.cn、.com、.net、.us、.uk、.org ...
- 二级域名：.com、.gov、.org、.edu、自定义、baidu、jd、taobao ...
- 三级域名：自定义、www.baidu.com、www.jd.com、www.taobao.com
- 四级域名：自定义、www.pku.edu.cn、mail.internal.jd.com

一般来说，购买二级域名后，三级、四级域名都是可以免费自定义的。

域名虽然有助于记忆，但是网络传输和域名没有半毛钱的关系，因为网络传输必须依靠的是 IP 地址。

所以就需要有一个过程将域名转换为真实的 IP 地址，转换的这个过程就被称为域名解析。

<br/>tips
Tip

和 IP 地址有一定联系的东西是端口 PORT。

IP 地址就好像某个设备在互联网中的地址，端口就好像这个设备中的某个应用程序。

例如访问 127.0.0.1:8080 就可以看到本地中的 A 项目，访问 127.0.0.1:8888 就可以访问到本地中的 B 项目。

全世界认可的 DNS 服务器一共有三种，外加一个局部使用的本地 DNS 服务器，一共四种，每一个 DNS 服务器内部都有一张类似表格的东西，记录了每个域名对应的 IP 地址。

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/5%20%E6%B5%8F%E8%A7%88%E5%99%A8%E4%B8%8E%E7%BD%91%E7%BB%9C/%E7%BD%91%E7%BB%9C/_assets/1740471793254-51ae24f7-32bc-4a1b-9952-8f5d513c5dd0.png)

例如当访问百度网站的时候，域名解析的过程如下：

- （第一步）首次访问一个域名，会读取本地的 hosts 文件；
- （第二步）如果 hosts 文件没有记录这个域名的 IP，则会读取本地的域名服务器（通常指网络运营商、家庭路由器等）；
- （第三步）如果本地路由器也没有，则会查询根域名服务器；
- （第四步）根域名服务器不会直接返回 www.baidu.com 的 IP 地址，而是会返回一个指向 .com 顶级域名服务器的地址，（第五步）并向 .com 顶级域名服务器进行查询；
- （第六步）.com 顶级域名服务器会返回一个指向 baidu.com 域名的权限 DNS 服务器地址，（第七步）并向权限 DNS 服务器查询；
- （第八步）权限 DNS 服务器返回 www.baidu.com 域名实际的 IP 地址；
- （第九步）本地 DNS 服务器收到权限 DNS 服务器返回的 IP 地址后，会将该信息缓存起来，并返回给客户端；
- 如果经过上面这些步骤依然找不到，那么这个域名就会解析失败；

得到真正的 IP 地址后，后续的步骤就会开始进行 TCP 的连接等，并进行实际的网络请求。
