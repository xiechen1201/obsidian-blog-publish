在现代互联网开发中，最常见的一个场景就是文件的上传和下载，本文将讲述一下 HTTP 协议和文件上传下载的那些联系。

## 上传
文件上传本质上仍然是一个表单的提交，无非就是数据量大一些而已。然后再实践的开发中，我们逐渐形成了一种共识，我们自行约定了文件上传默认使用下面的请求格式：

```http
POST /api/upload HTTP/1.1
...其他请求头
Content-Type: multipart/form-data; boundary=----WebKitFormBoundary7MA4YWxkTrZu0gW

----WebKitFormBoundary7MA4YWxkTrZu0gW
Content-Disposition: form-data; name="avatar"; filename="小仙女.jpg"
Content-Type: image/jpeg

(文件二进制数据)
----WebKitFormBoundary7MA4YWxkTrZu0gW
Content-Disposition: form-data; name="username"

admin
----WebKitFormBoundary7MA4YWxkTrZu0gW
Content-Disposition: form-data; name="password"

123123
----WebKitFormBoundary7MA4YWxkTrZu0gW

```

一般情况下，文件上传使用的都是 POST 请求。另外`multipart/form-data`格式的请求不仅限于文件上传，还可以支持普通的表单字段，只不过相比其他格式更适合上传文件。

另外，我们可以看到在请求头`Content-Type: multipart/form-data;`后面还跟着一串`boundary=----WebKitFormBoundary7MA4YWxkTrZu0gW`的字符串，这是什么？

这其实是浏览器自动分配的一个定界符，，用于分割表单的信息，每个分割区本质上就是一个键值对。

除了键值对之外，`multipart/form-data`允许添加其他的额外信息，例如文件数据区域，一般会把文件在本地的名称和文件 MIME 类型告诉服务器。

下面是使用 HTTP 调试工具发起的请求示例：

在 JavaScript 中，浏览器也有一个 API 可以用于模拟`<form>`表单的提交，详见 MDF：[链接](https://developer.mozilla.org/zh-CN/docs/Web/API/FormData)。

示例代码：

```js
var formdata = new FormData();
formdata.append("file", fileInput.files[0], "template.jpeg");
formdata.append("userId", "123123");
formdata.append("name", "张三");

var requestOptions = {
   method: 'POST',
   headers: ...,
   body: formdata
};

// 当把 formdata 对象传递给 fetch 后，
// 其内部会自动识别 Content-Type 为 multipart/form-data
fetch("http://localhost:3000/upload", requestOptions)
   .then(response => response.text())
   .then(result => console.log(result))
   .catch(error => console.log('error', error));
```

这样就可以完成文件的上传。

## 下载
对于文件下载， Web 端其实不需要做什么太多的处理，只需要服务器在响应头中添加`Content-Disposition: attachment; filename="xxx"`就可以触发浏览器的下载功能。

其中：

- `attachment`表示附件，浏览器看到这个字段的时候会触发下载行为（不同的浏览器可能存在区别）；
    - `inline`是默认值，表示响应的内容作为页面的一部分进行展示（不触发下载）；
- `filename`表示浏览器下载文件后使用的文件名称；
