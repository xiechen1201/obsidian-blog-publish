## 分层的意义
分层的意义在于当遇到一个复杂问题的时候，可以使用分层的思想把问题简单化。

例如，我有一杯 82 年的可乐，我想分享给我的好朋友富贵，但是我们已经有 10 年没有联系了，如果要完成这个事情，我可能需要考虑：

- 使用什么容器装可乐？例如塑料瓶、玻璃瓶还是煤气罐？
- 如何保证可乐一直处于低温？例如使用保温杯、小冰箱还是冰盒子？
- 如何保证可乐运输的过程中不被人偷喝呢？例如贴上封条，上面写上危险液体？
- 如何获取到富贵家的地址呢？是直接去查人查询呢？还是私人侦探呢？
- 如何运输可乐呢？是使用自行车、高铁、还是飞机呢？

这就形成了一个分层结构：

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/5%20%E6%B5%8F%E8%A7%88%E5%99%A8%E4%B8%8E%E7%BD%91%E7%BB%9C/%E7%BD%91%E7%BB%9C/_assets/1740014432083-c3d64b04-84d5-48d1-8a2a-89254406d08c.png)

从常理的角度出发，我们可以得出下面的结论：

- 每层都相互独立，只解决好自己的问题；
- 每层无需考虑上层的交付结果，仅需要把自己的结果交给下层即可；
- 每层有多种方案可供选择，选择不同的方案不会对上下层造成影响；
- 每一层会在上一层的基础上增加一些额外的信息；

## 五层网络模型
![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/5%20%E6%B5%8F%E8%A7%88%E5%99%A8%E4%B8%8E%E7%BD%91%E7%BB%9C/%E7%BD%91%E7%BB%9C/_assets/1740015119831-385a600b-7a1e-4ba1-aac5-27a5b6bd0b9e.png)

上面这张图是互联网中五层网络模型的分层示意图，接下来我们解释每一层负责的事情：

- 应用层
    - 该层是前端开发中最常接触的一层，使用发起一个 HTTP 协议的请求；
    - 主要负责的是和应用程序的交互；
- 传输层
    - 该层是将上一层的数据进行包装，保证两台计算机之间的数据传输的可靠性与顺序；
    - 简单理解 TCP 协议是“一对一”的，必须确保对方收到货，适合文件写作、网页等；
    - 简单理解 UDP 协议是“一对多”的，把“包裹”甩给你就跑了，丢了也不管，适合直播、打游戏等；
- 网络层
    - 该层主要负责将数据包从源设备传输到目的设备，解决的问题是如何找到对方；
- 数据链路层
    - 该层主要负责的是如何在同一个局域网的子网中找到对方，通过 MAC 地址精确发送；
    - MAC 地址和 IP 地址的区别？
        * MAC 地址通常是和物理网卡绑定的，且是全球唯一的，生产网卡的时候就已经固定了，相当于设备的身份证。而 IP 地址是和网络绑定在一块的，是会经常变动的，相当于目前的通讯地址；
- 物理层
    - 该层主要是将二进制数据转换为一种信号；
    - 并不关心数据的具体内容，只负责通过物理设备将信号从一个地方传输到另外一个地方；

例如下面的示例：

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/5%20%E6%B5%8F%E8%A7%88%E5%99%A8%E4%B8%8E%E7%BD%91%E7%BB%9C/%E7%BD%91%E7%BB%9C/_assets/1740017992056-543823b0-e38a-4a16-a1de-55b7a0132b0b.png)

当 A 给 B 发送一句表白信息的时候，数据是不能直接发送过去的，必须经过五层不同的处理。

- 应用层确定使用的是什么协议，添加一个头信息；
- 传输层不管上传使用什么协议，这一层继续添加一个头信息；
- 网络层继续添加头信息，用于添加网络寻找地址；
- 数据链路层，添加头部和尾部，用于在子网中寻找地址；
- 物理层将数据转换为信号；
- 对方也不能直接使用，需要进行解封装;
- ....
- 对方看到表白信息；

## 四层、五层、七层
我们可能还听说过四层和七层网络模型，那么它们之间有什么联系吗？

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/5%20%E6%B5%8F%E8%A7%88%E5%99%A8%E4%B8%8E%E7%BD%91%E7%BB%9C/%E7%BD%91%E7%BB%9C/_assets/1740018530176-c01669b4-9a81-49ab-8705-fab96bca4747.png)

七层网络模型是由国际标准化组织定义的，但是一般只存在于教科书中，现实中基本没有人使用，因为在真实的网络通信中，很多层的功能是结合在一起的，或者有的层并没有被明确区分。而五层网络模型受到七层网络模型的启发，优化了四层网络模型。
