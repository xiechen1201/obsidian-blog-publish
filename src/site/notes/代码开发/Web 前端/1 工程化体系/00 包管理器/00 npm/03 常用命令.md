## 安装
1、精确安装最新版本，也就是不会添加任何的语义化符号，直接安装例如`lodash@1.1.1`的包

```bash
$ npm install --save-exact 包名
# 简写
$ npm i -E 包名
```

2、安装指定版本

```bash
$ npm install 包名@版本号
```

3、安装包到生产依赖

```bash
$ npm install 包名
# 简写
$ npm i 包名

$ npm install --save 包名
# 简写
$ npm i -S 包名
```

4、安装包到开发依赖

```bash
$ npm install --save-dev 包名
# 简写
$ npm i -D 包名
```

## 查询
1、查询包的安装路径

```bash
$ npm root [--global,-g]
```

`--global`、`-g`表示全局。

2、查看包信息、版本、依赖等

```bash
$ npm view 包名 [子信息]

# 例如
$ npm info vue
$ npm info vue version
```

`view`的别名：`v`、`info`、`show`。

3、查询已安装的包

```bash
$ npm list [--global,-g] [[--depth=依赖深度]]
```

`list`的别名：`ls`、`la`、`ll`。

4、查询依赖包的依赖关系

```bash
$ npn ls <packageName>

# 例如
$ npm ls @vue/cli-shared-utils
```

## 更新
1、查询哪些包需要更新

```bash
$ npm outdated
```

2、更新包

```bash
$ npm update [-g] [包名]
# 如果不加包名就是更新全部的包
```

`update`的别名：`up`、`upgrade`。

## 卸载
```bash
$ npm uninstall [-g] 包名
```

`uninstall`的别名：`remove`、`rm`、`r`、`un`、`unlink`。

## 脚本
该命令会直接运行在 package.json 的`script`中配置好的脚本命令：

```bash
$ npm run <脚本名>
```

直接运行 node_modules/.bin 中的可执行文件，或者临时运行 npm 仓库中的某个包，但是不会进行本地的安装：

```bash
$ npx <可执行文件名>
```

## npm 配置
npm 的配置会对其他命令产生或多或少的影响。

安装好 npm 之后，最终会产生两个配置文件，一个是用户配置，一个是系统配置，当两个文件的配置项有冲突的时候，用户配置会覆盖系统配置。

通常，我们不关心具体的配置文件，而只关心最终生效的配置。

1、查询目前生效的各种配置

```bash
$ npm config ls [-l] [--json]
```

2、获取某个配置项

```bash
$ npm config get 配置项
```

3、设置某个配置项

```bash
$ npm config set 配置项=值
```

4、删除某个配置项

```bash
$ npm config delete 配置项
```
