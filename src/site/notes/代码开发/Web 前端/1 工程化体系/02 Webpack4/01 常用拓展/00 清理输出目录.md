Webpack 的生态要么是 Loader 就是 Plugin。

当我们每次使用`npx webpack`打包项目的时候，dist 目录下的旧内容都不会被删除，这就导致了 dist 内有很多垃圾文件！

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/1%20%E5%B7%A5%E7%A8%8B%E5%8C%96%E4%BD%93%E7%B3%BB/02%20Webpack4/01%20%E5%B8%B8%E7%94%A8%E6%8B%93%E5%B1%95/_assets/1695008342595-2d9ea291-79c3-467e-a6e2-121f4817430a.png)

我们可以使用 clean-webpack-plugin 这个插件来帮助我们在每次构建的时候都把 dist 下的目录旧内容清理掉。

1、安装

```bash
$ npm install clean-webpack-plugin --save-dev
```

2、配置使用

```js
// 需要结构处理使用，这个插件有点特殊
const { CleanWebpackPlugin } = require("clean-webpack-plugin");

module.exports = {
    mode: "development",
    devtool: "source-map",
    output: {
        filename: "[name].[chunkhash:5].js"
    },
    plugins: [
      new CleanWebpackPlugin()
    ]
};
```

可以看到两次打包生成的文件不一样（前提是更改了 src/index.js 文件的内容），dist 下也没有旧的 JS 文件。

其实本质上和我之前学习 Plugin 的时候一样，也是绑定一个事件，在事件触发的时候清理 dist 目录！
