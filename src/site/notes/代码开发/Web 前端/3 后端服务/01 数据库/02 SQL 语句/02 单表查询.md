## 🔢 SELECT 语句
SELECT 语句用于在数据库中选取数据。

语法：

```latex
SELECT column1, column2, ... FROM 表名;
```

- column 表示数据表的列名；
- 或者可以使用 * 通配符选取所有的列；

示例：

```plsql
-- 查询员工表，列出姓名和地址
SELECT `name`,location FROM company;

-- 为了更加精确的选取表的字段，可以在字段前面添加表名
SELECT company.`name`,company.location FROM company;
```

通配符查询示例：

```plsql
-- 查询所有公司
SELECT * FROM company;
```

## 🔢 AS 别名
也可以对选项的列进行重命名：

```plsql
-- 查询公司表，列出名称和地址
SELECT `name`,location AS "公司地址" FROM company;
```

## 🔢 CASE 条件
使用 CASE 可以实现类似`if...else...`的效果。

语法：

```latex
CASE
    WHEN 条件1 THEN 结果1
    WHEN 条件2 THEN 结果2
    ...
    ELSE 默认结果
END
```

示例：

```plsql
-- 查询员工表，列出姓名、地址和性别
SELECT
	employee.id,
	employee.`name`,
CASE employee.ismale
	WHEN 1 THEN "男"
	ELSE "女"
END AS "性别"
FROM
	employee;
```

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/3%20%E5%90%8E%E7%AB%AF%E6%9C%8D%E5%8A%A1/01%20%E6%95%B0%E6%8D%AE%E5%BA%93/02%20SQL%20%E8%AF%AD%E5%8F%A5/_assets/1744277479991-c049eebc-940a-42b4-b3a8-2cab018b9698.png)

或者直接基于条件判断：

```plsql
-- 查询员工表，列出姓名、地址和性别
SELECT
	employee.id,
	employee.`name`,
CASE
	WHEN employee.ismale = 1 THEN "男"
	ELSE "女"
END AS "性别"
FROM
	employee;
```

```plsql
-- 查询员工表，列出姓名、地址和性别
SELECT
	id,
	`name`,
CASE
	WHEN salary >= 10000 THEN "高薪"
	WHEN salary >= 5000 THEN "中等"
	ELSE "低"
END AS "salary"
FROM employee;
```

## 🔢 DISTINCT 不相同
在表中，一个列可能会包含多个重复值，有时希望仅仅列出不同的值，就可以使用 DISTINCT。

语法：

```latex
SELECT DISTINCT column1, column2, ... FROM table_name;
```

示例：

```plsql
-- 查询员工表，列出分布的地址
SELECT DISTINCT location FROM employee;
```

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/3%20%E5%90%8E%E7%AB%AF%E6%9C%8D%E5%8A%A1/01%20%E6%95%B0%E6%8D%AE%E5%BA%93/02%20SQL%20%E8%AF%AD%E5%8F%A5/_assets/1744278564310-215a93da-c7eb-4023-9d15-aefb7cdf6a03.png)

如果 DISTINCT 后面跟着多个列名，则所有的列都要相同才会去重：

```plsql
SELECT DISTINCT id,location FROM employee ORDER BY location;
```

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/3%20%E5%90%8E%E7%AB%AF%E6%9C%8D%E5%8A%A1/01%20%E6%95%B0%E6%8D%AE%E5%BA%93/02%20SQL%20%E8%AF%AD%E5%8F%A5/_assets/1744278768355-68ccb725-8604-47aa-a92c-b79de39dcfca.png)

（和实际没去重效果一致）

## 🔢 WHERE 条件
WHERE 用于过滤数据。

语法：

```latex
SELECT column1, column2, ...
FROM table_name
WHERE condition;
```

1、= 等于。

示例，查询部门为 5 的员工：

```plsql
SELECT * FROM employee WHERE employee.deptId=5;
```

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/3%20%E5%90%8E%E7%AB%AF%E6%9C%8D%E5%8A%A1/01%20%E6%95%B0%E6%8D%AE%E5%BA%93/02%20SQL%20%E8%AF%AD%E5%8F%A5/_assets/1744787642862-8715145c-5454-4c3c-bb4a-9909fde40bc3.png)

2、IN 查询在某个范围的数据。

示例，查询公司 ID 为 1 和 2 的部门：

```plsql
SELECT * FROM department WHERE companyId IN (1, 2);
```

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/3%20%E5%90%8E%E7%AB%AF%E6%9C%8D%E5%8A%A1/01%20%E6%95%B0%E6%8D%AE%E5%BA%93/02%20SQL%20%E8%AF%AD%E5%8F%A5/_assets/1744787755867-af84ae64-a8e7-4bb3-bf86-6a84766a5807.png)

3、IS 控制判断。

示例，查询地址为空/不为空的员工：

```plsql
-- 查询地址为空的数据
SELECT * FROM employee WHERE location IS NULL;
-- 查询不为空的数据
SELECT * FROM employee WHERE location IS NOT NULL;
```

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/3%20%E5%90%8E%E7%AB%AF%E6%9C%8D%E5%8A%A1/01%20%E6%95%B0%E6%8D%AE%E5%BA%93/02%20SQL%20%E8%AF%AD%E5%8F%A5/_assets/1744787885261-84d81898-f5b2-45f3-8b64-b7bd034200f1.png)

4、>、<、>=、<= 数据比较。

示例，查询薪资大于 1w 的员工：

```plsql
SELECT * FROM employee WHERE salary >= 10000;
```

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/3%20%E5%90%8E%E7%AB%AF%E6%9C%8D%E5%8A%A1/01%20%E6%95%B0%E6%8D%AE%E5%BA%93/02%20SQL%20%E8%AF%AD%E5%8F%A5/_assets/1744787985919-c442c189-c356-4d55-906e-a5e10763f9e7.png)

5、BRTWEEN 查询xx之间的数据。

示例，查询薪资在 1w 到 2w 之间的员工：

```plsql
SELECT * FROM employee WHERE employee.salary BETWEEN 10000 AND 20000;
```

6、LIKE 模糊查询。

模糊查询中`%`表示多个字符，`_`表示一个字符。例如`%M_`表示查询以 M 在倒数第二位的所有内容。

示例，查询在 2008 年入职的员工：

```plsql
SELECT * FROM employee WHERE joinDate LIKE "%2008%";
```

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/3%20%E5%90%8E%E7%AB%AF%E6%9C%8D%E5%8A%A1/01%20%E6%95%B0%E6%8D%AE%E5%BA%93/02%20SQL%20%E8%AF%AD%E5%8F%A5/_assets/1744788274649-63a735aa-4ddd-4879-a5c6-3ce79863ad6d.png)

示例，查询姓张的员工：

```plsql
SELECT * FROM employee WHERE `name` LIKE "张_";
```

7、AND 多条件并列。

示例，查询姓张的女生并且薪资大于 1w 的员工：

```plsql
SELECT * FROM employee
WHERE `name` LIKE "张%"
AND ismale=0 AND salary>=10000;
```

8、OR 多条件或者。

示例，查询姓张的女生或者出生日期大于 1992 年的员工：

## 🔢 ORDER BY 排序
ORDER BY 关键字用于对结果集进行排序。

语法：

```latex
SELECT column1, column2, ...
FROM table_name
ORDER BY column1, column2, ... ASC|DESC;
```

示例，按照员工的工资高低进行升序：

```plsql
SELECT * FROM employee ORDER BY salary ASC;
```

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/3%20%E5%90%8E%E7%AB%AF%E6%9C%8D%E5%8A%A1/01%20%E6%95%B0%E6%8D%AE%E5%BA%93/02%20SQL%20%E8%AF%AD%E5%8F%A5/_assets/1744788862572-408cc368-497b-4dc2-92bd-f9dc99af7b49.png)

示例，按照员工的工资高低进行降序：

```plsql
SELECT * FROM employee ORDER BY salary DESC;
```

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/3%20%E5%90%8E%E7%AB%AF%E6%9C%8D%E5%8A%A1/01%20%E6%95%B0%E6%8D%AE%E5%BA%93/02%20SQL%20%E8%AF%AD%E5%8F%A5/_assets/1744788908685-f03908f1-6a35-47e0-a1e6-9c120088e9d7.png)

示例，多列排序，先按照性别升序再按照工资降序：

```plsql
SELECT * FROM employee ORDER BY ismale ASC, salary DESC;
```

## 🔢 LIMIT 限制数量
语法：

```latex
SELECT column1, column2, ...
FROM table_name
LIMIT n, m;
```

示例，查询 5 条数据：

```plsql
SELECT * FROM employee LIMIT 5;
```

示例，跳过 3 条数据，查询 5 条数据：

```plsql
SELECT * FROM employee LIMIT 3,5;
```

## 🔢 运行顺序
以上几个 SQL 语句的执行顺序如下：

1. `FROM` - 先确定数据来源；
2. `WHERE` - 然后筛选数据；
3. `CASE` - 条件判断（如果有）；
4. `SELECT` - 选择要显示的列；
5. `DISTINCT` - 去重处理；
6. `ORDER BY` - 最后排序；
7. `LIMIT` - 限制返回条数；

想象一个场景："从(`FROM`)哪里找，筛选(`WHERE`)条件，判断(`CASE`)处理，去重(`DISTINCT`)后，选择(`SELECT`)展示，排序(`ORDER` BY)好，最后限制(`LIMIT`)数量"。
