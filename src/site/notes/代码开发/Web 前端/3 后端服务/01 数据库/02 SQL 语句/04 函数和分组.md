SQL 拥有很多可用于计数和计算的内建函数。

## 数学
1、`ABS(x)`返回 x 的绝对值。

示例：

```plsql
SELECT ABS(-5);
-- 5
```

2、`CEILING(x)`返回大于等于 x 的最小整数值。
示例：

```plsql
SELECT CEILING(3.2);
-- 4
```

3、`FLOOR(x)`返回小于等于 x 的最大整数值。
示例：

```plsql
SELECT FLOOR(3.8);
-- 3
```

4、`MOD(x,y)`返回 x 除以 y 的余数。
示例：

```plsql
SELECT MOD(10, 3);
-- 1
```

5、`PI()`返回圆周率 π 的值。
示例：

```plsql
SELECT PI();
-- 3.1415926535898
```

6、`RAND()`返回 0 到 1 之间的随机数。
示例：

```plsql
SELECT RAND();
-- 0.4123456789 (结果随机)
```

7、`ROUND(x,y)`返回将 x 四舍五入到y位小数的值。
示例：

```plsql
SELECT ROUND(2.58, 1);
-- 2.6
```

8、`TRUNCATE(x,y)`返回将 x 截断到 y 位小数的值。
示例：

```plsql
SELECT TRUNCATE(2.718, 2);
-- 2.71
```

## 聚合函数
1、`AVG(col)`返回指定列的平均值。

示例，求员工工资的平均值：

```plsql
SELECT AVG(salary) FROM employee;
```

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/3%20%E5%90%8E%E7%AB%AF%E6%9C%8D%E5%8A%A1/01%20%E6%95%B0%E6%8D%AE%E5%BA%93/02%20SQL%20%E8%AF%AD%E5%8F%A5/_assets/1744794756669-855d1765-5afa-4c2e-ba99-74ac4a7d1a6d.png)

<br/>warning
⚠️ 注意

使用聚合函数的情况下，不能使用非聚会字段，除非对非聚合字段进行分组。

例如：`SELECT employee.`name`,AVG(salary) FROM employee;`

这将得到一个错误：

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/3%20%E5%90%8E%E7%AB%AF%E6%9C%8D%E5%8A%A1/01%20%E6%95%B0%E6%8D%AE%E5%BA%93/02%20SQL%20%E8%AF%AD%E5%8F%A5/_assets/1744794871764-0eed9cdf-fba6-41ed-8a9b-0e4d1cbc1899.png)

这是因为，这个 SQL 要做两件事：1、计算平均工资 2、从某一行取出`name`字段。

但是，SQL 有点懵了，因为：

- 你要所有行的`salary`聚合成一个平均值；
- 但你又没说`name`要从哪一行取，选哪个呢？（前一行？后一行？中间某一行？）；

如果进行分组则没有这个问题，例如：`SELECT name, AVG(salary) FROM employee GROUP BY name;`。

这句 SQL 的意思是先按照`name`进行分组，然后再计算每个组的平均工资。

<br/>

2、`COUNT(col)`返回指定列中非 NULL 值的个数。

示例：

```plsql
-- 排除非空的id，然后进行汇总数量
SELECT COUNT(id) FROM employee;

-- 只要任意一行有数据，那么就进行汇总
SELECT COUNT(*) FROM employee;
```

3、计算最小值、最大值和总和。

- `MIN(col)`返回指定列的最小值；
- `MAX(col)`返回指定列的最大值；
- `SUM(col)`返回指定列的所有值之和；

示例，求员工的最低工资、最高工资和总和工资：

```plsql
SELECT
	COUNT(id) as "员工数量",
	AVG(salary) as "平均薪资",
	MIN(salary) as "最低薪资",
	MAX(salary) as "最高薪资",
	SUM(salary) as "总支出薪资"
FROM
	employee;
```

## 字符
1、`CONCAT(s1, s2..., sn)`将 s1, s2..., sn 连接成字符串。
示例：

```plsql
SELECT CONCAT('Hello', 'World');
-- HelloWorld
```

2、`CONCAT_WS(sep, s1, s2..., sn)`将 s1, s2..., sn 连接成字符串，并用 sep 字符间隔。
示例：

```plsql
SELECT CONCAT_WS(', ', 'Apple', 'Banana', 'Cherry');
-- Apple, Banana, Cherry
```

3、`TRIM(str)`去除字符串首部和尾部的所有空格。
示例：

```plsql
SELECT TRIM('   Hello World   ');
-- Hello World
```

4、`LTRIM(str)`从字符串 str 中切掉开头的空格。
示例：

```plsql
SELECT LTRIM('   Hello World');
-- Hello World
```

5、`RTRIM(str)`返回字符串 str 尾部的空格。
示例：

```plsql
SELECT RTRIM('Hello World   ');
-- Hello World
```

## 日期
1、`CURDATE()`或`CURRENT_DATE()`，返回当前系统日期（不包含时间部分）。
示例：

```plsql
SELECT CURDATE();
-- 输出示例：'2023-11-15'（取决于当前日期）

SELECT CURRENT_DATE();
-- 输出示例：'2023-11-15'
```

2、`CURTIME()`或`CURRENT_TIME()`，返回当前系统时间（不包含日期部分）
示例：

```sql
SELECT CURTIME();
-- 输出示例：'14:30:45'（取决于当前时间）

SELECT CURRENT_TIME();
-- 输出示例：'14:30:45'
```

3、`NOW()`或`CURRENT_TIMESTAMP()`，返回当前系统的日期和时间。
示例：

```sql
SELECT NOW();
-- 输出示例：'2023-11-15 14:30:45'

SELECT CURRENT_TIMESTAMP();
-- 输出示例：'2023-11-15 14:30:45'
```

4、`DATE()`，提取日期时间表达式的日期部分。
示例：

```sql
SELECT DATE('2023-11-15 14:30:45');
-- 输出：'2023-11-15'
```

5、`TIME()`，提取日期时间表达式的时间部分。
示例：

```sql
SELECT TIME('2023-11-15 14:30:45');
-- 输出：'14:30:45'
```

6、`DATEDIFF(date1, date2)`，计算两个日期之间的天数差（date1 - date2）。
示例：

```sql
SELECT DATEDIFF('2023-11-20', '2023-11-15');
-- 输出：5
```

7、`DATE_ADD(date, INTERVAL expr unit)`，向日期添加指定的时间间隔。
示例：

```sql
SELECT DATE_ADD('2023-11-15', INTERVAL 7 DAY);
-- 输出：'2023-11-22'
```

8、`DATE_FORMAT(date, format)`，按指定格式显示日期/时间。
示例：

```sql
SELECT DATE_FORMAT(NOW(), '%Y年%m月%d日 %H时%i分%s秒');
-- 输出示例：'2023年11月15日 14时30分45秒'
```

9、`DAYNAME(date)`，返回日期的星期名称。
示例：

```sql
SELECT DAYNAME('2023-11-15');
-- 输出：'Wednesday'（根据系统语言设置可能不同）
```

10、`DAYOFWEEK(date)`，返回日期的星期索引（1=周日，2=周一，...7=周六）。
示例：

```sql
SELECT DAYOFWEEK('2023-11-15');
-- 输出：4（表示周三）
```

11、`TIMESTAMPDIFF(part, date1, date2)`，返回 date1 到 date2 之间相隔的 part 值，part 是用于指定的相隔的年或月或日等。

part 可选：

- MICROSECOND
- SECOND
- MINUTE
- HOUR
- DAY
- WEEK
- MONTH
- QUARTER
- YEAR

示例：

```plsql
SELECT TIMESTAMPDIFF(HOUR, "2010-1-1 11:11:11", "2010-1-2 11:11:11");
```

## 分组
分组可以结合聚合函数来使用，相当于先根据某个字段进行分组，然后再进行聚合计算。

语法：

```latex
SELECT column_name, aggregate_function(column_name)
FROM table_name
GROUP BY column_name;
```

示例，查询员工分布的居住地：

```plsql
SELECT
	location,COUNT(id)
FROM
	employee
GROUP BY
	location;
```

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/3%20%E5%90%8E%E7%AB%AF%E6%9C%8D%E5%8A%A1/01%20%E6%95%B0%E6%8D%AE%E5%BA%93/02%20SQL%20%E8%AF%AD%E5%8F%A5/_assets/1744796474095-6563c909-a5d4-477a-a0fd-12d9e84678fd.png)

（先按照 location 字段进行分组，然后再根据 ID 计算每个分组的总数）

示例，按照地区、性别进行分组：

```plsql
SELECT
	location,ismale,COUNT(id)
FROM
	employee
GROUP BY
	location,ismale;
```

## > HAVING
`HAVING`是对分组后的结果进行过滤的语句，和`WHERE`类似，但它用在`GROUP BY`之后。

示例，查询每个部门的平均工资：

```plsql
SELECT employee.deptId, AVG(employee.salary)
FROM employee
GROUP BY employee.deptId;
```

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/3%20%E5%90%8E%E7%AB%AF%E6%9C%8D%E5%8A%A1/01%20%E6%95%B0%E6%8D%AE%E5%BA%93/02%20SQL%20%E8%AF%AD%E5%8F%A5/_assets/1744853069911-68212307-effc-4bcb-a439-77635e848517.png)

得到这个结果后，我又想对分组后的结果进行筛选，例如只显示平均工资大于 1.2w 的部门：

```plsql
SELECT employee.deptId, AVG(employee.salary) AS avg_salary
FROM employee
GROUP BY employee.deptId
HAVING avg_salary > 12000;
```

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/3%20%E5%90%8E%E7%AB%AF%E6%9C%8D%E5%8A%A1/01%20%E6%95%B0%E6%8D%AE%E5%BA%93/02%20SQL%20%E8%AF%AD%E5%8F%A5/_assets/1744853185725-449c7c1a-a2d2-4a51-87df-3e65c1968f84.png)

只要理清楚`WHERE`和`HAVING`的区别即可：

- `WHERE`是对原始数据进行过滤的；
- `HAVING`是对分组后的数据进行过滤的；

在实际的操作中，也可以将`WHERE`和`HAVING`搭配使用，例如查询某门下男员工平均工资大于 1.2w 的部门：

```plsql
SELECT employee.deptId, AVG(employee.salary) AS avg_salary
FROM employee
WHERE employee.ismale = 1
GROUP BY employee.deptId
HAVING avg_salary > 12000;
```

## 运行顺序
到现在我们又学习了`GROUP BY`和`HAVING`，我们再对 SQL 查询的运行顺序进行一个汇总：

- 先从哪里查（`FROM`）；
- 再筛原始数据（`WHERE`）；
- 然后分组（`GROUP BY`）；
- 分组后再筛（`HAVING`）；
- 条件判断（如果有）（`CASE`）；
- 选字段（`SELECT`）；
- 去重（`DISTINCT`）；
- 排序（`ORDER BY`）；
- 最后限制几条（`LIMIT`）；
