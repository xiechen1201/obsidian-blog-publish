## 全连接（笛卡尔积）
如果直接使用 SELECT 查询两张表，得到的结果是两张表数据相乘。

```plsql
SELECT * FROM `user`,company;
```

可以看到，结果是 user 表中的每一条数据对应 company 表中的每一条数据。

## 左连接
左连接是以左表为基准，右边的表和左面的表进行匹配，每次连接的时候判断条件是否满足。

语法：

```latex
SELECT *
FROM table1
LEFT JOIN table2
ON table1.column_name=table2.column_name;
```

示例，查询 department 表 ID 等于 employee 表 deptId 的数据：

```plsql
-- 部门表的第一行拿出来依次去判断员工表的每一行，看哪一行能满足条件
SELECT
	*
FROM
	department AS d
LEFT JOIN employee AS e
ON d.id = e.deptId;
```

## 右连接
右链接和左连接正好相反，是以右表为基准。

示例：

```plsql
SELECT
	*
FROM
	employee AS e
	RIGHT JOIN department AS d ON d.id = e.deptId;
```

## 内连接
内连接也是最常用的一种联表查询的方式，用于从多个表中根据它们之间的关系提取匹配的记录。

语法：

```latex
SELECT *
FROM table1
INNER JOIN table2
ON table1.column_name=table2.column_name;
```

示例，联表查询：

```plsql
SELECT
	*
FROM
	employee AS e
	INNER JOIN department AS d ON d.id = e.deptId;
```

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/3%20%E5%90%8E%E7%AB%AF%E6%9C%8D%E5%8A%A1/01%20%E6%95%B0%E6%8D%AE%E5%BA%93/02%20SQL%20%E8%AF%AD%E5%8F%A5/_assets/1744792514715-d8a43e0a-53f1-46b5-8617-e5135cc5b5f6.png)

示例，联表查询并保留部分列：

```plsql
SELECT
	e.`name`,
	joinDate,
	salary,
	d.`name` AS deptName
FROM
	employee AS e
	INNER JOIN department AS d ON d.id = e.deptId;
```

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/3%20%E5%90%8E%E7%AB%AF%E6%9C%8D%E5%8A%A1/01%20%E6%95%B0%E6%8D%AE%E5%BA%93/02%20SQL%20%E8%AF%AD%E5%8F%A5/_assets/1744792629004-c660238a-5680-47a2-8ac1-7935100f5936.png)

这样就得到了两个表的数据。
