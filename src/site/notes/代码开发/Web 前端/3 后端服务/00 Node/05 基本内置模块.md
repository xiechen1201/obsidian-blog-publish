## os 模块
用于读取操作系统的一些信息。

```js
const os = require('os');

console.log(os);
```

1、`os.EOL`获取操作系统一行字符结束的分隔符：

```js
console.log(os.EOL);
// Windows 使用回车和换行字符序列（\r\n）
// Unix 和 Unix-like 系统（包括 Linux 和 macOS） 使用换行字符（\n）
```

2、`os.arch()`获取操作系统的架构名:

```js
console.log(os.arch()); // arm64
```

4、`os.freemem()`获取系统当前还有多少空闲的内存，单位为字节：

```js
console.log(os.freemem()); // 100827136
```

5、`os.homedir()`获取当前用户的主目录:

```js
console.log(os.homedir()); // /Users/xiechen
```

6、`os.hostname()`获取操作系统的主机名:

```js
console.log(os.hostname()); // xiechendeMacBook-Pro.local
```

7、`os.tmpdir()`获取操作系统的临时目录：

```js
console.log(os.tmpdir()); // /var/folders/p1/c_n7361j0b33y7g2z_01cqkr0000gn/T
```

## path 模块
用于处理文件和目录路径。

```js
const path = require('path');

console.log(path);
```

1、`path.basename(path[, ext])`获取`path`的最后一部分名字：

```js
console.log(path.basename('a/b/c/d/test.html')); // test.html

console.log(path.basename('a/b/c/d/test')); // test

// 如果后缀名匹配上，则结果删除后缀名，否则保留
console.log(path.basename('a/b/c/d/test.html', '.html'));
// test
console.log(path.basename('a/b/c/d/test.html', '.js'));
// test.html
```

2、`path.sep`获取操作系统的「路径段分隔符」：

```js
console.log(path.sep); // \
// 例如 /Users/xiechen/Documents/code-personal/s-duyi/nodejs/05/code

// 在 window 系统返回 \
// 例如 C:\Users\Username\Documents\MyFile.txt
```

3、`path.delimiter`返回操作系统「路径分隔符」：

```js
console.log(path.delimiter); // :
// 例如 mac：'/usr/bin:/bin:/usr/sbin:/sbin:/usr/local/bin'
// 例如 window: 'C:\Windows\system32;C:\Windows;C:\Program Files\node\'
```

4、`path.dirname(path)`获取`path`目录名：

```js
console.log(path.dirname('a/b/c/d/test.js')); // a/b/c/d
```

5、`path.extname(path)`获取`path`的拓展名：

```js
console.log(path.extname('a/b/c/d/test.js')); // .js
```

6、`path.join([...paths])`将多段路径拼接为一个完整的路径：

```js
console.log(path.join('a', 'b', 'c')); // a/b/c
```

7、`path.normalize(path)`对`path`进行规范化处理，解决`..`和`.`段的问题：

```js
console.log(path.normalize('/foo/bar//baz/asdf/quux/..'));
// '/foo/bar/baz/asdf'
```

8、`path.relative(from, to)`根据当前工作目录返回从`from`到`to`的相对路径：

```js
console.log(path.relative('/data/orandea/test/aaa', '/data/orandea/impl/bbb'));
// ../../impl/bbb
```

9、`path.resolve([...paths])`将路径段转化为绝对路径：

```js
console.log(path.resolve('a/b/c/test.js'));
// /Users/xiechen/Documents/code-personal/s-duyi/a/b/c/test.js
```

>
> `path.resolve()`的路径是相对于「命令行」的路径。

## util 模块
该模块提供了一些工具方法供开发者使用。

```js
const util = require('util');
console.log(util);
```

1、`util.callbackify(original)`用于将一个 Promise 异步函数转化为 callback 的形式：

```js
async function delay(duration) {
    return new Promise((resolve, reject) => {
        setTimeout(() => {
            resolve(duration);
        }, duration);
    });
}
delay(3000).then((res) => {
    console.log(res);
});

const delayCallback = util.callbackify(delay);
delayCallback(3000, (err, res) => {
    console.log(res);
});
```

2、`util.promisify(original)`用于将一个回调函数转化为异步函数：

```js
function delayCallback(duration, callback) {
    setTimeout(() => {
        // null 表示没有错误
        callback(null, duration);
    }, duration);
}

let delay = util.promisify(delayCallback);
delay(3000).then((res) => console.log(res));
```

3、`util.inherits(constructor, superConstructor)`用于实现继承，目前已经不推荐使用了，而是使用 ES6 的 class 的 extends!!!

4、`util.isDeepStrictEqual(val1, val2)`用于严格比较两组数据：

```js
const obj1 = {
    a: 1,
    b: 2,
    c: {
        d: 3,
        e: {
            f: 4
        }
    }
};

const obj2 = {
    a: 1,
    b: 2,
    c: {
        d: 3,
        e: {
            f: "4"
        }
    }
};

console.log(util.isDeepStrictEqual(obj1, obj2));
// false
// 因为 obj2 中的 f 属性数据类型是 String
```
