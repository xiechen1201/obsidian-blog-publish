
那么为什么`global`对象上还有个`global`属性呢？

其实就像给`global`自身保留了一个位置，相当于`global.global = global`。

和`window`对象一样，`global`上的属性可以直接调用。

```js
global.setTimeout(() => {
    console.log('setTimeout1');
}, 3000);
// 等价于
setTimeout(() => {
    console.log('setTimeout2');
}, 3000);
```

## setTimeout()
该方法用于创建一个延时器，在一定时间执行函数内指定的内容。

和`window`对象不同，在 Node 中该函数返回的是一个对象：

```js
let res = setTimeout(() => {
    console.log('setTimeout2');
}, 3000);
console.log(res);

/*
  Timeout {
    _idleTimeout: 3000,
    _idlePrev: [TimersList],
    _idleNext: [TimersList],
    _idleStart: 52,

```

## setTimeout()
该方法用于创建一个定时器，在一定时间循环执行函数内指定的内容。

该函数同样返回一个对象：

```js

    console.log('setTimeout2');
}, 3000);
console.log(res);
```

## setImmediate()
该方法会在当前事件循环结束后执行函数内的指定内容。同样返回一个对象：

```js
let res = setImmediate(() => {

}, 3000);
console.log(res);

/*

    _idleNext: null,
```


## process
表示「进程」对象，因为 Node 运行的时候相当于一个应用程序，程序在操作系统内占用一个进程。

```js
console.log(process);

/*
  process {
    version: 'v22.1.0',
    versions: {
      ...
    },
    arch: 'arm64',
    platform: 'darwin',
    release: {
      name: 'node',
      sourceUrl: 'https://nodejs.org/download/release/v22.1.0/node-v22.1.0.tar.gz',
      headersUrl: 'https://nodejs.org/download/release/v22.1.0/node-v22.1.0-headers.tar.gz'
    },
    ...
*/
```

- `process.cwd()`用于获取当前 NodeJS 进程的工作目录，返回绝对路径：

```js
console.log(process.cwd());
```

- `process.exit()`用于强制退出当前的 Node 进程：

```js
setTimeout(() => {
    console.log('setTimeout');
}, 3000)

process.exit();
```

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/3%20%E5%90%8E%E7%AB%AF%E6%9C%8D%E5%8A%A1/00%20Node/_assets/1716333014719-c6402497-7ea0-4810-b2e2-5b2224327800.png)

控制台什么都不会输出，因为还没等延时器内部执行 Node 程序已经被退出了。

在调用`proess.exit()`的时候可以传递「退出码」，0 表示成功退出，默认为 0。

- `process.argv`属性用于获取运行命令中所有的参数：

```js
console.log(process.argv);
```

- `process.platform`属性用于获取当前设备的操作系统：

```js
console.log(process.platform);
```

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/3%20%E5%90%8E%E7%AB%AF%E6%9C%8D%E5%8A%A1/00%20Node/_assets/1716333290284-10ce001d-ee4d-4eab-a8e2-d6f6bf1e6dec.png)

- `process.kill()`方法用于杀死程序进程，类似于在任务管理器中退出进程：

```js
process.kill(73504)
// 73504 为程序的 pid
```

- `process.env`属性用于获取环境变量对象：

```js
console.log(process.env);
console.log(process.env.PATH);
```

## __dirname
<br/>warning
⚠️ 注意

该属性并不属于`global`对象下的属性，而是一个在 module 内存在的特殊变量。

<br/>

该属性返回当前模块所在的「目录绝对路径」：

```js
console.log(__dirname);
```
