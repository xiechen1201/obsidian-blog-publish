I/O 也就是 input 和 output，对外部设备的输入输出。

外部设备包括：磁盘、网卡、显卡、打印机...

I/O 的读写速度往往低于内存和 CPU 的交互速度。

## fs 模块
fs 模块是 Node 内置的文件系统模块，提供了一系列 API 用于操作文件。

```js
const fs = require("fs");
```

🔔 提示

fs 模块所有的 API 操作都具有 Promise、同步、回调的方式！

<br/>

```js
const filename = path.resolve(__dirname, './demo.txt');

// Promise
fs.promises.readFile(filename, 'utf-8').then(res=>{
    console.log(res);
})

// 同步
let res = fs.readFileSync(filename, 'utf-8');
console.log(res);

// 回调
fs.readFile(filename, (error, data) => {
    console.log(data);
});
```

为什么使用回调的方式呢？

因为读取文件需要一定的时间，如果是同步的写法代码就会阻塞，及其影响性能。

<br/>

1、`fs.readFile(path[, options], callback)`用于读取一个文件：

```js
// 拿到一个绝对路径
const filename = path.resolve(__dirname, './demo.txt');

fs.readFile(filename, 'utf-8', (error, data) => {
    console.log(data);
});

/*
  hello world
  skjajsa
*/
```

如果不指定编码，则返回 Buffer 对象：

```js
fs.readFile(filename, (error, data) => {
    console.log(data);
})
// <Buffer 68 65 6c 6c 6f 20 77 6f 72 6c 64 0a 73 6b 6a 61 6a 73 61>
```

2、`fs.writeFile(file, data[, options], callback)`用于写入一个文件：

```js
fs.writeFile(filename, 'hello world', { flag: 'a' }, (error) => {
    console.log('写入成功！');
})
// flag: "a" 表示在文件内追加内容，而不是覆盖！
```

```js
// 手动复制的案例
const filename = path.resolve(__dirname, './iShot_2024-05-17_11.20.33.png');
const toFilename = path.resolve(__dirname, './copy.png');

fs.readFile(filename, (error, data) => {
    fs.writeFile(toFilename, data, (error) => {
        console.log('写入成功！');
    })
});
```

3、`fs.stat(path[, options], callback)`用于获取文件或者目录的信息：

```js
fs.stat(filename, (error, stats) => {
    console.log(stats);
});

/*
  Stats {
    dev: 16777229,
    mode: 33188,
    nlink: 1,
    uid: 501,
    gid: 20,
    rdev: 0,
    blksize: 4096,
    ino: 136226602,
    size: 19,
    blocks: 8,
    atimeMs: 1716244621558.5933,
    mtimeMs: 1716244619937.2134,
    ctimeMs: 1716244619937.2134,
    birthtimeMs: 1716243458939.263
  }
*/
```

- `size`表示文件或者目录占用的字节数，当读取的是目录时`size`为 0，因为目录在操作系统中是一个特殊的文件，该文件有一个指针记录了其他文件的地址；
- `atime`表示上次访问的时间；
- `mtime`表示上次修改的时间；
- `ctime`表示上次修改文件状态的时间；
- `birthtime`表示文件创建的时间；
- `isDirectory()`用于判断是否是目录；
- `isFile()`用于判断是否是文件；

<br/>

4、`fs.readdir(path[, options], callback)`用于读取目录中的文件和子目录：

```js
fs.readdir(path.resolve(__dirname, './'), (error, files) => {
    console.log(files);
})

/*
  [
    'copy.png',
    'demo.txt',
    'iShot_2024-05-17_11.20.33.png',
    'index.js',
    'node_modules',
    'package-lock.json',
    'package.json',
    'practice',
    'testMkDir'
  ]
*/
```

5、`fs.mkdir(path[, options], callback)`用于创建一个目录：

```js
fs.mkdir(path.resolve(__dirname, './testMkDir'), (error) => {
    console.log('创建成功！');
});
```

6、`fs.exists(path, callback)`用于判断文件或者目录是否存在。该方法已过时，要使用`fs.stat()`和`fs.access()`代替！
