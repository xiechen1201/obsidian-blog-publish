## 🔢 属性顺序
CSS 的书写顺序虽然不会影响样式的实际表现，但按照一定的顺序书写有助于代码的可读性和维护性。

一个常见的 CSS 书写顺序遵循从外观到布局的逻辑，大致可以分为以下几个部分：

- 显示属性：`display`,`position`,`float`,`clear`；
- 自身属性：`width`,`height`,`margin`,`padding`,`border`,`background`；
- 文本属性：`color`,`font-text-align`,`vertical-align`,`whitespace`；
- 其他；

CSS 命名规范：

1、选择器复合单词用中划线`box-wrapper`；

2、JS构造`ID`复合单词用下划线`J_name` ；

3、选择器都用小写，尽可能的使用缩写，不用看不懂的缩写
