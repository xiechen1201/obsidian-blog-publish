浮动属性的产生目的是为了实现文字环绕的效果，让文字环绕图片（类似报纸的排版）。

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1742276187178-9186c01a-4add-435c-b06a-28044251907e.png)

到了后面，浮动慢慢的变成了一种页面布局的方式。 浮动可以理解为让某个元素脱离标准流，漂浮在标准流之上，和标准流不是一个层次。

语法：

```latex
float: value;
```

- value：
    - `none`无浮动；
    - `left`左浮动；
    - `right`右浮动；

例如实现一个两栏布局：

```css
body {
  width: 90%;
  max-width: 900px;
  margin: 0 auto;
}

div:nth-of-type(1) {
  width: 48%;
  float: left;
}

div:nth-of-type(2) {
  width: 48%;
  float: right;
}

```

## 🔢 特性
使用浮动属性后会产生一些特性：

1、脱离标准文档流（这一点上面也说过了）。

例如我们有这样的两个元素：

```html
<div class="one"></div>
<div class="two"></div>
```

```css
.one {
    width: 80px;
    height: 80px;
    background-color: red;
}

.two {
    width: 150px;
    height: 150px;
    background-color: blue;
}
```

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1742276554775-4a8b37c1-a2d5-4ea7-9235-027226648214.png)

正常情况下，都是至上而下排列的，可一旦设置了浮动属性后，元素就会脱离标准文档流，元素原先的位置也会被其他元素占有。

```diff
.one {
    width: 80px;
    height: 80px;
    background-color: red;
+    float: left;
}

.two {
    width: 150px;
    height: 150px;
    background-color: blue;
}
```

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1742276690944-d994f589-7969-40f8-a7c3-537218e3a3ee.png)

可以看到，蓝色的元素占有了红色元素的区域。

2、浮动元素相互贴靠。

因为块元素在页面中独占一行，自上而下排列，设置浮动后可以让块元素横着排列。如果父元素的宽度不足以横向排列所有的浮动元素，浮动元素会自动进行换行。

```diff
.box {
  width: 400px;
  height: 400px;
  border: 1px solid #000;
  box-sizing: border-box;
}

.item {
  width: 100px;
  height: 100px;
  border: 1px solid #000;
  box-sizing: border-box;
+  float: left;
}
```

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1665238122408-90209748-d930-4896-b4d1-58f18fe968be.png)

3、设置浮动属性后元素的宽度会进行收缩，行为类似于内联块（但并不是）。

例如：

```html
<p>
    Global Privacy Control (GPC) is on the way to becoming a formal
    privacy standard with the recent publication of its first working
    draft. Let's take a look at what the implications are for developers
    and users.
</p>
```

```css
p{
    background-color: antiquewhite;
}
```

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1742277145078-f43f375c-b112-4c6f-a8a7-f2bacabd3724.png)

`<p>`元素的默认行为是占满一整行，如果设置了浮动属性后，宽度会进行收缩。

```diff
p {
    background-color: antiquewhite;
+    float: left;
}
```

## 🔢 清除浮动
当给一个元素设置浮动属性后，这个属性给带来副作用，因此我们需要清除浮动的副作用。

如果父元素没有设置高度，而内部的子元素全部进行浮动就会造成父元素高度塌陷：

```css
.wrapper {
  width: 300px;
  background-color: green;
}

.item {
  width: 100px;
  height: 100px;
  background-color: orange;
  border: 1px solid #000;
  float: left;
}
```

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1665239752598-2dd578d8-9f27-42b2-afbb-f754ddaeef68.png)

清除浮动的办法通常有：

1、给父元素设置一个高度。

这也是最直接的方式。

```diff
.wrapper {
      width: 300px;
+      height: 100px;
      background-color: green;
  }
```

2、设置`clear`属性。

`clear`属性是专门用于清除浮动的一个属性，定义元素的哪边不允许出现浮动元素，该属性需要作用于块元素上：

语法：

```latex
clear: value;
```

value：

- `left`在左侧不允许浮动元素；
- `right`在右侧不允许浮动元素；
- `both`在左右侧都不允许浮动元素；
- `none`默认值，允许浮动元素出现在两侧；

示例：

```diff
<div class="wrapper">
    <div class="item">1</div>
    <div class="item">2</div>
+    <div class="clear"></div>
</div>
```

```css
.clear {
    clear: both;
}
```

基于此，也可以使用`::after`伪元素：

```diff
.wrapper {
    width: 300px;
    background-color: green;
}

+	.wrapper::after {
+    content: "";
+    display: block;
+    clear: both;
+	}

.item {
    width: 100px;
    height: 100px;
    background-color: orange;
    float: left;
}
```

```html
<div class="wrapper">
    <div class="item">1</div>
    <div class="item">2</div>
</div>
```

3、父元素设置`overflow: hidden;`属性，触发 BFC。

```diff
.wrapper {
  width: 300px;
  background-color: green;
+  overflow: hidden; /* 实现清除浮动 */
}
.item {
  width: 100px;
  height: 100px;
  background-color: orange;
  border: 1px solid #000;
  float: left;
}
```
