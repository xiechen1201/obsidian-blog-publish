什么是 2D 和 3D 的场景呢？

2D 场景：在屏幕上水平和垂直的交叉线 X 轴和 Y 轴；

3D 场景：在垂直于屏幕的方法，相对于 3D 多出个 Z 轴；

Z 轴：靠近屏幕的方向是正向，远离屏幕的方向是反向；

## 🔢 perspective 景深
什么是景深？

其实对于`perspective`景深属性，我们可以简单的理解为视距，用来设置用户和元素 3D 空间 Z 平面之间的距离。

而其效应由属性的值来决定：值越小，用户与 3D 空间 Z 平面距离越近，视觉效果更令人印象深刻。反之，值越大，用户与 3D 空间 Z 平面距离越远，视觉效果就很小。

语法：

```latex
perspective: value;
```

属性值：

- value：`none`/具体数值单位，通常的数值在 900-1200 之间；

<br/>warning
⚠️ 注意

1、`perspective`取值为`none`或不设置，就没有真 3D 空间。
2、`perspective`取值越小，3D 效果就越明显，也就是你的眼睛越靠近真 3D。
3、`perspective`的值无穷大，或值为 0 时与取值为`none`效果一样。

<br/>

示例：

```html
<div>
  <img src="./imgs/cardKingClub.png" alt="" width="142" height="200" />
  <img src="./imgs/cardKingClub.png" alt="" width="142" height="200" />
</div>
<div>
  <img src="./imgs/cardKingClub.png" alt="" width="142" height="200" />
  <img src="./imgs/cardKingClub.png" alt="" width="142" height="200" />
</div>
```

```css
div {
  width: 500px;
  height: 300px;
  margin: 30px auto;
  position: relative;
  background: url(images/bg-grid.jpg) no-repeat center center;
  background-size: 100% 100%;
}

div img {
  position: absolute;
  top: 50%;
  left: 50%;
  margin-left: -71px;
  margin-top: -100px;
  transform-origin: bottom;
}

div img:nth-child(1){
  opacity: .5;
  z-index: 1;
}

div img:nth-child(2){
  z-index: 2;
  transform: rotateX(45deg);
}

/* 第二个盒子设置 perspective 属性 */
div:nth-of-type(2){
  perspective: 500px;
}
```

Tip

除了`perspective`属性可以激活一个 3D 空间之外，在 3D 变形的函数中的`perspective()`也可以激活 3D 空间。

他们不同的地方是：`perspective`用在舞台元素上（变形元素们的共同父元素），`perspective()`就是用在当前变形元素上，并且可以与其他的`transform`函数一起使用。

<br/>

示例：

```html
<div class="wrapper">
  <img src="./imgs/01.png" alt="" />
  <img src="./imgs/01.png" alt="" />
  <img src="./imgs/01.png" alt="" />
</div>
```

```css
/* .wrapper {
  perspective: 1000px;
} */

img {
  display: block;
  width: 400px;
  height: auto;
  transform: perspective(1000px) rotateX(-100deg);
}
```

<br/>warning
⚠️ 注意

1、`perspective()`必须设置在`transform`的第一个位置，因为是在变化元素之前，否则不会生效。

2、每个元素设置该值都相当于一双眼睛，三个物体就是三双眼睛看三个物体。

## 🔢 perspective-origin 景深原点
`perspective-origin`属性主要用来决定`perspective`观察 3D 元素的（位置）角度。

语法：

```latex
perspective-origin: X Y;
```

属性值：

- X 轴：`left`|`right`|`center`（默认值） | 具体单位数值；
- Y 轴：`top`|`bottom`|`center`（默认值） | 具体单位数值；

<br/>warning
⚠️ 注意

`perspective-origin`属性需要与`perspective`属性结合起来使用，以便将视点移至元素的中心以外位置，为了指转换子元素变形的深度，`perspective-origin`属性必须定义父元素上。

<br/>

示例：

```css
.wrapper {
  perspective: 1000px;
  perspective-origin: center top;
}

img {
  display: block;
  width: 400px;
  height: auto;
  transform: perspective(1000px) rotateX(-100deg);
}
```

## 🔢 backface-visibility 背面可见
该属性用于设置元素反转后背面是否可见。

语法：

```latex
backface-visibility: value;
```

属性值：

- `value`可选：
    - `visible`可见；
    - `hidden`不可见；

示例：

```html
<div class="box">
  <img src="./imgs/01.png" alt="" />
</div>
<div class="box hidden">
  <img src="./imgs/01.png" alt="" />
</div>
```

```css
@keyframes identifier {
  from {
    transform: rotateX(0deg);
  }
  to {
    transform: rotateX(360deg);
  }
}

.box {
  perspective-origin: right top;
  perspective: 1000px;
}

img {
  border: 3px solid red;
  width: 300px;
  height: auto;
  animation: identifier 2s linear infinite;
}

.hidden img {
  /*  设置反转后背面不可见  */
  backface-visibility: hidden;
}
```

## 🔢 transform-style 动画呈现
该属性用于设置子元素是否为 3D 立体效果进行显示，如果不进行设置就是扁平化显示，叠在再一起。

语法：

```latex
transform-style: value;
```

属性值：

- `value`可选：
    - `flat`默认值，表示所有子元素在 2D 平面呈现；
    - `preserve-3d`表示所有子元素在 3D 空间中呈现；

也就是说，如果对一个元素设置了`transform-style`的值为`flat`，则该元素的所有子元素都将被平展到该元素的 2D 平面中进行呈现。

沿着 X 轴或 Y 轴方向旋转该元素将导致位于正或负 Z 轴位置的子元素显示在该元素的平面上，而不是它的前面或者后面。

如果对一个元素设置了`transform-style`的值为`preserve-3d`，它表示不执行平展操作，他的所有子元素位于 3D 空间中。

示例：

```html
<div class="box1">
  <div></div>
  <div></div>
</div>
<div class="box2">
  <div></div>
  <div></div>
</div>
```

```css
.box1 {
  display: inline-block;
  width: 50%;
  height: 600px;
  border: 1px solid brown;
  transition: all 1s;
  perspective: 1200px;
  transform-style: preserve-3d;
}

.box1 div:nth-child(1) {
  position: absolute;
  top: 8%;
  left: 10%;
  width: 500px;
  height: 500px;
  background-color: violet;
}

.box1 div:nth-child(2) {
  position: absolute;
  top: 8%;
  left: 10%;
  width: 500px;
  height: 500px;
  background-color: tomato;
  transform: rotateX(55deg);
}

/* 切面交叉后没有直接隐藏覆盖面 */

.box2 {
  position: absolute;
  left: 50%;
  display: inline-block;
  width: 50%;
  height: 600px;
  border: 1px solid brown;
  transition: all 1s;
  perspective: 1200px;
}

.box2 div:nth-child(1) {
  position: absolute;
  top: 8%;
  left: 10%;
  width: 500px;
  height: 500px;
  background-color: violet;
}

.box2 div:nth-child(2) {
  position: absolute;
  top: 8%;
  left: 10%;
  width: 500px;
  height: 500px;
  background-color: tomato;
}
```

## 🔢 3D 位移
方法：

- `translateZ(z)`让元素在 3D 空间沿 Z 轴进行位移；
- `translate3d(x, y, z)`让元素在 3D 空间沿 X、Y 和 Z 轴进行位移

示例：

```css
.content-box:hover {
  transform: translate3d(100px, 100px, 100px);
}
```

## 🔢 3D 旋转
方法：

- `rotateZ()`让元素在 3D 空间沿 Z 轴进行旋转；
- `rotate3d(x, y, z, a)`：
    - `x`是一个 0 到１之间的数值，主要用来描述元素围绕 X 轴旋转的矢量值；
    - `y`是一个０到１之间的数值，主要用来描述元素围绕 Y 轴旋转的矢量值；
    - `z`是一个０到１之间的数值，主要用来描述元素围绕 Z 轴旋转的矢量值；
    - `a`是一个角度值，主要用来指定元素在 3D 空间旋转的角度，如果其值为正值，元素顺时针旋转，反之元素逆时针旋转；
    - ![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1584968952267-7efe8721-9f38-4ee2-a626-0b5619706a78.png)

示例：

```css
.content-box:hover {
  transform: rotate3d(0, 0, 0.6, 45deg)
}
```

## 🔢 3D 缩放
方法：

- `scaleZ()`让元素在 Z 轴上按比例缩放。
    - 默认值为１，当值大于１时，元素放大。反之小于１大于 0.01 时，元素缩小；
- `scale3d(x, y, z)`
    - `x`横向缩放比例；
    - `y`纵向缩放比例；
    - `z``Z`轴缩放比例；

<br/>warning
⚠️ 注意

`scaleZ()`和`scale3d()`函数单独使用时没有任何效果，需要配合其他的变形函数一起使用才会有效果。

<br/>

示例：

```css
.content-box3:hover {
  transform: scale3d(0, 0, 2)
}
```
