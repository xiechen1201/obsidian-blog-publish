## 列数量
设置元素应该被分隔的列数，适用于除`table`外的非替换块级元素, `table cells,` `inline-block`元素。

语法：

```latex
column-count: number；
```

示例：

```css
.box {
  width: 600px;
  height: 400px;
  border: 1px solid #000;
  columns-count: 4;
}
```

## 列宽度
设置或检索对象每列的宽度，语法：

```latex
column-width: value;
```

示例：

```css
.box {
  width: 600px;
  height: 400px;
  border: 1px solid #000;
  column-width: 100px;
}
```

## columns
是上面两个属性的复合属性。

示例：

```css
.box {
  width: 600px;
  height: 400px;
  border: 1px solid #000;
  columns: 3 100px; /* 参数2可选 */
}
```

## 列间隔
设置列之间的间隔大小，默认为`16px`，语法：

```latex
column-gap: value;
```

示例：

```css
.box {
  width: 600px;
  height: 400px;
  border: 1px solid #000;
  columns: 4;
  column-gap: 30px;
}
```

## 列边框
设置列与列之间的边框，语法：

```latex
/* 单独设置 */
column-rule-width: value;   /* 分隔线的宽度，如 1px */
column-rule-style: value;   /* 分隔线的样式，如 solid、dashed */
column-rule-color: value;   /* 分隔线的颜色，如 #ccc */

/* 复合属性 */
column-rule: width style color;
```

示例：

```css
.box {
  width: 600px;
  height: 400px;
  border: 1px solid #000;
  columns: 3;
  column-gap: 10px;
  column-rule: 1px solid red;
}
```

## 列填充
设置或检索对象所有列的高度是否统一，语法：

```latex
column-fill: value;
```

属性值：

- value
    - `auto`列高度自适应内容；
    - `balance`所有列的高度以其中最高的一列统一；

示例：

```css
.box {
  width: 600px;
  height: 400px;
  border: 1px solid #000;
  columns: 3;
  column-gap: 10px;
  column-rule: 1px solid red;
  column-fill: auto;
}
```

## 跨列
设置或检索对象元素是否横跨所有列（给子元素设置），语法：

```latex
column-span: value;
```

属性值：

- value
    - `none`不跨列；
    - `all`横跨所有列；
    - 或者具体的列数

示例：

```css
.box {
  width: 600px;
  height: 400px;
  border: 1px solid #000;
  columns: 3;
  column-gap: 10px;
  column-rule: 1px solid red;
  column-fill: auto;
}
p {
  column-span: all;
}
```
