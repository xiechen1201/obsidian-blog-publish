在日常开发设置时，常见的固定宽度为 1190px ，那么如何做到在不同宽度的页面做出不同的展示就是本章的内容。

我们常见的页面布局方案有以下几种：

1. 固定布局：以像素作为页面的基本单位，不管设备屏幕及浏览器宽度，只设计一套尺寸；
2. 可切换的固定布局：同样以像素作为页面单位，参考主流设备尺寸，设计几套不同宽度的布局。通过识别的屏幕尺寸或浏览器宽度，选择最合适的那套宽度布局；
3. 响应布局：对页面进行响应式的设计实现，需要对相同内容进行不同宽度的布局设计；
    1. 有两种方式：PC 优先（从 PC 端开始向下设计）；
    2. 移动优先（从移动端向上设计）；
    3. 无论基于那种模式的设计，要兼容所有设备，布局响应时不可避免地需要对模块布局做一些变化（发生布局改变的临界点称之为断点）；
4. 弹性布局：以百分比作为页面的基本单位，可以适应一定范围内所有尺寸的设备屏幕及浏览器宽度，并能完美利用有效空间展现最佳效果；
5. 混合布局：同弹性布局类似，可以适应一定范围内所有尺寸的设备屏幕及浏览器宽度，并能完美利用有效空间展现最佳效果；只是混合像素、和百分比两种单位作为页面单位；

什么是响应式设计？

Responsive Web Design 网格布局`Flex` + 弹性图片 + 媒体查询。

响应式布局是为了让网页实现自动缩放的效果，根据当前视口大小决定怎么样的排列方式。

<br/>

特点：

- 面对不同分辨率设备灵活性强；
- 能够快捷解决多设备显示适应问题；

缺点：

- 兼容各种设备工作量大，效率低下；
- 代码累赘，会出现隐藏无用的元素，加载时间加长；
- 其实这是一种折中性质的设计解决方案，多方面因素影响而达不到最佳效果；
- 一定程度上改变了网站原有的布局结构，会出现用户混淆的情况；

## 🔢 媒体查询
CSS3 新增的媒体查询可以让我们根据设备显示器的特性（如视口宽度、屏幕比例、设备方向（横向或纵向））为其设定 CSS 样式，媒体查询由媒体类型和一个或多个检测媒体特性的条件表达式组成。

媒体查询中可用于检测的媒体特性有`width`、`height`和`color`等。使用媒体查询，可以在不改变页面内容的情况下，为特定的一些输出设备定制显示效果。

<br/>

使用`@media`查询，你可以针对不同的媒体类型定义不同的样式，语法：

```css
@media not|only mediatype and (mediafeature) and|or|not (mediafeature) {
  /* 编写样式 */
}
```

- `not`: `not`运算符用于否定媒体查询，如果不满足这个条件则返回`true`，否则返回`false`；
    - 如果出现在以逗号分隔的查询列表中，它将仅否定应用了该查询的特定查询；
    -  如果使用`not`运算符，则还必须指定媒体类型；
- `only`: `only`运算符仅在整个查询匹配时才用于应用样式，并且对于防止较早版本的浏览器应用所选样式很有用；
    - 当不使用`only`时，旧版本的浏览器会将`screen and (max-width: 500px) `简单地解释为`screen`，忽略查询的其余部分，并将其样式应用于所有屏幕；
    - 如果使用`only`运算符，则还必须指定媒体类型；
- `,`(逗号)：逗号用于将多个媒体查询合并为一个规则。逗号分隔列表中的每个查询都与其他查询分开处理，其行为类似于逻辑或`||`运算符；
- `and`: `and`操作符用于将多个媒体查询规则组合成单条媒体查询，其行为类似于逻辑且`&&`运算符；

`mediatype`媒体类型的常用值：

- `all`：用于所有设备，不写的时候就是默认值；
- `screen`：电脑、平板电脑、智能手机屏幕等；

`mediafeature`媒体特性常用值：

- `height`设备可见的高度；
- `width`设备可见的宽度；
- `max-height`设备可见的最大高度（再大时样式不生效）；
- `max-width`设备可见的最大宽度；
- `min-height`设备可见的最小高度（再小时样式不生效）；
- `min-width`设备可见的最小宽度；
- `orientation`设备的方向（竖屏`portrait`，横屏`landscape`）；
- `prefers-color-scheme`设备的显示模式（明亮`light` 黑暗`dark`）；

所谓媒体特性，就是指在确定了设备的情况下，具体再根据细分条件进行分类。

<br/>

示例1：

```css
/* 打印样式 */
@media print {}

/* 手机等小屏幕手持设备 */
@media screen and (min-width: 320px) and (max-width: 480px) {}

/* 平板之类的宽度 1024 以下设备 */
@media only screen and (min-width: 321px) and (max-width: 1024px) {}

/* PC客户端或大屏幕设备: 1028px 至更大 */
@media only screen and (min-width: 1029px) {}

/* 竖屏 */
@media screen and (orientation: portrait) {}

/* 横屏 */
@media screen and (orientation: landscape){}
```

示例2：

```css
/* 960 - 768 的宽度 */
@media screen and (max-width: 960px) and (min-width: 768px) {
  body {
    background-color: red;
  }
}

/* 768 - 500 的宽度 */
@media screen and (max-width: 768px) and (min-width: 500px) {
  body {
    background-color: yellow;
  }
}

/* 500 以下的宽度 */
@media screen and (max-width: 500px) {
  body {
    background-color: darkcyan;
  }
}
```

## 🔢 外部 CSS
如果页面加载的时候外部的 CSS 文件，那么媒体查询也可以生效：

1、使用`<link>`标签。

这和`@media`规则是一样的，只是在`<link>`上新增了一个`media`属性，示例：

```html
<link rel="stylesheet" type="text/css" media="screen and (max-width: 960px) and (min-width: 768px)" href="./css/media1.css" />
```

2、使用`@import`规则，示例：

```css
@media screen and (max-width: 768px) and (min-width: 500px) {
  @import './css/media1.css';
  body {
    background-color: yellow;
  }
}

@media screen and (max-width: 500px) {
  @import url(./css/media2.css);
  body {
    background-color: darkcyan;
  }
}
```
