## 🔢 颜色值
在 CSS2 的时候用过的颜色值有 HEX（如`#FFFFFF`）和`rgb()`（如`rgb(10, 10, 100)`）。

CSS3 新增了两个颜色值：

1、`rgba()`

RGBA 即红色、绿色、蓝色、透明度（英语：Red, Green, Blue,  Alpha）。

- 红色（R）0 到 255 间的整数，代表颜色中的红色成分；
- 绿色（G）0 到 255 间的整数，代表颜色中的绿色成分；
- 蓝色（B）0 到 255 间的整数，代表颜色中的蓝色成分；
- 透明度（A）取值 0~1 之间， 代表透明度，1 表示完全不透明，0 表示完全透明；

示例：

```css
p{
  color: rgba(10, 10, 100, 0.5);
  font-size: 18px;
}
```

2、`hsl()`

`HSL`即色相、饱和度、亮度（英语：Hue, Saturation, Lightness）。

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1666962991491-8951b438-aac5-44de-81fb-19196b64bd3f.jpeg)

- 色相（H）是色彩的基本属性，定义色相（0为赤色、60为橙色、120为绿色、180为青色、240为蓝色、300为紫色）；
- 饱和度（S）是指色彩的纯度，越高色彩越纯，低则逐渐变灰，取 0-100% 的数值；
- 亮度（L），取 0-100%，增加亮度，颜色会向白色变化；减少亮度，颜色会向黑色变化；

示例：

```css
p{
  color: hsl(40, 100%, 50%);
  font-size: 18px;
}
```

## 🔢 透明度
语法：

```latex
opacity: value;
```

属性值：

- value：0（包括）到 1（包括） 之间的数字，1 表示完全不透明，0 表示完全透明；

💡 提示

`opacity` 和`rgba()` 的区别：

`opacity`会把自己包括内部子级都会生效透明，`rgba()`只会作用自己而不会影响子级。

<br/>

💡 提示

在 CSS 中隐藏元素的方式有三种，分别是`display: none;`、`visibility: hidden;`和`opacity: 0;`。

它们具有以下区别：

- 表现行为
    - `display: none;`从文档流中移除，不占据任何空间，触发浏览器的重绘和重排；
    - `visibility: hidden;`和`opacity: 0;`虽然都是元素不可见，但是它们仍然占据空间，只会触发浏览器的重绘；
- 事件响应
    - `display: none;`和`visibility: hidden;`隐藏后不会再响应 JS 的事件处理；
    - `opacity: 0;`仍然响应事件处理；

<br/>

示例：

```css
.box{
  opacity: 0.5;
}
```
