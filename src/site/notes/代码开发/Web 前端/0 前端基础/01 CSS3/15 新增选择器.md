## 属性选择器
之前我们讲过的属性选择器，CSS3 对属性选择器进行了拓展。

1、`el[type^="text"]{ ... }`寻找`type`属性以`te`字符串「开头」的元素。

示例：

```html
<input type="text" />
```

```css
input[type^="te"]{ ... }
```

2、`el[type$="text"]{ ... }`寻找`type`属性以`xt`字符串「结尾」的元素。

示例：

```html
<input type="text" />
```

```css
input[type$="xt"]{ ... }
```

3、`el[type*="text"]{ ... }`寻找`type`属性「包含」`ex`字符串的元素。

示例：

```html
<input type="text" />
```

```css
input[type*="ex"]{ ... }
```

4、`el[lang~="us"]{ ... }`寻找`lang`属性以「空格分割」的`us`字符串的元素。

示例：

```css
/* <input lang="en us" /> */
input[type～="us"]{ ... }
```

## 结构伪类选择器
1、`:root`寻找根元素，相当于`<html>`根标签，优先级比`html{ ... }`高。

示例：

```css
:root{
  padding: 0;
  margin: 0;
}
```

2、`el:empty`寻找没有任何子元素（包含文本、空格、换行）的元素。

示例：

```html
<ul>
	<li><!-- 第 1 个 li 元素 --></li>
	<li>第 2 个 li 元素</li>
	<li>
		<!-- 第 3 个 li 元素 -->
	</li>
</ul>
```

```css
li:empty {
  background-color: orange;
}
```

3、不限制元素类型的结构：

- `el:first-child`寻找第一个子元素；
- `el:last-child`寻找最后一个子元素；
- `el:nth-child(n)`寻找「正数」第`n`个子元素（或者选`odd`表示奇数，`even`表示偶数）；
- `el:nth-last-child(n)`寻找「倒数」第`n`个子元素（或者选`odd`表示奇数，`even`表示偶数）；
- `el:only-child`寻找元素下只有一个子级的元素；

示例：

```css
li:first-child {
  background-color: orange;
}
li:last-child {
  background-color: green;
}
li:nth-child(odd) {
  color: red;
}
```

4、限制元素类型的结构：

- `el:first-of-type`寻找同类型元素的第一个兄弟元素；
- `el:last-of-type`寻找同类型元素的最后一个兄弟元素；
- `el:nth-of-type(n)`寻找「正数」同类型元素的第`n`个兄弟元素（或者选`odd`表示奇数，`even`表示偶数）；
- `el:nth-last-of-type()`寻找「倒数」同类型元素的第`n`个兄弟元素（或者选`odd`表示奇数，`even`表示偶数）；
- `el:only-of-type`寻找同类型元素下只有一个子级的兄弟元素；

示例：

```css
li:first-of-type {
  background-color: orange;
}
li:last-of-type {
  background-color: green;
}
li:nth-of-type(odd) {
  color: red;
}
```

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1666061077697-c7cc79fd-1c99-47ae-9cee-396e148c6145.png)

`:first-child`和`:first-of-type`的区别：

- `:first-child`是选择父元素下的第 1 个子元素（不区分元素类型），而`:first-of-type`是选择父元素下某个元素类型的第 1 个子元素（区分元素类型）；
- `:last-child`和`:last-of-type`、`nth-child(n)`和`:nth-of-type(n)`同样也可以这样去理解；

理解了上面的再看个案例：

```css
div :first-child {
  background-color: red;
}
```

## 否定伪类选择器
`el:not(){ ... }`用于排除某类型的元素。

示例：

```css
li:not(:first-child){
  color: blueviolet;
}
```

## 目标伪类选择器
`el:target`寻找匹配 URL 上 hash 的元素。

示例：

```css
<body>
  <a href="#title1">title1</a>
  <a href="#title2">title2</a>
  <ul>
    <li id="title1">标题1</li>
    <li id="title2">标题2</li>
  </ul>
</body>
```

```css
:target {
  background-color: orange;
}
```

## 状态伪类选择器
- `el:enabled{ ... }`匹配可用的`<input>`元素；
- `el:disabled{ ... }`匹配禁用的`<input>`元素；
- `el:read-only{ ... }`匹配只读的`<input>`元素；
- `el:checked{ ... }`匹配选中的`<input>`元素；
- `el:default{ ... }`匹配单选框、复选框默认勾选项；
- `el:read-write{ ... }`表单项可写；

示例：

```html
<form action="">
  <input
    type="checkbox"
    id="basketball"
    name="interest"
    value="basketball" />
  <label for="basketball">篮球</label>

  <!--  默认选中  -->
  <input
    type="checkbox"
    checked
    id="running"
    name="interest"
    value="running" />
  <label for="running">跑步</label>

  <input
    type="checkbox"
    id="sing"
    name="interest"
    value="sing" />
  <label for="sing">唱歌</label>
</form>
```

```css
input[type="checkbox"]:default{
  outline: 2px solid red;
}
```

## 伪元素选择器
`el::selection{ ... }`匹配被选择的文字。

示例：

```css
p::selection{
  background-color: orange;
}
```
