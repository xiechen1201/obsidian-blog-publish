CSS 的基本语法：

```css
选择器 {
  属性名: 属性值;
  属性名: 属性值;
}
```

## ID 选择器
需要先给元素设置`id`属性，然后用`#id`去选择到`DOM`，`ID`要具有唯一性：

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Document</title>
    <style type="text/css">
      #box {
        width: 100px;
        height: 100px;
      }
    </style>
  </head>
  <body>
    <div id="box"></div>
  </body>
</html>
```

## 类选择器
需要先给元素设置`class`属性，然后用`.class`去选择到`DOM`，类选择符更适合定义一类样式：

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Document</title>
    <style type="text/css">
      .box {
        width: 100px;
        height: 100px;
      }
    </style>
  </head>
  <body>
    <div class="box"></div>
    <div class="box"></div>
  </body>
</html>
```

## 伪类选择器
伪类用于选择元素的特殊状态，通常是用户交互或者文档的特定状态。它们是在不修改 HTML 元素本身的情况下，为元素的不同状态或基于特定条件应用样式。

1、状态伪类：

- `:link`超链接的初始状态，仅适用于`<a>`元素;
- `:visited`超链接被访问后的状态，仅适用于`<a>`元素;
- `:hover`鼠标悬停，即鼠标划过超链接时的状态;
- `:active`超链接被激活时的状态，即鼠标按下时超链接的状态;
- `:focus`元素获得焦点时应用的样式；

示例：

```css
a:hover {
  color: red;
}

a:active {
  color: blue;
}
```

2、结构伪类

- `:first-child`选中第一个子元素；
- `:last-child`选中最一个子元素；

示例：

```css
li:first-child {
  background-color: orange;
}

li:last-child {
  background-color: green;
}
```

## 属性选择器
使用`[]`对标签的属性进匹配。

1、匹配包含某个属性的元素，示例：

```css
/* 含有 href 的属性 */
[href] {
  text-decoration: none;
}

/* div 含有 href 属性的元素 */
div[id] {
  width: 100px;
  height: 100px;
}
```

2、匹配某个属性完全等于某个属性值的元素，示例：

```css
/* input 标签且 type="text" */
input[type="text"]{
  border: none;
}
```

3、匹配属性值是一个单词，且完全匹配的元素，示例：

```css
/* 元素：<div class="box test"></div> */
div[class~="box"] {
  border: 1px solid;
}
```

4、匹配属性值等于 value 或以 value- 开头的元素，示例：

```css
/* <input lang="en-us" /> */
input[lang|="en"]{
  border: none;
}
```

## 元素选择器
对页面上所有选择的标签样式都会生效：

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Document</title>
    <style type="text/css">
      div {
        width: 100px;
        height: 100px;
      }
    </style>
  </head>
  <body>
    <div>内容1</div>
    <div>内容2</div>
  </body>
</html>
```

## 伪元素选择器
伪元素用于选择元素的特定部分或生成一个新的虚拟子元素，这个子元素可以用于样式化文档中尚未显式存在的内容。

1、在元素之前创建元素，示例：

```css
p::before {
  content: "Note: ";
  color: red;
}
```

2、在元素之后创建元素，示例：

```css
p::after {
  content: " [End]";
  color: blue;
}
```

<br/>warning
⚠️ 注意

上面两个伪元素在元素的前面或者后面创建一个元素的时候，必须要用`content`属性否则不起作用。

<br/>

3、选中元素的首字母，示例：

```css
.box::first-letter {
    color: red;
}
```

4、选中元素的首行文本，示例：

```css
.box::first-line {
  color: red;
}
```

<br/>warning
⚠️ 注意

上面两个伪元素在元素只能生效于块元素。

<br/>

## 通配符选择器
对页面上所有的标签样式都会生效，适用于页面初始化默认样式：

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Document</title>
    <style type="text/css">
      *{
        width: 100px;
        height: 100px;
      }
    </style>
  </head>
  <body>
    <div>内容1</div>
    <li>内容2</li>
  </body>
</html>
```

## !important 关键字
`!important`可以将样式的优先级设置为最高：

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Document</title>
    <style type="text/css">
      #box {
        /* 覆盖下面 aqua 的样式 */
        background-color: red !important;
      }
      div {
        background-color: aqua;
      }
    </style>
  </head>
  <body>
    <div id="box"></div>
  </body>
</html>
```

## 关系选择器
## > 后代选择器
选择某个元素下所有后代子元素。

语法：

```css
选择符1 选择符2 { 属性：属性值; }
```

示例：

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Document</title>
    <style type="text/css">
      strong em {
        color: red;
      }
      strong .box {
        color: blue;
      }
    </style>
  </head>
  <body>
    <strong>
      <em>这是测试内容</em>
    </strong>
    <strong>
      <div class="box">这是测试内容</div>
    </strong>
  </body>
</html>
```

## > 子元素选择器
选择某个元素下的某个子元素。

语法：

```css
选择符1 > 选择符2 { 属性：属性值; }
```

示例：

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Document</title>
    <style type="text/css">
      strong > em {
        color: red;
      }
      strong > .box {
        color: blue;
      }
    </style>
  </head>
  <body>
    <strong>
      <em>这是测试内容</em>
    </strong>
    <strong>
      <div class="box">这是测试内容</div>
    </strong>
  </body>
</html>
```

## > 相邻兄弟
选择某个元素相邻的兄弟元素。

语法：

```css
选择符1 + 选择符2 { 属性：属性值; }
```

语法：

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Document</title>
    <style type="text/css">
      h1 + box {
        border: 1px solid #000;
      }
    </style>
  </head>
  <body>
    <h1 class="title">标题</h1>
    <div class="box box1">内容</div>
  </body>
</html>

```

## > 并列选择器
类似多个条件（选择器）并列。

语法：

```css
选择器1选择器2{ ... }
```

示例：

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Document</title>
    <style type="text/css">
      h1.title {
        color: gold;
      }
      .box.boox1{
        color: red;
      }
    </style>
  </head>
  <body>
    <h1 class="title">标题</h1>
    <div class="box box1">内容</div>
  </body>
</html>

```

## > 群组选择器
表示多个选择器为一组。

语法：

```css
选择器1,选择器2,选择器3{ ... }
```

示例：

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Document</title>
    <style type="text/css">
      input,div,li {
        width: 100px;
        height: 100px;
      }
    </style>
  </head>
  <body>
    <input type="text" />
    <div></div>
    <li></li>
  </body>
</html>
```
