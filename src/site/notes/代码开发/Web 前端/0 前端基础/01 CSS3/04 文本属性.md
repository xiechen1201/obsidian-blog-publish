## 字体大小
语法：

```latex
font-size: value;
```

属性值：

- value 可选：
    - 具体数字 + `px`像素单位；
    - 具体数字 + `em`相对单位；
    - 具体数字 + `rem`相对单位；

示例：

```css
.content {
  font-size: 20px;
}
```

> [!tip]
>
> Info
>
> 为了减小系统间的字体显示差异，IE Netscape Mozilla 的浏览器制作商于 1999 年召开会议，共同确定`16px`标准字体大小默认值，即`1em`。


## 字体颜色
语法：

```latex
color: value;
```

属性值：

- value 可选：
    - colorName；
    - hexColor；
    - `rgb()`；
    - `rgba()`；
    - `hsl()`;
    - 详见：[MDN](https://developer.mozilla.org/zh-CN/docs/Web/CSS/color)；

示例：

```css
.box1 {
  color: #000000;
}

.box2 {
  color: rgba(10, 20, 30, 1);
}

.box3 {
  color: red;
}
```

## 文本字体
语法：

```latex
font-family: value1，value2，value3;
```

- 属性值：
    - value：可选：
        * 字体的名称；
            - 浏览器首先会寻找字体 1，如存在就使用该字体来显示内容，如在字体 1 不存在的情况下，则会寻找字体 2，如字体 2 也不存在，按字体 3 显示内容，如果字体 3 也不存在，则按系统默认字体显示；

细节：

- 如果字体是中文字体时，需加双引号，例如`"微软雅黑"`；
- 如果英文字体中有空格时，需加双引号例如`"Times New Roman"`；
- 如果英文字体只有一个单词组成可以不加双引号，例如`Arial`；
- Windows 中文版本操作系统下，中文默认字体为宋体或者新宋体，英文字体默认为 Arial；

示例：

```css
.box1 {
  font-family: "宋体", "微软雅黑";
}
```

## 字体加粗
语法：

```latex
font-weight: value;
```

属性值：

- value 可选：
    - `bolder`更粗的；
    - `bold`加粗；
    - `normal`正常；
    - 具体的数字 100—900；

示例：

```css
.box1{
  font-weight: bold;
}

.box2{
  font-weight: 500;
}
```

## 字体风格
语法：

```latex
font-style: value;
```

属性值：

- value 可选：
    - `italic`斜体；
    - `oblique`斜体；
    - `normal`正常；

> [!tip]
>
> `italic`和`oblique`都是向右倾斜的文字，但区别在于`Italic`是指斜体字，而`oblique`是倾斜的文字，对于没有斜体的字体应该使用`oblique`属性值来实现倾斜的文字效果。


示例：

```css
.box1{
  font-style: italic;
}
```

## 水平对齐
语法：

```latex
text-align: value;
```

属性值：

- value可选：
    - `left`；
    - `center`；
    - `right`；
    - `justify`两端对齐，这个值对中文无效；

示例：

```css
.box{
  text-align: center;
}
```

## 垂直对齐
语法：

```latex
vertical-align: value;
```

属性值：

- `value`可选：
    - `baseline`使元素的基线与父元素的基线对齐；
    - `top`；
    - `bottom`；
    - `middle`居中对齐；
    - 详见：[MDN](https://developer.mozilla.org/zh-CN/docs/Web/CSS/vertical-align#%E5%B0%9D%E8%AF%95%E4%B8%80%E4%B8%8B)；

> [!warning]
>
> 如果行内块里面没有文本，默认是和行内块的底部进行对齐；
>
> 如果行内块里有文本，则会和块内的文本进行对齐；
>
> `vertical-align`就是解决行内块和行内元素对齐的问题，不能用它垂直对齐块级元素！！！


示例：

```css
/* 容器内多行文本居中的方法 */
.box{
  display: table;
}

.item{
  display: table-cell;
  vertical-align: middle;
}
```

## 文本行高
行高就是文本占据的高度，具有默认高度。

语法：

```latex
line-height: value;
```

属性值：

- `value`可选：
    - `normal`正常；
    - 具体数值；

> [!tip]
>
> Info
>
> 当单行文本的行高「等于」容器高时，可实现单行文本在容器中垂直方向居中对齐；
> 当单行文本的行高「小于」容器高时，可实现单行文本在容器中垂直中齐以上；
> 当单行文本的行高「大于」容器高时，可实现单行文本在容器中垂直中齐以下;


示例：

```css
.box{
  /* 垂直居中对齐 */
  width: 100px;
  height: 100px;
  line-height: 100px;
}
```

## font 属性的简写
该属性是`font-style`、`font-weight`、`font-size`、`line-height`和`font-family`几个属性的简写。

语法：

```latex
font: font-style font-weight font-size/line-height font-family;
```

> [!warning]
>
> 1、简写时`font-size`和`line-height`只能通过斜杠/组成一个值，不能分开写。
> 2、顺序不能改变，这种简写法只有在同时指定`font-size`和`font-family`属性时才起作用，而且你没有设定`font-weight`和`font-style`，他们会使用默认值。


示例：

```css
.box{
  font: italic bold 20px/50px "楷体";
}
```

## 文本修饰
语法：

```latex
text-decoration: value;
```

属性值：

- `value`可选：
    - `none`无；
    - `underline`下划线；
    - `overline`上划线；
    - `line-through`中划线；

示例：

```css
.box1{
  text-decoration: underline;
}
```

## 文本缩进
语法：

```latex
text-indent: value;
```

属性值：

- `value`可选：
    - 具体数值；

> [!warning]
>
> 该属性只对第一行起作用！


示例：

```css
.box1 {
  /* em 是相对父元素字体大小，如果父元素字体大小为 16px，那么 2em 就是 32px */
  text-indent: 2em;
}
```

## 文本空白
语法：

```latex
white-space: value;
```

属性值：

- `value`可选：
    - `normal`默认值，空白会被浏览器忽略；
    - `nowrap`文本不会换行，文本会在同一行上继续，直到遇到标签为止；
    - `pre`空白会被浏览器保留，其行为方式类似`HTML`中的`pre`标签；
    - `pre-wrap`保留空白符序列，但是正常的进行换行；
    - `pre-line`合并空白符序列，但是保留换行符；

```css
.box {
  white-space: nowrap;
}
```

## 文本省略号
语法：

```latex
text-overflow: value;
```

属性值：

- `value`可选：
    - `clip`不显示省略号，而是简单的裁切；
    - `ellipsis`当对象内文本溢出时，显示省略标记；
    -

`text-overflo` 属性仅是显示`...`省略号，如果要实现溢出时产生省略号的效果还需定义：

1、容器宽度`width: value;`；

2、强制文本在一行内显示`white-space: nowrap;`；

3、溢出内容为隐藏`overflow：hidden;`；

4、溢出文本显示省略号`text-overflow：ellipsis;`

示例：

```latex
.box{
  width: 200px;
  border: 1px solid #000;
  /* 文本超出显示省略号 三大件 */
  overflow: hidden;
  white-space: nowrap;
  text-overflow: ellipsis;
}
```
