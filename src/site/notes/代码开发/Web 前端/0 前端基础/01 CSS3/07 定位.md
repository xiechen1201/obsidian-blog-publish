## 🔢 文档流
学习定位之前，我们首先需要了解一下文档流。

默认情况下，块级元素的宽度是父元素的 100%，高度和内容一样高。内联元素的宽高和其内容的宽高一致。

块级元素在页面中是从上到下垂直布局的，内联元素则不是，它们不会新开一个行，而是横向挨着排列的，如果父元素宽度不足则会换行显示。

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1742546371427-8fa4838b-cab2-4ad0-a78a-2c1150ee7ec0.png)

## 🔢 定位
定位则会覆盖上面的正常文档流状态，例如让某个元素定位在页面或者其他元素的某个位置上。

目前，有五种定位方式：

- `static`静态定位；
- `relative`相对定位；
- `absolute`绝对定位；
- `fixed`固定定位；
- `sticky`粘性定位；

## 🔢 静态定位
静态定位其实就是所谓的正常文档流，没有什么特别的。该属性不受到`top`、`bottom`、`left`和`right`的影响。

## 🔢 相对定位
相对定位和和静态定位非常的类似，占据在正常文档流中，可以设置其位置（相对于元素原始的位置）让具有相对定位的元素和其他正常元素重叠。

```html
<div class="one">one</div>
<div class="two">two</div>
<div class="three">three</div>
```

```css
*{
  margin: 0;padding: 0;
}

div{
  width: 100px;
  height: 100px;
  outline: 1px solid;
  line-height: 100px;
  text-align: center;
}

.two{
  position: relative;
  left: 50px;
  top: 50px;
}
```

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1742546891301-e1092d94-cc0a-444c-bfc6-291938c19f30.png)

可以看到对`.two`的元素设置了`left`和`top`属性后，`.two`的位置发生了变化。

Tip

`top`、`bottom`、`left`和`right`可以精确的指定要将定位元素移动到的位置。

<br/>

## 🔢 绝对定位
绝对定位是相对于距离自己最近的，并且具有定位元素进行偏移，如果所有的父元素都是静态定位，则会根据浏览器「页面」进行定位，而不是浏览器「窗口」。

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1742547831713-2f517af9-cb12-4b7c-a8e9-51c4b45c1d8f.png)

使用绝对定位属性后，元素会脱离标准文档流，原始的位置也会被其他元素占有。如果元素还设置了`margin`属性，那么该属性也会失效。

```html
<div class="one">one</div>
<div class="two">two</div>
<div class="three">three</div>
```

```css
*{
  margin: 0;padding: 0;
}

div{
  width: 100px;
  height: 100px;
  outline: 1px solid;
  line-height: 100px;
  text-align: center;
}

.two{
  position: absolute;
  left: 50px;
  top: 50px;
}
```

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1742547381447-cad0d84f-a0bc-45ec-9ad6-3ecf6ee79ebf.png)

可以看到，`.two`元素设置绝对定位后，原始的位置被`.three`占据了。

另外，设置了绝对定位后的元素其`display`属性会变成`block`，例如：

```html
<a href="#">百度一下</a>
```

```css
*{
  margin: 0;padding: 0;
}

a{
  outline: 1px solid;
  width: 100px;
  height: 100px;
  position: absolute;
  top: 50px;
  left: 50px;
}
```

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1742547708720-d8b73260-7f77-48da-a14b-d1cf1f6636bc.png)

可以看到，元素不能设置宽高的内联元素，设置了绝对定位属性后，`display`变成了`block`，可以设置宽高了。

假如一个父元素设置了定位元素，例如设置了相对定位，那么绝对定位元素则会在父元素内进行位置定位。

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1742547958239-4c0a5b79-98ac-41cf-9ec0-f1b4e939e68f.png)

（红色元素为绝对定位，绿色元素为相对定位）

## 🔢 固定定位
固定定位和相对定位基本类似，也会脱离标准文档流，只不过固定定位不会相对于最近的具有定位属性的祖先元素进行定位，而是相对于浏览器「窗口」。

对一个盒子进行固定定位以后，无论页面如何滚动，这个盒子的显示位置都是不会变化的。

很多时候，经常使用固定定位对页面的导航栏在页面上进行固定定位。

## 🔢 粘性定位
粘性定位基本上属于相对定位和固定定位的组合模式。当页面滚动到一个阈值的时候（例如窗口顶部 10px），从此该元素就变成固定的了，否则就是相对定位的行为。

它是相对于它的最近一个可以滚动的祖先元素进行定位的。

## 🔢 z-index
还有一个非常重要的属性--`z-index`。当元素开始重叠后，该属性就决定了哪些元素出现在其他元素的最前面。

我们可以把`z-index`数值想象是对 Z 轴的层级调整，值越大则元素的层级越高。

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1742551057289-560e144b-a164-467b-8bfb-672fc3d10a51.png)

例如：

```css
.two{
  position: absolute;
  left: 50px;
  top: 50px;
  z-index: 10;
}
```

## 🔢 层叠上下文
某些元素的显示层级会受到`z-index`值的影响。因为这些元素具有一些特殊属性，它们可以创建自己的层叠空间，从而决定谁在上、谁在下。

在层叠上下文中，子元素的层级关系也是按照同样的规则来决定的。关键点在于，子元素的`z-index`只在它所在的父级范围内起作用。换句话说，子元素的层叠顺序不会影响父级之外的元素，而是作为父级层叠上下文的一个独立空间来处理。

示例：

```html
<div class="outer"></div>
<div class="modal">
  <div class="overlapping-element"></div>
</div>
```

```css
.outer {
    position: relative;
    z-index: 10;
    width: 100px;
    height: 100px;
    width: 100px;
    height: 100px;
    background-color: rgb(146, 209, 52, 0.8);
}

.modal {
    position: absolute;
    top: 50px;
    left: 50px;
    z-index: 100;
    width: 100px;
    height: 100px;
    background-color: rgba(0, 0, 0, 0.8);
    padding: 20px;
    border-radius: 5px;
}

/* 与模态框重叠的元素，其 z-index 更高 */
.overlapping-element {
    position: absolute;
    top: 70px;
    left: 70px;
    z-index: 20; /* 这个 z-index 比 .outer 更高 */
    width: 20px;
    height: 20px;
    background-color: red;
    color: white;
    padding: 10px;
    border-radius: 5px;
}
```

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1742780965207-ed4fc45a-bb72-4da6-872c-df6f6e90c2a0.png)

当符合以下任意一个条件后，会形成一个新的层叠上下文：

- 文档的根元素`<html>`（其本身就是一个层叠上下文）；
- `position`的值为`absolute/relative`且`z-index`的值不为`atuo`；
- `flex`容器的子元素，且`z-index`的值不为`atuo`；
- `grid`容器的子元素，且`z-index`的值不为`atuo`；
- ...

总结：层叠上下文都是自包含的：当一个元素的内容发生层叠后，该元素将被作为整体在父级层叠上下文中按顺序进行层叠。
