## transform
`transform`属性应用于元素的 2D 或 3D 的转换。

`transform`的属性值有：

- `rotate()`旋转；
- `skew()`倾斜；
- `scale()`缩放；
- `translate()`位移；

以上 4 个属性值分别还有 X、Y 轴的坐标概念，比如`rotate()`方法又细分出`rotateX()` 、`rotateY()`的针对单个坐标方向的方法。

## 位移
将元素向指定的方向移动，类似于`position: relative`。

- `translate(x, y)`定义 2D 转换，沿着 X 轴和 Y 轴移动；
- `translateX()`水平方向移动一个对象，如果值为正值，对像向右移动，如果值为负值，对像向左移动；
- `translateY()`纵轴方向移动一个对象，如果值为正值，对象向下移动，如果值为负值，对像向上移动；

<br/>tips
Info

`translate(-100px ,0)`实际上等于`translateX(-100px)`

`translate(0, -100px)`实际上等于`translateY(-100px)`

<br/>

示例：

```css
.content2:hover {
  transform: translate(100px, 0);
}
```

## 缩放
让元素根据中心原点对对象进行缩放。

- `scale(X, Y)`元素沿着 X 和 Y 轴按照指定的倍数进行缩放；
- `scaleX(x)` 元素沿着 X 轴按照指定的倍数进行缩放；
- `scaleY(y)`元素沿着 Y 轴按照指定的倍数进行缩放；

方法参数：

- X 和 Y 的默认的值 1，因此 0.01 到 0.99 之间的任何值，使一个元素缩小；
- 如果只有一个值时，其第二个值默认与第一个值相等；
    - 例如`scale(1, 1)` 元素不会有任何变化，而`scale(2, 2)`让元素沿 X 轴和 Y 轴放大两倍。

<br/>warning
⚠️ 注意

1、设置缩放的时候，每个值都代表的是倍数，不能带单位。

2、如果希望元素缩小，那么设置的值在 0-1 之间的小数，如果希望放大，则设置大于 1 的值。

<br/>

示例：

```css
.content3:hover {
  transform: scale(0.5, 0.5);
}
```

## 旋转
通过指定的角度参数`deg`对元素根据对象原点指定一个 2D 旋转，它主要在二维空间内进行操作。

- `rotate(*deg)`接受一个角度值，用来指定旋转的幅度（类似按照 Z 轴进行旋转）；
- `rotateX(*deg)` 元素围绕其 X 轴以给定的度数进行旋转；
- `rotateY(*deg)` 元素围绕其 Y 轴以给定的度数进行旋转；

<br/>warning
⚠️ 注意

如果值为正值，元素相对原点中心顺时针旋转；

如果值为负值，元素相对原点中心逆时针旋转。

<br/>

示例：

```css
.content:hover {
  transform: rotate(30deg)
}
```

## 倾斜
能够让元素倾斜显示，它可以将一个对象以其中心位置围绕着 X 轴和 Y 轴按照一定的角度倾斜。

- `skew(x, y)`一个参数时表示水平方向的倾斜角度，两个参数时第一个参数表示水平方向的倾斜角度，第二个参数表示垂直方向的倾斜角度；
- `skewX()`定义沿着`X`轴的 2D 倾斜转换；
- `skewY()`定义沿着`Y`轴的 2D 倾斜转换；

## transform-origin
该属性用于设置元素变形原点，也就是该元素围绕着那个点变形或旋转，默认是元素的中心点。

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1667222212131-94dbaa84-8e8a-4aee-80cd-1c56573b664c.png)

因为我们元素默认基点就是其中心位置，换句话说我们没有使用`transform-origin`属性改变元素基点位置的情况下，`transform`进行的`rotate()`、`translate()`、`scale()`和`skew()`等操作都是以元素自己中心位置进行变化的。

```css
.box{
  transform: rotate(90deg);
  transform-origin: left top;
}
```

## 复合动画
当使用复合动画的时候，动画是按照顺序执行的，也就是说以下代码先进行位移再进行旋转。

示例：

```css
transform: translate(300px, 200px) rotate3d(0, 0, 0.6, 45deg);
```

多个动画之间用空格分隔。
