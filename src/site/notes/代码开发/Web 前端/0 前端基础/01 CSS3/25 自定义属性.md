## 🔢 初识自定义属性
什么是自定义属性？

自定义属性也就是根据我们的需求「自定一个属性的名称和属性的值」。

定义一个自定义属性和定义一个 CSS 属性的区别并不大，自定义属性需要使用`--`来作为前缀。

```css
:root {
  /* 这是自定义属性 */
  --color: #fff000;
  --sz-cm: 100px;
  /* 这是 CSS 的本身属性 */
  background-color: #f0f0f0;
}
```

要想使用自定义属性，我们还得使用 CSS 中的`var()`函数来引用自定义属性：

```css
:root {
  --color: #fff0000;
  --sz-cm: 100px;
}

div {
  background-color: var(--color);
  width: var(--sz-cm);
}
```

以上代码，会给 div 元素设置背景颜色和一个宽度。

当然，我们可以使用 CSS 中的`cacl()`方法来计算：

```css
:root {
  --color: #fff0000;
  --sz-cm: 100px;
}

div {
  background-color: var(--color);
  width: calc(var(--sz-cm) * 2px);
}
```

以上代码，我们给 div 元素的宽度再*2px。

CSS 变量可以干什么？

1、可以提取相同的属性值，例如定义一些全局共用的颜色值、边框的大小等等。

2、简化相似的代码。

当然，它的功能还不止这一些...

## 🔢 属性值切换
下面是一个共用主题色的小案例：

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1692243642698-62b3021c-3b91-4678-8ce3-c01f5f58573f.png)

这是一个简单的页面布局，分别是 section、aside 和 footer ，其中它们都是使用了`:root`伪类的`--theme-color`属性，这个时候背景色是灰色的。

假如，这个时候需求变了说要主题是要为绿色，我们只需要更改`:root`伪类中的`--theme-color`自定义属性值即可。

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1692243968733-d6e62eed-af4b-4030-aeb7-283a6890160b.gif)

或者我们还可以通过 JS 来动态的设置页面的主题色：

```html
<body>
  <div class="content-box">
    <ul>
      <li data-color="#dddddd">灰色</li>
      <li data-color="#84fab0">绿色</li>
      <li data-color="#46aef7">蓝色</li>
    </ul>
    <main>
      <section>section</section>
      <aside>aside</aside>
    </main>
    <footer>footer</footer>
  </div>
  <script>
    const oUl = document.querySelector("ul");
    const root = document.querySelector(":root")

    oUl.onclick = function (e) {
      if (e.target.nodeName === "LI") {
        const color = e.target.dataset.color;
        root.style.setProperty("--theme-color", color);
      }
    };
  </script>
</body>
```

以上代码，通过获取到 li 中的自定义属性，然后通过`setProperty()`方法来设置`:root`的`--theme-color`属性值，来实现动态主题的切换。

## 🔢 作用域
CSS 变量也存在作用域的问题：

自定义属性也存在作用域的问题，使用`var()`函数寻找变量的时候，它会先从当前选择器中查找，然后是父元素、祖父元素，直到根元素。

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <title></title>
    <style>
      * {
        margin: 0;
        padding: 0;
      }

      :root {
        --color: #ff9a9e;
      }

      .box1 {
        --color: #ffd1ff;
      }

      .box2 {
        --color: #a18cd1;
      }

      .box3 {
        --color: #8fd3f4;
        width: 100px;
        height: 100px;
        margin: 200px auto;
        background-color: var(--color);
      }
    </style>
  </head>
  <body>
    <!-- 3 个盒子层层嵌套 -->
    <div class="box1">
      <div class="box2">
        <div class="box3"></div>
      </div>
    </div>
  </body>
</html>

```

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1692258190925-dfc3ffd5-16b3-43b9-aa02-cb6796020630.gif)

从图中可以看到，当我删除每个父元素的`--color`的属性后，`var()`都会继续向上找。如果到`:root`还是没有`--color`这个属性，那么就会使用默认的样式，也就是白的背景色。

当然，`var()`还可以使用默认值：

```css
* {
  margin: 0;
  padding: 0;
}

/* :root {
--color: #ff9a9e;
}

.box1 {
--color: #ffd1ff;
}

.box2 {
--color: #a18cd1;
} */

.box3 {
  /*  --color: #8fd3f4; */
  width: 100px;
  height: 100px;
  margin: 200px auto;
  background-color: var(--color, #000);
}
```

这样，即使`var()`找不到`--color`属性的时候，那么他就会使用自己的默认值。

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1692258443575-47df8925-0f60-4a21-8f12-1fd6cdc55093.png)

`var()`的默认值还可以是一个`var()`函数：

```css
* {
  margin: 0;
  padding: 0;
}

:root {
  /* --color: #ff9a9e; */
  --default-color: red;
}

/*.box1 {
--color: #ffd1ff;
}

.box2 {
--color: #a18cd1;
} */

.box3 {
  /*  --color: #8fd3f4; */
  width: 100px;
  height: 100px;
  margin: 200px auto;
  background-color: var(--color, var(--default-color, #000));
}
```

这个时候，`.box3`的`var()`函数先去找`--color`属性，如果找不到就去使用默认值。默认值又是一个`var()`函数，又去找`--default-color`属性，如果找到了就显示为红色，如果还是找不到那就使用黑色。
