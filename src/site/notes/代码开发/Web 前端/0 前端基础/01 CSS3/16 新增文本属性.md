## 文字阴影
语法：

```latex
text-shadow: X轴偏移量 Y轴偏移量 模糊半径 阴影颜色;
```

属性值：

- `X`轴偏移量：正数是向右偏移，必填；
- `Y`轴偏移量：正数是向下偏移，必填；
- 模糊半径：值越大越模糊，最小为 0；
- 阴影颜色：颜色值；

示例：

```css
.box {
  text-shadow: 10px 10px 10px #000;
}
```

和`box-shadow`一样，当使用逗号进行分隔表示多层阴影，示例：

```css
.box {
  text-shadow: 10px 10px 10px #000, 20px 20px 10px red;
}
```

## 文字换行
说到文字换行我们需要了解浏览器对文字的换行处理规则：

1. 完整的「英文单词」会超出容器，当遇到空格、连字符`“-”`会进行换行（认为是一个单词）；
2. 中文字符串正常换行（一个字就是一个字符），当遇到标点符号的为下一行行首的时候，会将上一行的末尾文字也进行换行；

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1666526432131-ec328154-1fca-4dc3-af27-342971a1ff35.png)

浏览器认为`SupportSupportSupport`是一个单词，当一行显示不下的时候会尝试换行进行显示，如果换行后还是显示不下就会溢出盒子。

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1666526473492-0960771d-7d6d-4d26-9fba-8eff69e5eea1.png)

我们可以利用连字符`“-”`会进行换行。

语法：

```latex
word-wrap: value;
```

属性值：

- value
    - `noraml`正常；
    - `break-wrap`长单词截断换行；

示例：

```css
.box {
  width: 200px;
  height: 200px;
  border: 1px solid #000;
  word-wrap: break-word;
}
```

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1666526753786-3b299be1-93a8-47e2-a088-e2db520839c8.png)

`break-wrap`可以强制让单词截断换行！

## 文本断行
语法：

```latex
word-break: value;
```

属性值：

- value
    - `noraml`正常；
    - `break-all`长单词不进行另起一行的进行换行（单词内进行换行）；
    - `keep-all`只能在半角空格或连字符处换行；

示例：

```css
.box {
  width: 200px;
  height: 200px;
  border: 1px solid #000;
  word-break: break-all;
}
```

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1666527054536-abdc988b-82ce-4bec-8655-b4ef55829564.png)

`break-all`属性可以让单词不另起换行，直接在本行进行单词断行。

## 自定义字体

> [!tip]
>
> `@font-face`是`CSS3`新增的规则，而不是属性！
>
> 它需要配合`font-famil`字体名称、`src`字体路径来使用，当使用逗号`,`进行分隔的时候表示字体兼容，当第一种字体不兼容的时候就会向后加载。


示例：

```css
@font-face {
  /* 自定义字体名称为 my-font */
  font-family: "my-font";
  src: url(./fonts/Spooky-Fright.ttf), /* url用来加载字体文件，可以是在线或本地地址 */
       url(./fonts/Mythias.otf) format(otf); /* format表示浏览器对字体格式的支持不一样，需要指定后缀 */
}

p{
  /* 使用字体 */
  font-family: "my-font";
  font-size: 30px;
}
```
