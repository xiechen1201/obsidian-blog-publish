## 宽与高
定义宽度，语法：

```latex
width: value;
min-width: value;
max-width: value;
```

定义高度，语法：

```latex
height: value;
min-height: value;
max-height: value;
```

宽度和高度属性值`value`都可选：具体单位值`px`/`em`/`rem`，示例：

```css
.box1 {
  width: 100px;
  max-width: 500px;
  height: 100px;
}
```

## 内外边距
定义外边距，语法：

```latex
margin-top: value;
margin-right: value;
margin-bottom: value;
margin-left: value;

margin: top right bottom left;
margin: top (left and right) bottom;
margin: (top and bottom) (left and right);
margin: (top、right、bottom and left)；
```

定义内边距，语法：

```latex
padding-top: value;
padding-right: value;
padding-bottom: value;
padding-left: value;

padding: top right bottom left;
padding: top (left and right) bottom;
padding: (top and bottom) (left and right);
padding: (top、right、bottom and left)；
```

属性值：

- `value`可选：
    - 具体数字 + `px`像素单位；
    - 具体数字 + `em`相对单位；
    - 具体数字 + `rem`相对单位；
    - `auto`自动；

<br/>warning
⚠️ 注意

1、浏览器的`<bady>`标签默认有`margin`外边距，一般初始化的时候要清除掉`body { margin: 0; }`；

2、`padding/margin`是一个复合值，属性值的个数表示的意思也不相同；

<br/>

示例：

```css
.box1{
  /* 外上边距10px，外右边距20px，外下边距30px，外左边距40px */
  /* 呈顺时针的方向 */
  margin: 10px 20px 30px 40px;
}

.box2{
  /* 内上边距10px 内左+右边距20px 内下边距40px */
  padding: 10px 20px 40px;
}

.box3{
  /* 内上+下边距10px 内左+右边距40px */
  padding: 10px 40px;
}

.box4{
  /* 内上+右+下+左边距10px */
  padding: 10px;
}

.box5{
  /* 内上边距10px 内右面边距20px */
  padding-top: 10px;
  padding-right: 20px;
}
```

```css
/* 实现块元素左右居中 */
.box {
  width: 300px;
  height: 300px;
  margin: 20px auto;
  padding: 20px;
  border: 1px solid #000;
}
```

## 列表样式
语法：

```latex
list-style-type: value;
```

属性值：

- `value`可选：
    - `disc`实心圆；
    - `circle`空心圆；
    - `square`实心方块；
    - `none`去掉列表符号；
- 示例：

```css
li{
  list-style-type: square;
}
```

使用图片作为列表符号，语法：

```latex
list-style-image: url(所使用图片的路径及全称);
```

示例：

```css
li{
  /* url() 不加引号 */
  list-style-image: url(../img/list.png);
}
```

定义列表符号的位置：

语法：

```latex
list-style-position: value;
```

属性值：

- `value`可选：
    - `outside`外边；
    - `inside`里边；
- 示例：

```css
li{
  list-style-position: inside;
}
```

另外还有一个`list-style`属性是`list-style-type`、`list-style-image`和`list-style-position`的复合属性。

示例：

```css
li{
  list-style: square inside;
}
```

## 内容溢出
定义溢出样式共有三种方式，语法如下：

```latex
overflow: value;		设置x、y轴溢出属性；
overflow-y: value;	设置x轴溢出属性；
overflow-x: value;	设置y轴溢出属性；
```

属性值：

- `value`可选：
    - `visible`默认值，内容不会被修剪，会出现在元素框之外；
    - `hidden`内容会被修剪，并且其余内容是不可见的；
    - `scroll`内容会被修剪，但是浏览器会显示滚动条，以便查看其余的内容；
    - `auto`如果内容被修剪，则浏览器会显示滚动条，以便查看其他的内容；
- 示例：

```css
.box{
  overflow: hidden;
}

.box1{
  overflow-x: scroll;
}
```

## 元素展现
通过`display`属性可以让元素转化为不同的块类型。

语法：

```latex
display: value;
```

属性值：

- `value`可选：
    - `none`隐藏；
    - `inline`行内元素；
    - `inline-block`行内块元素；
    - `table`类似于`<table>`元素；
    - `block`块元素；
    - `flex`布局；

示例：

```css
span{
  display: block;
}
```

```css
/* 容器内多行文本居中的方法 */
div{
  display: table
}
li{
  display: table-cell;
  vertical-align: middle;
}
```

```css
/* 解决图片间隙 */
img{
  display: none;
}
```

<br/>tips
Info

行内、行内块标签，只要是换行、空格都会转变为文本分隔符，如果要取消`<img>`标签的间隙，需要转化为块元素。

<br/>

## 元素可见
语法：

```latex
visibility: value;
```

属性值：

- `value`可选：
    - `visible`显示；
    - `hidden`隐藏；

<br/>warning
⚠️ 注意

`display: none;`不保留在文档内占据的空间

`visibility: hidden;`保留在文档内占据的空间

<br/>

示例：

```css
.box{
  visibility: hidden;
}
```

## 边框样式
单边设置：

```latex
/* 宽度 */
border-top-width: value;
border-right-width: value;
border-bottom-width: value;
border-left-width: value;

/* 样式 */
border-top-style: value;
border-right-style: value;
border-bottom-style: value;
border-left-style: value;

/* 颜色 */
border-top-color: value;
border-right-color: value;
border-bottom-color: value;
border-left-color: value;
```

简写：

```latex
/* 四值：上 右 下 左 */
border-width: 1px 2px 3px 4px;
border-style: solid dashed dotted double;
border-color: red #ccc black rgba(0,0,0,0.5);

/* 三值：上 (左右) 下 */
border-width: 1px 2px 3px;
border-style: solid dashed dotted;
border-color: red #ccc black;

/* 两值：(上下) (左右) */
border-width: 1px 2px;
border-style: solid dashed;
border-color: red #ccc;

/* 单值：统一所有边 */
border-width: 1px;
border-style: solid;
border-color: red;
```

全局简写：

```latex
border: width style color;
```

属性值：

- `width`可选：
    - 具体数值 + `px`像素单位
    - 具体数值 + `em`相对单位
    - 具体数值 + `rem`相对单位
- `style`可选：
    - `dotted`点线；
    - `dashed`虚线；
    - `solid`实线；
    - `double`双线；
- `color`可选：
    - 同`color`属性的值；
    - `transparent`透明；

示例：

```css
.box1{
  border: 1px solid red;
}

.box2{
  border-width: 1px;
  border-style: dashed;
  border-color: transparent;
}

.box3{
  border-top: 1px solid #000;
}

.box4{
  border-top-width: 2px;
}
```

## 盒子模型
盒子模型就是一个容器，具有宽高属性就可以称为盒子/容器。

`padding`和`border`是占据盒子本身的宽高区域之内的，所以盒子的可视区域是：`content`+`padding * 2`+`border * 2`。

例如设置一个宽高为 `200px` 大小的盒子，而盒子的实际宽度是：左右`padding`20 + `content`200 + `border`20 = 240。

示例：

```css
.box {
  width: 200px;
  height: 200px;
  margin: 10px;
  padding: 10px;
  border: 10px solid #000;
}
```

如果想要盒子的`padding`的`border`不改变盒子的实际宽度，需要使用`box-sizing`属性。

语法：

```latex
box-sizing: value;
```

属性值：

- `value`可选：
    - `content-box`默认值，W3C 标准盒模型；
    - `border-box`IE6（怪异）盒模型；
- 示例：

```css
.box {
  width: 200px;
  height: 200px;
  margin: 10px;
  padding: 10px;
  border: 10px solid #000;
  /* 新增属性 */
  box-sizing: border-box;
}
```

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1665230761224-6dc2fa21-8a9e-462e-b25c-e610ea142ad2.png)

Tip

1、W3C 标准盒模型（`content-box`），`border`、`padding` 的设置会破坏元素宽高，必须得重新计算，非常麻烦（除了在 IE 浏览器，默认就是标准盒模型，所以可以用`box-sizing`来转换）。

2、IE（怪异）盒模型（`border-box`），`border`、`padding` 的设置不会影响元素的宽高，这非常实用（且因为 IE 盒模型不是标准，所以才有`box-sizing`这个标准属性来设置，将它标准化）（IE6/5 是怪异模型，IE7 开始是标准盒模型）。

3、另外还可以通过行高的计算去减盒子的宽高。
