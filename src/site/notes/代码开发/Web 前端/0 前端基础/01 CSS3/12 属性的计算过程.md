当我们在浏览器中给元素设置 CSS 属性后，那么属性是如何计算的呢？

示例：

```html
<p>this is a test</p>
```

```css
p{
  color : red;
}
```

上面的代码中是一个非常简单的案例，就是给一个段落设置了字体的颜色。

难道段落就真的只有这一个 CSS 属性吗？

我们查看一下浏览器的控制台：

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1742437877758-508f6d95-86c5-4586-810a-9b86e163328a.png)

段落元素所有的属性都拥有，只不过都是默认值而已。

那么元素的 CSS 属性到底是如何计算的呢？

总体来讲，计算的过程分为下面 4 步：

1. 确定声明值；
2. 层叠冲突；
3. 使用继承值；
4. 使用默认值；

## 🔢 确定声明值
当我们在样式表中对某一个元素书写样式的时候，这个声明就会被当作 CSS 的属性值。

```html
<h1>test</h1>
```

这个标题元素没有书写任何的样式，那么就会使用浏览器的默认样式：

```css
h1 {
  font-size: 32px;
  font-weight: 700;
}
```

如果此时我设置了一个样式：

```css
h1 {
  font-size: 20px;
}
```

我们自己书写的样式称为作者样式，如果作者样式和浏览器的默认样式发生冲突，那么就会优先使用作者样式当作 CSS 的属性值，`font-weight`属性没有产生冲突，因此依旧使用默认值。

## 🔢 层叠冲突
如果样式表中的作者样式有冲突的时候，那么就会使用层叠规则来确定 CSS 的属性值：

```html
<div class="test">
  <h1>test</h1>
</div>
```

```css
.test h1{
  font-size: 50px;
}

h1 {
  font-size: 20px;
}
```

上面代码中，两个选择器都选中了`<h1>`元素，并且都设置了`font-size`属性，这显然就属于层叠冲突。

当发生层叠冲突的时候，就会根据选择器的「权重值」来计算最终使用哪一个作者样式。

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1742438451748-237e02c0-74e0-46d7-8ce7-1a4d0445d0e0.png)

## 🔢 层叠规则
CSS 的选择器在层叠中胜出取决于三个因素（优先级排序）：

- 重要性；
- 专用性；
- 源代码次序；

1、重要性。

在 CSS 中有个关键字`!import`，它优先于所有规则。但是通常情况下不建议使用，除非有特别明确的需要。因为它改变了层叠正常工作的方式，会让调试 CSS 属性变得困难。

2、专用性。

专用性基本上是衡量选择器具体程度的一种方法，主要看它能匹配多少元素。

选择器专用性排序：元素选择器 < 类选择器 < ID 选择器 < 行内样式/`!import`。

一个选择器具有的专用性的量可以使用四种不同的值来衡量，它们可以被认为是千位、百位、十位和个位。

- 千位：如果是行内样式则该列加 1 分，否则为 0；
- 百位：在整个选择器中每包含一个 ID 选择器就在该列加 1 分；
- 十位：在整个选择器中每包含一个类/伪类/属性选择器就在该列加 1 分；
- 个位：在整个选择器中每包含一个元素/伪元素选择器就在该列加 1 分；

注意，通用的选择器（`*`）、复合选择器（`+`、`>`、`～`、空格）和否定伪类（`:not`）在专用性中无影响。

例如：

| 选择器 | 千位 | 百位 | 十位 | 个位 | 合计 |
| --- | --- | --- | --- | --- | --- |
| `h1` | 0 | 0 | 0 | 1 | 0001 |
| `#id` | 0 | 1 | 0 | 0 | 0100 |
| `h1 + p::first-letter` | 0 | 0 | 0 | 3 | 0003 |
| `li > a[href*="zh-CN"] > .inline-warning` | 0 | 0 | 2 | 2 | 0022 |
| 无选择器，使用行内样式 | 1 | 0 | 0 | 0 | 1000 |

3、源代码次序。

如果多个相互竞争的选择器具有相同的重要性和专用性，那么源代码的次序就来帮助决定使用哪一个规则。

例如：

```css
p {
    color: red;
}
p {
    color: blue;
}
```

`<p>`元素的字体最终为蓝色。

不过有一点需要注意，当多个 CSS 规则匹配相同元素的时候，它们都被应用到这个元素上了，只不过因为层叠规则被层叠掉了。

## 🔢 使用继承
如果元素的某个样式，开发者没有设置，那么也不着急去使用默认值，而是看一下能否继承到该属性值。

例如：

```html
<div class="test">
  <p>this is a test</p>
</div>
```

```css
.test{
  color: red;
}
```

在上面的代码中，虽然没有给`<p>`设置`color`属性，但是该属性能够从`<div>`元素上继承得到，所以最终显示为`red`。

## 🔢 继承规则
所谓继承就是应用于某个元素的一些属性值可以被该元素的子元素继承，有些则不会。

常见的可以被自动继承的属性有：

- 字体
    - `font`
    - `font-family`
    - `font-size`
    - `font-style`
    - `font-weight`
- 文本
    - `letter-spacing`
    - `word-spacing`
    - `line-height`
    - `direction`
    - `visibility`
- 颜色
    - `color`

CSS 为了处理继承提供了四种特殊的通用属性：

- `inherit`：继承父元素的属性值；
- `initial`：使用浏览器默认值；
- `unset`：可继承属性表现为 `inherit`，否则为 `initial`；
- `revert`：优先使用自定义样式，否则使用浏览器默认值；

另外继承还遵循就近的原则，属性值的继承会继承离自己最近的那个父元素的属性，例如：

```html
<div class="one">
  <div class="two">
    <p>Lorem ipsum dolor sit amet.</p>
  </div>
</div>
```

```css
.two {
  color: blue;
}

.one {
  color: red;
}
```

在这个示例中，`.two`比`.one`更接近于`<p>`，因此最终会采用`.two`的`color`值。
