## 事件处理函数
说到事件处理函数那得先知道什么是「事件」。

事件简单理解就是干某一件事，比如我吃饭、睡觉这就是一个事件。

既然有了「事件」后总得反馈我点什么。比如我睡觉了第二天我的状态就会很好，我吃饭了我就不会挨饿。

程序毅然如此，我触发「事件」后应该用「事件处理函数」干点什么。

「事件」是元素本身就具有的能力，而绑定事件是给程序一个处理事件的函数，而不是绑定事件本身，被绑定事件的元素就是「事件源」。

绑定事件的方式：

1、利用元素的属性

```html
<div onclick="console.log(1)"></div>
<button onclick="handleClickDiv()"></button>
```

2、用`on`事件来绑定

```js
var oDiv = document.getElementsByTagName("div")[0];

oDiv.onclick = function(){
  // do...
}
```

在同一元素同一事件的时候，后绑定事件会覆盖前绑定的事件：

```js
var oDiv = document.getElementsByTagName("div")[0];

oDiv.onclick = function(){
  console.log(1)
}
oDiv.onclick = function(){
  console.log(2)
}

// 点击 div 元素只会打印 2
```

3、使用`el.addEventListener(type, fn, Boolean)`

<br/>danger
📌  这样虽然是`W3C`提出的规范，但是`IE8`浏览器不兼容

<br/>

```js
var oDiv = document.getElementsByTagName("div")[0];

oDiv.addEeventListener("click",function(){
  console.log(1);
},false)
```

该方法在同一个元素绑定多个同样 的事件依然生效

```js
var oDiv = document.getElementsByTagName("div")[0];

oDiv.addEeventListener("click",function(){
  console.log(1);
},false)

oDiv.addEeventListener("click",function(){
  console.log(2);
},false)

// 点击的时候会打印 1 2，因为多个同样的事件不会覆盖
```

但是有一种情况比较特殊：

```js
var oDiv = document.getElementsByTagName("div")[0];
oDiv.addEventListener("click", test, false);
oDiv.addEventListener("click", test, false);

function test() {
  console.log(1);
}
```

这样的情况下两个点击事件绑定的是同一个函数的引用时只会执行一次！！！

4、`IE8`绑定事件的方式

```js
var oDiv = document.getElementsByTagName("div")[0];

oDiv.attachEvent("onclick",function(){
   console.log("1");
})
```

最后来个兼容的写法：

```js
function addEvent(el, type, fn) {
  if (el.addEventListener) {
    el.addEventListener(type, fn, false);
  } else if (el.attachEvent) {
    el.attachEvent("on" + type, function () {
      fn.call(el);
    });
  } else {
    el["on" + type] = fn;
  }
}

var oDiv = document.getElementsByTagName("div")[0];
addEvent(oDiv, "click", function () {
  console.log(1);
})
```

## 解除事件处理函数
某些情况下我们绑定事件处理函数后，需要解除应该怎么解除呢？

`on`事件解除事件处理函数

```js
var oDiv = document.getElementsByTagName("div")[0];
oDiv.onclick = function(){}

oDiv.onclick = null;
```

`addEventListener`解除事件处理函数

需要注意的是`removeEventListener`的第一、三个参数必须和`addEventListener`是一样的，第二个参数表示函数的引用，指向同一个函数引用即可解除。

```js
var oDiv = document.getElementsByTagName("div")[0];
function test(){
  console.log(1)
}

oDiv.addEventListener("click", test, false);
oDiv.removeEventListener("click", test, false);
```

```js
var oDiv = document.getElementsByTagName("div")[0];

// 利用 arguments.callee 来指向同一个函数引用
oDiv.addEventListener("click", function(){
  console.log(1)
  oDiv.removeEventListener("click", arguments.callee, false);
}, false);

```

解除`IE8`中`attachEvent`事件处理函数

```js
var oDiv = document.getElementsByTagName("div")[0];
function test(){}

oDiv.attachEvent("onclick", test);
oDiv.detachEvent("onClick", test)
```

## 事件处理函数中的 this

在事件绑定处理函数中，普通的`on`事件和`addEventListener`中的`this`都指向元素本身，而`IE8`中的`attachEvent`指向`window`

<br/>

```js
var oDiv = document.getElementsByTagName("div")[0];

oDiv.onclick = function(){
  console.log(this); // <div></div>
}

// ==========

oDiv.addEventListener("click",function(){
  console.log(this); // <div></div>
},false)

// ==========

oDiv.attachEvent("onclick",function(){
  console.log(this); // window
})
```

## 事件冒泡
先来看下案例的`DOM`结构：

```html
<!-- 其他内容忽略 -->
<style>
  .wrapper {
    width: 300px;
    height: 300px;
    background-color: green;
  }
  .outer {
    width: 200px;
    height: 200px;
    background-color: red;
  }
  .inner {
    width: 100px;
    height: 100px;
    background-color: orange;
  }
</style>

<!-- 其他内容忽略 -->
<body>
  <div class="wrapper">
    <div class="outer">
      <div class="inner"></div>
    </div>
  </div>
</body>
```

```js
var outer = document.getElementsByClassName("outer")[0];

  console.log("outer");
},false);

  console.log("inner");

```

可以看到当我点击黄色`div`的时候红色、绿色的`div`点击事件也被触发了，当我点击红色`div`的时候绿色的`div`点击事件也被触发了。

像这样的事件一层一层的向上触发我们就叫做「事件冒泡」。

点击子元素的时候向上冒泡，这个事件要向上传递，直到传递到顶层的父元素停止！！！

事件冒泡一般发生在`DOM`是嵌套关系的事件中！！！

`focus`、`blur`、`change`、`submit`、`reset`、`select`这些事件都不会冒泡！！！

## 事件捕获
那什么又是事件捕获呢？

「事件捕获」和事件冒泡刚好相反，「事件捕获」是从父元素的事件向下传递，一直到最后的子元素停止，这样的现象我们叫做「事件捕获」。

<br/>

当我们使用`addEventListener`的时候将第三个参数更改为`true`即表示「事件捕获」，而默认的`false`表示「事件冒泡」。

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/02%20JavaScript/03%20WebAPI/00%20DOM%20%E5%9F%BA%E7%A1%80/_assets/1653633830409-85f16b3b-cf76-479d-bfbb-cf3cbbf8b9dc.png)

```js
var wrapper = document.getElementsByClassName("wrapper")[0];
var outer = document.getElementsByClassName("outer")[0];
var inner = document.getElementsByClassName("inner")[0];

wrapper.addEventListener("click", function () {
  console.log("wrapper");
},true);
outer.addEventListener("click", function () {
  console.log("outer");
},true);
inner.addEventListener("click", function () {
  console.log("inner");
},true);
```

## 事件流的过程
事件捕获和事件冒泡的执行过程时，事件捕获先比事件冒泡执行。

```js
var wrapper = document.getElementsByClassName("wrapper")[0];
var outer = document.getElementsByClassName("outer")[0];
var inner = document.getElementsByClassName("inner")[0];

wrapper.addEventListener("click", function () {
  console.log("wrapper 1");
},true);
outer.addEventListener("click", function () {
  console.log("outer 2");
},true);
inner.addEventListener("click", function () {
  console.log("inner 3");
},true);
inner.addEventListener("click", function () {
  console.log("inner 4");
},false);
outer.addEventListener("click", function () {
  console.log("outer 5");
},false);
wrapper.addEventListener("click", function () {
  console.log("wrapper 6");
},false);
```

![点击黄色的 div](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/02%20JavaScript/03%20WebAPI/00%20DOM%20%E5%9F%BA%E7%A1%80/_assets/1653634327815-9071b7c6-86c1-417b-aa7f-de9968321f78.png)

在`DOM`事件流中，实际的目标（`<div>`元素）在捕获阶段不会接收到事件。这是因为捕获阶段从`document`到`<html>`再到`<body>`就结束了。下一阶段，即会在` <div>`元素上触发事件的“到达目标” 阶段，<u>通常在事件处理时被认为是冒泡阶段的一部分。</u>然后，冒泡阶段开始，事件反向传播至文档。

## 阻止事件冒泡
如何阻止事件冒泡？事件处理函数中有个`event`事件对象参数，该对象是事件发生时的一些信息，该对象有个`stopPropagation()`方法可以阻止事件冒泡。

`IE8`的`event`事件对象存在于`window`上而非事件处理函数中，所以要考虑兼容。

```js
inner.addEventListener("click", function (event) {
  // 兼容IE8
  var e = event || window.event;
  e.stopPropagation();

  console.log("bubbleInner");
}, false);
```

这样就可以阻止事件冒泡！！！

`IE8`还可以利用`event.cancelBubble`属性来阻止冒泡。

```js
inner.addEventListener("click", function (event) {
  // 兼容IE8
  var e = event || window.event;
  e.cancelBubble = true;

  console.log("bubbleInner");
}, false);
```

## 阻止默认事件
浏览器的默认事件有很多种，例如鼠标右键显示菜单等等

取消默认事件有两种方式：

1、函数返回`false`

```js
document.oncontextmenu = function(){
  console.log(1)
  return false
}
```

但是这样的方式无法在`addEventListener`上使用！！！

2、`W3C`规范的`event.preventDefault()`

```js
document.addEventListener("contextmenu",function(event){
  var event= event || window.event
  event.preventDefault()
},false)
```

3、`IE8`以下使用`event.returnValue`

```js
document.addEventListener("contextmenu",function(event){
  var event= event || window.event
  event.returnValue = false
},false)
```
