## 🔢 input

当输入框输入内容就会触发该事件。

 ❌  `input`事件出自`HTML5`的规范，但是`IE8`及以下不支持！！！

<br/>

```js
var oInput = document.getElementById("content");
oInput.oninput = function () {
  console.log(this.value);
};
```

`IE8`需要用`onpropertychange`事件来代替`input`事件：

```js
oInput.onpropertychange = function () {
  console.log(this.value);
};
```

## 🔢 change

表单改变值的时候触发，对于`input`输入框来说，`change`事件会在文本框失去焦点的时候触发，而`input`事件是在输入的过程中实时触发。

当文本框聚焦和失焦的时候值没有变化不会触发`change`事件。

<br/>

```js
var oInput = document.getElementById("content");
oInput.onchange = function () {
  console.log(this.value);
};
```

## 🔢 focus

当文本框获得焦点时触发该事件。

<br/>

```js
var oInput = document.getElementById("content");
oInput.onfocus = function () {
  console.log(this.value);
};
```

## 🔢 blur

当文本框失去焦点时触发该事件。

<br/>

```js
var oInput = document.getElementById("content");
oInput.onblur = function () {
  console.log(this.value);
};
```
