## deviceorientation 事件
`deviceorientation`事件会在设备方向变化的时候进行触发。

<br/>warning
⚠️ 注意

该事件不可取消也不会冒泡。

<br/>

```js
if (window.DeviceOrientationEvent) {
  window.addEventListener('deviceorientation', function (event) {
    document.getElementById('root').innerHTML =
      'alpha: ' + event.alpha + '<br>' +
      'beta: ' + event.beta + '<br>' +
      'gamma: ' + event.gamma;
  });
} else {
  alert('你的浏览器不支持DeviceOrientation');
}
```

该事件主要有以下三个值：

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/02%20JavaScript/03%20WebAPI/00%20DOM%20%E5%9F%BA%E7%A1%80/_assets/1718260951395-76eed34a-2cf5-47a7-8f48-23f7908ad3d1.png)

- `event.alpha`：设备绕 Z 轴（从顶部到底部）的旋转角度，以度为单位，范围是 0 到 360 度。
- `event.beta`：设备绕 X 轴（从左到右）的旋转角度，以度为单位，范围是 -180 到 180 度。
- `event.gamma`：设备绕 Y 轴（从前到后的旋转角度，以度为单位，范围是 -90 到 90 度。
- `event.absolute`：一个布尔值，表示设备方向是否是相对于地球坐标系。

## deviceorientation 事件
`deviceorientation`事件主要应用在移动端，如果可以获取设备的加速度信息，而且数据发生了变化，这个事件就会在`window`上触发。

`deviceorientation`事件只反映设备在空间中的朝向，而不涉及移动相关的信息。

<br/>warning
⚠️ 注意

该事件不可取消，也不会冒泡。

<br/>

![主要存在 3 个方向](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/02%20JavaScript/03%20WebAPI/00%20DOM%20%E5%9F%BA%E7%A1%80/_assets/1668570630021-7d0fb43f-5681-47b3-83d5-091093c17d0d.png)

```js
if (window.DeviceMotionEvent) {
  window.addEventListener('devicemotion', function(event) {
    console.log(evnet);
  });
} else {
  document.getElementById('output').textContent = 'Device Motion not supported.';
}
```

该事件主要的属性：

- `event.acceleration`：给出设备在 x、y、z 三轴上的加速度。加速度用 m/s² 表示。
- `event.accelerationIncludingGravity`：在重力作用下，给出设备在 x、y、z 三个轴上的加速度的对象。加速度单位为 m/s²。
- `event.rotationRate`：一个给出设备绕三个方向轴（阿尔法轴、贝塔轴和伽马轴）的旋转速率的对象。旋转速率以度每秒表示。
- `event.interval`：代表从设备获取数据的时间间隔（毫秒）的数字。

## onvisibilitychange 事件
`Web`开发中一个常见的问题是开发者不知道用户什么时候真正在使用页面。如果页面被最小化或隐藏在其他标签页后面，那么轮询服务器或更新动画等功能可能就没有必要了。

这个`API`本身非常简单，由 3 部分构成。

- `document.visibilityState`可见状态：
    - `visible`此时页面内容至少是部分可见。即此页面在前景标签页中，并且窗口没有最小化。
    - `hidden`此时页面对用户不可见。即文档处于背景标签页或者窗口处于最小化状态，或者操作系统正处于 '锁屏状态' .
    - `prerender`页面此时正在渲染中，因此是不可见的 (`considered hidden for purposes of document.hidden`)。文档只能从此状态开始，永远不能从其他值变为此状态。注意：浏览器支持是可选的。
- `visibilitychange`事件，该事件会在文档从隐藏变可见（或反之）时触发。 
- `document.hidden`布尔值，表示页面是否隐藏。这可能意味着页面在后台标签页或浏览器中被最小化了。这个值是为了向后兼容才继续被浏览器支持的，应该优先使用`document.visibilityState`检测页面可见性。

<br/>

```js
document.addEventListener("visibilitychange", () => {
  console.log(document.visibilityState);
});
```

## contextmenu 事件

`contextmenu`事件专门用于表示何时该显示上下文菜单，从而允许开发者取消默认的上下文菜单并提供自定义菜单。

<br/>

`contextmenu`会产生事件冒泡，因此只要给`document`指定一个事件处理程序就可以处理页面上的所有同类事件。

`contextmenu`事件应该算一种鼠标事件，因此`event`对象上的很多属性都与光标位置有关。通常，自定义的上下文菜单都是通过`oncontextmenu`事件处理程序触发显示，并通过`onclick`事件处理程序触发隐藏的。

```html
<!DOCTYPE html>
<html>
  <head>
    <title>ContextMenu Event Example</title>
  </head>
  <body>
    <div id="myDiv">
      Right click or Ctrl+click me to get a custom context menu.
      Click anywhere else to get the default context menu.
    </div>
    <ul id="myMenu" style="position:absolute; visibility:hidden; background-color:silver">
      <li><a href="http://www.somewhere.com">somewhere</a></li>
      <li><a href="http://www.wrox.com">Wrox site</a></li>
      <li><a href="http://www.somewhere-else.com">somewhere-else</a></li>
    </ul>
  </body>
</html>
```

```js
window.addEventListener("load", (event) => {
  let div = document.getElementById("myDiv");

  div.addEventListener("contextmenu", (event) => {
    // 取消默认事件
    event.preventDefault();

    let menu = document.getElementById("myMenu");
    menu.style.left = event.clientX + "px";
    menu.style.top = event.clientY + "px";
    menu.style.visibility = "visible";

  });

  document.addEventListener("click", (event) => {
    document.getElementById("myMenu").style.visibility = "hidden";
  });
});
```

## beforeunload 事件
`beforeunload`事件会在`window`上触发，用意是给开发者提供阻止页面被卸载的机会。

这个事件会在页面即将从浏览器中卸载时触发，如果页面需要继续使用，则可以不被卸载，可用于弹出对话框，提示用户是继续浏览页面还是离开当前页面。

这个事件不能取消，否则就意味着可以把用户永久阻拦在一个页面上。

```js
window.addEventListener("beforeunload", function (event) {
  event.returnValue = "我在这写点东西...";
});
```

## DOMContentLoaded 事件
`window`的`load`事件会在页面完全加载后触发，因为要等待很多外部资源加载完成，所以会花费较长时间。

而`DOMContentLoaded`事件会在`DOM`树构建完成后立即触发，而不用等待图片、`JavaScript`文件、`CSS`文件或其他资源加载完成。

要处理`DOMContentLoaded`事件，需要给`document`或`window`添加事件处理程序（实际的事件目标是`document`，但会冒泡到`window`）。

`DOMContentLoaded`事件通常用于添加事件处理程序或执行其他`DOM`操作。这个事件始终在`load`事件之前触发。

具体请看：

[时间线、解析与渲染](https://www.yuque.com/xiechen/ipqq3d/xsdu45)

```js
document.addEventListener("DOMContentLoaded", (event) => {
  console.log("Content loaded");
});
```
