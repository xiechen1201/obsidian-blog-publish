我们在之前写的函数声明在全局环境下是不会被释放的，始终存在于`GO`中，可以随时随地的调用。

```js
// 每次页面加载求数据的和，都需要调用一次。
add(1, 2);
function add(a, b) {
  console.log(a + b);
}
```

那么有没有一种函数是可以自己执行且执行完成会立即被释放的函数呢？

## 立即执行函数初识
「立即执行函数」`IIFE(immediaely invoked function expression)`

立即执行函数的特点就是：不需要手动调用自动立即执行，执行完成后立即销毁

```js
// 写法一
(function(){
  // 执行内容
})()

// 写法二，W3C 推荐的写法
(function(){
  // 执行内容
}())
```

以上两种写的区别只是`()`在`()`里外的区别！！！而多数开发人员的习惯倾向于第一种写法。

立即执行函数传参：

```js
(function(a,b){
  console.log(a+b); // 3
})(1,2)
```

立即执行函数返回值：

```js
var num = (function(a,b){
            return a+b;
          })(1,2)
console.log(num); // 3
```

立即执行函数会忽略函数名：

```js
(function test() {
  var a = 2;
  var b = 2;
  console.log(a + b);
})();
console.log(test); // error
```

以上代码在立即执行函数执行后打印函数名会提示报错，这也进一步说明了立即执行函数执行完会释放的定论。

## 立即执行函数 & 表达式
函数只有是表达式的时候才能被执行符号`()`执行。

用`()`包裹起来的函数就是函数表达式！！！

<br/>

```js
function test1(){}();  // 不会执行且报错
var test2 = function(){}(); // 执行，因为这个本来就是函数表达式声明
(function test3(){})(); // 执行
```

立即执行函数执行且销毁：

```js
var test  = function(){}();
console.log(test); // undefind，test 函数被销毁
```

函数表达式的函数名会被忽略：

```js
(function test() {
  console.log(123);
})();
console.log(test); // error
```

这里又可以插入一道面试题了🛋 ：

```js
// 请问 a 打印什么？
var a = 10;
if (function b() {}) {
  a += typeof b;
}
console.log(a);

/**
* 答案是 10undeind
* 因为在 if 判断中JS引擎将 (function b(){}) 立即为函数表达式
* 函数表达式是忽略函数名的
* 所以 typeof b 返回 undefind
* 结果是 10undefind
*/
```

使用`+、-、!、&&、||`都能将函数声明转换成函数表达式：

```js
+function test(){
    console.log(1); // 1
}()

||function test(){
    console.log(1); // 1
}()
```

下面插入一道面试题 🌴 ：

```js
// 以下代码能正常执行吗？
function test(a,b) {
  console.log(a,b)
}(6,7);

// 其实是完全可以的，但是不会执行 test 函数
// 当函数声明直接使用()进行执行的时候，这样函数会被认为是一个立即执行函数，这样会直接显示语法错误
// 但是这里的(6,7)是会被解释成逗号运算符的，JS引擎会将以上代码解释为
function test(){};
(6,5);
```

## 逗号运算符
逗号运算符永远返回`()`中`,`的最后一项数据。

```js
console.log((1,2)); // 2
console.log((2 - 1, 6 + 5, 24 + 1)); // 25
```

结合立即执行函数在看一道面试题🔑 ：

```js
// 问打印什么？
var fn =
  (function test1() {
    return 1;
  },
  function test2() {
    return 2;
  })();
console.log(typeof fn); // number

/**
* 打印 number
* 因为逗号运算符返回()中最后一个数据，也就是 test2
* (function test2(){})() 形成了立即执行函数，返回 2
* 所以打印 number
*/
```

## 立即执行函数 & 闭包问题
闭包的问题就是函数内部的变量可以被外部操作，这里有道经典的闭包面试题可以配合立即执行函数来解题：

```js
// 请问 document.write 会输出什么？？？
function test() {
  var arr = [];
  for (var i = 0; i < 10; i++) {
    arr[i] = function () {
      document.write(i + " ");
    };
  }
  return arr;
}
var myArr = test();

for (var index = 0; index < myArr.length; index++) {
  myArr[index]();
}

/**
* 答案是 10 10 10 10 10 10 10 10 10 10
* 那为什么是 10 个 10 呢？这就是因为闭包导致的，我们将 test 函数进行分解
* 首先在 for 循环中保存了 10 个 function, 但是这 10 个 function 并没有执行，而是在外面的 myArr 执行，这样就形成了闭包
* 当 myArr 执行每一个函数的时候，每个函数在回头去找 test 中的 i，此时的 i 已经变成了 10，所以 打印出 10 个 10

将 for 循环进行拆分
var i = 0;
for(; i < 10; ){
  arr[i] = function () {
             查找 i ,发现 i 已经变成了 10
             document.write(i + " ");
           };
  i++
}

*/

// 如何解决呢？
// 我们可以用立即执行函数形成一个独立的函数
// 这样就可以解决了
function test() {
  var arr = [];
  for (var i = 0; i < 10; i++) {
    // 保存一个独立的作用域
    (function (j) {
      arr[j] = function () {
        // 打印的是立即执行函数的参数
        document.write(j + " ");
      };
    })(i);
  }
  return arr;
}
var myArr = test();

for (var index = 0; index < myArr.length; index++) {
  myArr[index]();
}
```
