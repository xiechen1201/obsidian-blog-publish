## name 属性
函数的`name`属性可以返回函数的名称。

```js
function foo() {}
foo.name // "foo"
```

这个属性早就被浏览器广泛支持，但是直到 ES6，才将其写入了标准。ES6 对这个属性的行为做出了一些修改。

如果将一个匿名函数赋值给一个变量，ES5 的`name`属性，会返回空字符串，而 ES6 的`name`属性会返回实际的函数名。

```js
var f = function () {};

// ES5
f.name // ""

// ES6
f.name // "f"
```

如果将一个具名函数赋值给一个变量，则 ES5 和 ES6 的`name`属性都返回这个具名函数原本的名字。

```js
const bar = function baz() {};

// ES5
bar.name // "baz"

// ES6
bar.name // "baz"
```

`Function`构造函数返回的函数实例，`name`属性的值为`anonymous`。

```js
(new Function).name // "anonymous"
```

`bind`返回的函数，`name`属性值会加上`bound`前缀。

```js
function foo() {};

console.log(foo.bind({}).name); // bound foo
// call 相当于函数执行后没有返回值，所以报错
console.log(foo.call({}).name); // ❌Cannot read properties of undefined (reading 'name')
```

## 参数的默认值
ES5 的时候如果要给函数设置一个默认值：

```js
function sum(a, b, c) {
  a = a || 0;
  b = b || 0;
  c = c || 0;
  return a + b + c;
}
var result = sum(1, undefined, 3);
console.log(result);
```

ES6 中的默认值，在书写形参的时候直接给形参赋值默认值即可：

```js
function sum(a = 0, b = 0, c = 0) {
    return a + b + c;
}
var result = sum(1, undefined, 3);
console.log(result);
```

这样一来，调用函数的时候如果没有给对应的参数赋值，则会自动使用默认值！

例如下面的的案例，给函数的参数赋值一个默认的 DOM 元素：

```js
/**
 * @param {*} name 元素的名称
 * @param {*} container 元素的父元素
 * @param {*} content 元素的内容
 */
function createElement(
  name = 'div',
  container = document.getElementById('container'),
  content = ''
) {
  let el = document.createElement(name);
  if (content) {
    el.innerHTML = content;
  }
  container.appendChild(el);
}
createElement('div', document.getElementById('container'), 'hello world');
createElement('button', undefined, 'this is button element');
```

## > 对 arguments 的影响
函数的默认值会对`arguments`产生影响。

正常情况下：

```js
function test(a, b) {
  console.log('arguments:', arguments); // [1, 2]
  console.log('a & b:', a, b); // 1 2

  // 更改 a 的值
  a = 3;

  // 形参和 arguments 都会发生变化！
  console.log('arguments:', arguments); // [3, 2]
  console.log('a & b:', a, b); // 3 2
}
test(1, 2);
```

如果给函数添加了默认值，那么该函数会自动采用严格模式下的规则，让`arguments`和形参脱离：

```js
function test(a = '一', b = "二") {
  console.log('arguments:', arguments); // [1, 2]
  console.log('a & b:', a, b); // 1 2

  a = 3;

  console.log('arguments:', arguments); // [1, 2]
  console.log('a & b:', a, b); // 3 2
}
test(1, 2);
```

## > 暂时性死区
函数的形参和 ES6 中的`let`、`const`一样具有作用域，并且根据参数的声明顺序具有暂时性死区。

```js
// 没有问题，因为 a 已经被声明
function test(a, b = a) {
  console.log(a, b); // 1 1
}
test(1);

// 存在问题，因为 b 还没有被声明
function test2(a = b, b) {
  // ❌Cannot access 'b' before initialization
  console.log(a, b); // 1 1
}
test2(undefined, 2);
```

另外一个问题是函数的形参不能和变量的声明同名，否则会导致重复定义：

```js
function test(a, b = a) {
    let a = 10; // ❌Identifier 'a' has already been declared
}
test(1);
```

## 剩余参数
ES5 的时候如果一个函数接收任意多的参数那么就需要通过`arguments`来进行处理，例如下面的案例中使用参数进行求和并返回：

```js
function sum() {
  let num = 0;
  for (let i = 0; i < arguments.length; i++) {
    num += arguments[i];
  }
  return num;
}
console.log(sum(1, 2, 3));
console.log(sum(1, 2, 3, 4));
console.log(sum(1, 2, 3, 4, 5, 6, 7, 8));
```

虽然可以使用`arguments`来解决这个问题，但是它存在缺陷：

1、如果和形参配合使用，容易导致混乱。

2、从语义上来讲，使用`arguments`获取参数，由于形参的缺失无法从函数定义上理解函数的真正意图，这是最严重的问题。

ES6 提供了「剩余」参数来收集函数末尾的所有参数，并将其放入形参的数组中。

```js
function sum(...args) {
  // args 收集了所有的参数，形成了一个数组
  let num = 0;
  for (let i = 0; i < args.length; i++) {
    num += args[i];
  }
  return num;
}
console.log(sum(1, 2, 3));
console.log(sum(1, 2, 3, 4));
console.log(sum(1, 2, 3, 4, 5, 6, 7, 8));
```

> [!warning]
> 剩余参数使用的细节：
> 1、一个函数只能出现一个剩余参数。
> 2、一个函数如果有剩余参数，则必须书写在形参的最后面。

```js
// 只能有一个剩余参数
// ❌Rest parameter must be last formal parameter
function sum(...args, ...args1){}
```

```js
// 剩余参数必须书写在形参的最后
// ❌Rest parameter must be last formal parameter
function sum1(a, b, ...args, c) {}
```

## 拓展运算符
剩余参数会引发一个问题：

```js
// 获取指定长度的随机数数组
function getRandomNumbers(len) {
  const arr = [];
  for (let i = 0; i < len; i++) {
    arr.push(Math.random());
  }
  return arr;
}

// 求和
function sum(...args) {
  // args [[xxx, xxx, xxx, ...]]
  let num = 0;
  for (let i = 0; i < args.length; i++) {
    num += args[i];
  }
  return num;
}

let nums = getRandomNumbers(10);
// 传递的实参和形参参数了冲突
let all = sum(nums);

console.log(nums);
console.log(all);
```

以上代码，我们通过`getRandomNumbers(10)`获取到了一个长度为 10 的随机数数组，然后想通过`sum()`方法让这 10 个随机数进行相加，但是`sum()`方法接收一个按序的参数，并不是数组。

我们如何将这个数组进行展开呢？将数组的每一项进行展开，依次作为参数传递给`sum()`方法，而不是将整个数组作为参数进行传递。

在 ES5 的时候我们可以使用`Funtion.prototype.apply`来进行按序传递参数：

```js
...
let nums = getRandomNumbers(10);
let all = sum.apply(this, nums);
```

ES6 可以通过更加简便的「拓展运算符」进行讲数组进行展开：

```js
let nums = getRandomNumbers(10);
// 对 nums 数组进行展开，相当于传递了 10 个参数
let all = sum(...nums);
// 还可以继续传递其他的参数
let all2 = sum(...nums, 10, 20, 30);
```

使用拓展运算符可以对数组进行复制：

```js
const arr1 = [3, 5, 6, 7, 8];
const arr2 = [...arr1];
```

使用拓展运算符复制的数组和原数组不是用一个对内存地址，而是一个独立的新数组！

拓展运算符也可以用来展开一个对象，同样可以实现复制的目的：

```js
let obj1 = {
  name: 'zs',
  age: 18,
  sex: '男'
};

let obj2 = {
  ...obj1
};

// 修改 obj2 的属性，不会影响 obj1 的属性
obj2.name = 'ls';

console.log(obj1); // {name: 'zs', age: 18, sex: '男'}
```

使用拓展运算符将对象的属性进行展开会把前面的属性进行覆盖：

```js
// 可以覆盖之前的属性
let obj1 = {
  name: 'zs',
  age: 18,
  sex: '男'
};

let obj2 = {
  ...obj1,
  name: 'ls'
};
console.log(obj2); // {name: 'ls', age: 18, sex: '男'}
```

> [!warning]
> 使用拓展运算符复制的数组/对象是一种浅拷贝！

```js
let obj1 = {
  name: 'zs',
  age: 18,
  sex: '男',
  hobby: ['篮球', '足球', '乒乓球']
};

let obj2 = {
  ...obj1
};
obj2.hobby.push('台球');

console.log(obj1);
console.log(obj2);
console.log(obj1.hobby === obj2.hobby); // true
```

## 明确函数的双重用途
因为函数可以进行实例化调用，也可以进行普通调用，这就很容易造成混乱。

```js
function Person(name, age) {
  this.name = name;
  this.age = age;
  this.info = `他的名字是${name}, 年龄是${age}`;
}

let p1 = new Person('张三', 22);
let p2 = Person('李四', 23);
console.log(p1, p2, window.info);
```

如何进行判断调用函数的时候是不是使用`new`进行调用的呢？

在 ES6 之前可以使用`instanceof`来判断是不是属于构造函数的实例。

```js
function Person(name, age) {
  if (!(this instanceof Person)) {
    throw new Error('必须使用 new 来进行调用');
  }
  this.name = name;
  this.age = age;
  this.info = `他的名字是${name}, 年龄是${age}`;
}

let p1 = new Person('张三', 22);
// 绕开判断的限制
Person.call(new Person(), '李四', 23)
let p2 = Person('李四', 23);
console.log(p1, p2, window.info);
```

但是这样的方式可以通过`Function.prototype.call()`的方式绕过这种判断的限制。

ES6 提供了一个特殊的 API `new.target`，可以使用这个 API 在函数内部判断该函数是否使用了`new`进行调用。

在调用函数的时候如果没有使用`new`来调用函数，那么`new.target`则返回的是`undefinde`，如果使用`new`来调用函数则返回的是该函数。

```js
function Person(name, age) {
  console.log(new.target);

  if (new.target === undefined) {
    throw new Error('必须使用 new 来进行调用');
  }

  this.name = name;
  this.age = age;
  this.info = `他的名字是${name}, 年龄是${age}`;
}

let p1 = new Person('张三', 22); // ƒ Person(name, age)
let p2 = Person('李四', 23); // ❌必须使用 new 来进行调用
let p3 = Person.call(); // undefined

console.log(p1, p2, window.info);
```

## 箭头函数
ES5 中`this`的指向取决于函数的调用方式：

1、直接调用函数`this`指向全局对象。

2、通过对象调用函数`this`指向该对象。

3、通过`new`调用函数`this`只想新创建的实例对象。

4、通过`call()`、`apply()`、`bind()`调用函数，`this`指向指定的对象。

5、`DOM`事件中的`this`指向事件源。

需要注意的是`setInterval()`中的`this`也是指向全局对象`window`的：

```js
var obj = {
  count: 0,
  start: function () {
    setInterval(function () {
      // 这里的 this 指向全局对象 window
      // 因为这里的 function 是在底层直接调用的
      this.count++;
      console.log(this.count); // NaN
    }, 1000);
  }
};
obj.start();
```

ES6 提供了箭头函数，箭头函数是一个函数表达式，理论上任何函数表达式的情况下都可以使用箭头函数。

完整的写法：

```js
(参数1, 参数2) => { 函数体 }
```

例如把上面`setInterval()`的参数改为箭头函数：

```js
var obj = {
  count: 0,
  start: function () {
    setInterval(() => {
      // this 的指向变正确了
      this.count++;
      console.log(this.count); // 1 2 3 4 5 ...
    }, 1000);
  }
};
obj.start();
```

这个时候发现`setInterval()`内部尽然可以正确的访问到`obj`对象了！

## > this 指向
这是因为箭头函数的`this`指向和普通函数的`this`指向不一样，箭头函数的`this`指向取决于函数定义的位置的`this`指向，和如何调用无关。

根据上面的案例，可以理解为这样：

```js
setInterval(this, 1000);
```

同样的看下面的这个案例：

```js
var obj = {
  count: 0,
  print: () => {
    console.log(this.count);
  }
};
obj.print(); // undefined
```

`obj.print()`执行的时候得到的却是`undefined`!

可以利用上面`setInterval`拆分的方式，把`obj.print()`进行拆分：

```js
var obj = {
  count: 0,
  print: this // 这里的this指向的是 window
};
```

还是那句话，箭头函数的`this`指向的是定义时候的`this`，`this`书写在函数外部的时候，`this`指向的是`window`对象。

## > 简写
当书写箭头函数的时候，如果函数的参数只有一个，那么是可以省略小括号的。如果函数没有参数或者具有多个参数，那么是不能省略小括号的。

```js
const print = num => {
    console.log(num);
};
print(100);
```

如果函数体只有一句表达式，那么是可以省略花括号的，并且可以省略`return`关键字。

```js
参数 => 返回值
```

```js
const print = num => num % 2 !== 0;
console.log(print(100)); // false
console.log(print(99)); // true
```

如果函数内需要返回的是一个对象，则必须使用`()`进行包裹。

```js
参数 => ({ 返回值 })
```

```js
const sum = (num1, num2) => ({
  sum: num1 + num2,
  sub: num1 - num2
});
```

## > 箭头函数没有 arguments
箭头函数是没有自己的`this`、`arguments`、`new.target`的，如果使用了这三个对象则实际使用的是箭头函数外层的`this`、`arguments`、`new.target`。

```js
const func = () => console.log(this); // window
func();

const obj = {
  method: func
};
// 因为箭头函数没有 this
obj.method(); // window
```

```js
const obj = {
  method: function () {
    const func = () => {
      // 使用的是 method 方法中的 this
      console.log(this); // obj
      // 使用的是 method 方法中的 arguments
      console.log(arguments); // [100]
    };
    func()
  }
};
obj.method(100);
```

## > 箭头函数没有原型
箭头函数没有原型，所以不能当作构造函数进行实例化。

```js
const func = () => {};
console.log(func.prototype); // undefined
console.dir(func);

new func(); // ❌func is not a constructor
```

## > 箭头函数的使用场景
1、临时性使用的函数，并不会进行刻意的调用。

```js
// 例如事件处理函数
dom.addEventListener('click', () => {})

// 例如异步处理函数
setInterval(() => {}, 1000)
```

2、为了绑定外层`this`的情况下。

3、在不影响其他代码的情况下，保持代码的简洁。

```js
// 例如数组方法中的回调函数
[1, 2, 3].map(el => el * 2);
```
