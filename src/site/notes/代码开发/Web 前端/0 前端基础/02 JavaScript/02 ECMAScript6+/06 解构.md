什么是解构？

解构是 ES6 新增的一种语法规则，可以将一个对象或者数组的某个属性提取到某个变量中，解构不会对被解构的对象或者数组产生任何的影响。

## 🔢 对象解构
在 ES5 中我们想要提取对象中的属性通常使用如下的方式：

```js
var user = {
  name: 'zhangsan',
  age: 18,
  sex: '男',
  address: {
    province: '河北',
    city: '石家庄'
  }
};

// 书写起来比较的麻烦
let name, age, sex, address;
name = user.name;
age = user.age;
sex = user.sex;
address = user.address;
```

使用属性的时候需要一个一个的进行声明然后赋值，显得很麻烦。

使用 ES6 的解构可以快速的进行简写：

```js
const user = {
  name: 'zhangsan',
  age: 18,
  gender: '男',
  address: {
    province: '河北',
    city: '石家庄'
  }
};

let name, age, gender, address;
// 整个赋值语句视为一个整体
// 理解为把 user 对象的 name, age... 属性读取出来，放到同名变量中 name, age... 中去
({ name, age, gender, address } = user);
```

声明变量和解构语句还可以进行简写为一句：

```js
let { name, age, gender, address } = user;
```

## 🔢 > 解构默认值
如果解构一个不存在的属性，那么变量就会赋值为`undefined`:

```js
// user 对象中不存在 abc 属性
let { abc } = user;
console.log(abc); // undefined
```

针对上面的这种情况，当解构一个不存在的属性时可以给变量设置一个默认值：

```js
// user 对象中不存在 abc 属性
let { abc = '默认值' } = user;
console.log(abc); // 默认值
```

<br/>warning
⚠️ 注意

当一个值为`null`的时候，无法赋值默认值，因为`null`是一个有效的值！

<br/>

```js
const user = { name: undefined, age: null }
const { name = 'defaultName', age = 20 } = user
console.log(name, age); // defaultName null
```

## 🔢 > 非同名属性解构
解构赋值还可以进行非同名属性解构（也可以理解为重命名），如果解构的属性和声明变量名不一致，那么是可以进行重命名的：

```js
let { name: userName, age } = user;
console.log(userName, age); // zhangsan 18
```

<br/>warning
⚠️ 注意

上面的代码中，是先定义了两个变量`userName`和`age`，再从`user`对象中读取同名属性赋值，其中`userName`读取的是`name`属性！

<br/>

默认值和重命名可以进行组合：

```js
let { abc: efg = 123 } = user;
console.log(efg); // 123
```

上面的代码意为定义了一个`efg`的属性，然后从`user`对象中解构`abc`属性，如果没有`abc`属性则赋值为 123 的默认值。

## 🔢 > 深层解构
如果想要解构的是`user.address`属性中的其他属性，那么就可以使用深层解构。

```js
let {
  name,
  address: { city }
} = user;
```

<br/>warning
⚠️ 注意

`address: { city }`中的`:`不在表示重命名，而是表示对`address`属性进行解构，并且后续也无法使用`address`属性！

<br/>

```js
console.log(city); // 石家庄
console.log(address); // ❌Error
```

## 🔢 > 剩余项解构
解构赋值可以结合剩余参数结合使用：

```js
const user = {
  name: 'zhangsan',
  age: 18,
  gender: '男',
  address: {
    province: '河北',
    city: '石家庄'
  }
};

const { name, ...obj } = user;
console.log(name, obj); // zhangsan { age: 18, gender: '男', address: { province: '河北', city: '石家庄' } }
```

以上代码中表示从`user`对象中解构出`name`属性，然后把剩余的属性全部解构到`obj`属性上。

## 🔢 数组解构
数组本质上还是一个对象。

```js
let arr = [10, 20, 30];
// 实际上相当于
let obj = {
  0: 10,
  1: 20,
  2: 30
};

console.log(arr[0]); // 输出 10
console.log(obj["0"]); // 输出 10
```

所以解构数组可以按照解构对象一样的形式：

```js
const arrs = ['a', 'b', 'c', 'd'];
const { 0: n1, '1': n2 } = arrs;
console.log(n1, n2); // 'a' 'b'
```

ES6 对数组提供了更加简便的方式：

```js
let n1, n2;
[n1, n2] = arrs;
console.log(n1, n2); // 'a' 'b'
```

针对数组的解构是根据数组的下标进行解构的。

声明变量和解构合并为一句：

```js
const [n1, n2] = arrs;
console.log(n1, n2); // 'a' 'b'
```

当解构数组的时候，如果值为`undefind`那么是会使用默认值的，其他类型的`false`值都将被正常获取：

```js
let [a, b = 2, c = 3, d = 4] = [1, undefined, null, false];
console.log(a, b, c, d); // 1 2 null false
```

解构赋值也存在暂时性死区：

```js
// 在定义 y 之前无法访问 y
let [x = y, y = 1] = []; // Cannot access 'y' before initialization
console.log(x, y);

// 在 x 之后访问 x 这样是容许的
let [x = 1, y = x] = [];
console.log(x, y); // 1 1
```

## 🔢 > 解构默认值
当对数组进行解构的时候，可以跳过数组项只解构想要的下标项：

```js
// 只解构第一项和最后一项
let [n1, , , n4] = arrs;
console.log(n1, n4); // a d
```

数组解构也可以设置默认值：

```js
let [n1, , , n4, n5, n6 = '默认值'] = arrs;
console.log(n1, n4, n5, n6); // a d undefined 默认值
```

以上代码中，`arrs`的长度为 4，所以解构的时候`n5`和`n6`必定无法解构出数据，但是`n6`设置了一个默认值。

## 🔢 > 深层解构
数组和对象一样也可以进行深层解构：

```js
const arrs = ['a', 'b', 'c', 'd', [1, 2, 3, 4]];

const [n1, n2, n3, n4, [n5, n6, n7, n8]] = arrs;
console.log(n1, n2, n3, n4, n5, n6, n7, n8); // a b c d 1 2 3 4
```

## 🔢 > 剩余项解构
数组也可以进行剩余项的解构：

```js
const arrs = ['a', 'b', 'c', 'd'];
const [n1, ...newArr] = arrs;
console.log(n1, newArr); // a ['b', 'c', 'd']
```

以上代码中表示从`arrs`数组解构出`n1`，然后把其他的项解构到`newArr`属性中。

## 🔢 > 数据交换
利用数组解构是按照下标进行解构这一特点，我们可以快速的实现两个数据的交换：

```js
let a = 1;
let b = 2;
[b, a] = [a, b];

console.log(a, b); // 2 1
```

## 🔢 函数参数的解构
函数参数的解构和对象解构、数组解构的方式一致，只是作为一个函数的参数进行传递。

```js
let user = {
  name: '张三',
  age: 18,
  address: {
    city: '北京',
    detail: '西城区'
  }
};

foo(user);
function foo({ name, age, address: { city } }) {
  console.log(name, age, city);
}
```

如果调用函数的时候没有传递参数，则不能对形参进行解构：

```js
foo();
function foo({ name, age, address: { city } }) { // ❌Error: Cannot destructure property 'name' of 'undefined' or 'null'.
  console.log(name, age, city);
}
```
