## 使用 var 声明变量的问题
1、会出现重复声明，导致数据被覆盖。

```js
var a = 1;
function print() {
  console.log(a);
}

// ...假设这里有 1000 行代码

var a = 2;
print(); // 2
```

因为中间部分的代码太长，我们可能忘记上面声明了变量`a`，导致下面又声明了一次结果就是调用`print()`方法的时候打印的却是 2。

2、变量提升，出现奇怪的数据访问。

```js
if (Math.random() > 0.5) {
  var a = 'abc';
  console.log(a); // abc
} else {
  console.log(a); // abc
}
console.log(a); // abc
```

即使出现随机数大于 0.5 的情况，`else`块中的`a`也不会报错，而是会打印出 abc，这是因为`var`没有块级作用域的概念，`if`块中声明的变量`a`会变成全局的变量。

类似的问题：

```js
var oBox = document.getElementById('box');

for (var i = 0; i < 10; i++) {
  var oBtn = document.createElement('button');
  oBtn.innerText = '按钮' + i;
  oBtn.onclick = function () {
    // 点击全部输出的是9
    console.log(i);
  };

  oBox.appendChild(oBtn);
}
```

这是因为变量`i`不存在块级作用域，以上的代码可以拆分为下面的代码：

```js
var i;
for(i = 0;i < 10; i++){
  ...
}
```

所以，每次点击按钮的时候实际上打印的都是全局的变量`i`。

可以使用立即执行函数来解决这个问题：

```js
var oBox = document.getElementById('box');

for (var i = 0; i < 10; i++) {
  var oBtn = document.createElement('button');
  oBtn.innerText = '按钮' + i;

  // 每次都产生一个独立的函数作用域
  // i 就变成了每个函数作用域的局部变量
  (function (i) {
    oBtn.onclick = function () {
      // 点击全部输出的是9
      console.log(i);
    };
  })(i);

  oBox.appendChild(oBtn);
}
```

3、全局变量会挂载到`window`对象上面，导致全局对象变量的污染。

```js
var abc = '123';
console.log(window.abc); // 123
```

```js
var console = 'abc';
console.log(window.console); // ❌console.log is not a function
```

## 使用 let 声明变量
到了 ES6 的版本中带来了`let`用于声明变量，相比`var`关键字`let`具有以下优点：

1、使用`let`声明的变量不会变成全局变量。

```js
let a = 'abc';
console.log(window.a); // undefined
```

2、使用`let`声明的变量不允许在当前作用域内重复的定义。

```js
let a = 123;
// 检查到当前作用于已经声明了变量 a
let a = 456; // ❌Identifier 'a' has already been declared
```

不同的作用于可以重复声明：

```js
let a = 123;
function foo() {
  let a = 'abc';
  console.log(a); // 输出 'abc'
}
foo();
```

3、块级作用域。

ES6 不仅引入了`let`来解决变量声明的问题，同时引入了块级作用域的概念。

块级作用域：代码执行的时候遇到`{}`花括号会创建一个块级作用域，`{}`花括号结束会销毁块级作用域。

```js
// 全局作用域
let a = 123;
{
  // 块级作用域
  let a = 456;
  // 使用的是块级作用域中的 a，块外部不能访问，如果块内没有变量 a，则查找外部的 a
  console.log(a); // 456
}
```

再用上面`var`定义变量的案例举例：

```js
if (Math.random() < 0.5) {
    // 定义在当前作用域
    let a = 123;
    console.log(a);
} else {
    // 这是另外一个块级作用域
    console.log(a); // ❌a is not defined
}
// 这是全局作用域
console.log(a); // ❌a is not defined
```

4、暂时性死区。

使用`let`定义的变量不会出现变量提升的问题，所以也就不能在定义变量之前进行变量访问。在底层实现上，`let`定义的变量也会进行提升，但是提升后会将改变量放入「暂时性死区」，如果访问的变量位于暂时性死区则会进行报错！

当代码运行到该变量的声明语句时，该变量会从暂时性死区中移除，后续可以正常的进行访问。

```js
console.log(a); // ❌Cannot access 'a' before initialization
let a = 123;
```

使用`let`来解决上面点击按钮的案例：

```js
let oBox = document.getElementById('box');

// 开启 10 个作用域，每次都是一个新的块级作用域
for (let index = 0; index < 10; index++) {
  let oBtn = document.createElement('button');
  oBtn.innerHTML = '按钮' + index;
  oBtn.onclick = function () {
    console.log(index);
  }

  oBox.appendChild(oBtn);
}
```

上面代码中，在循环中使用`let index = 0;`会进行特殊的处理，每次进入循环都会开启一个新的作用域，并且将循环变量绑定到该作用域。

也就说每次循环都会使用一个全新的循环变量，循环变量会在循环结束后进行销毁。

## 使用 const 声明变量
ES6 同时新增了`const`关键字来定义变量，和`let`对比区别比较小，仅在于使用`const`声明的变量必须在声明的时候就进行赋值，且不可以进行更改，一般用来定义常量。

也就说使用`const`定义的值可以保证变量的值不被随意的被更改。

```js
// 必须进行赋值
const a; // ❌Missing initializer in const declaration
```

```js
// 不可以进行更改
const a = 123;
a = 456; // ❌Assignment to constant variable.
```

需要注意的是，常量不可变是指声明常量的内存空间不可变，但是并不能保证内存空间中的地址指向的其他空间不可变。

```js
const person = {
    name: '张三',
    age: 20
};

person.name = '李四'; // 修改成功
person.age = 30; // 修改成功

console.log(person); // { name: '李四', age: 30}

person = {}; // ❌Assignment to constant variable.
```

常量的命名分为以下两种情况：

1、特殊的常量：从字面意义上一定是不可变的，例如圆周率。通常变量的名称全部是大写的，多个单词使用`_`下划线链接。

```js
const PAY_URL = 'https://xxxx.com'
```

2、普通的常量：不确定能否被改变，使用普通的方式命名即可；

```js
const person = { name: "zhansgan", age: 20 };
```
