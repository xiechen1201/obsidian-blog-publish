## 🔢 属性的简洁写法
在 ES5 的时候我们书写一个对象的时候需要使用`:`来间隔 key 和 value：

```js
function createUser(loginId, loginPwd, nickName) {
  // 参数的名称和变量的名称一样，写法没有问题，但是比较啰嗦
  return {
    loginId: loginId,
    loginPwd: loginPwd,
    nickName: nickName,
    id: Math.random()
  };
}
```

ES6 之后如果对象字面量初始化的时候，成员的名称来自于一个变量，且和变量的名称相同的时候，可以进行简写：

```js
function createUser(loginId, loginPwd, nickName) {

  const sayHello = function () {
    console.log('hello');
  }

  // 即表示属性名，也可以进行赋值
  // 只是提供了一个语法糖
  return {
    loginId,
    loginPwd,
    nickName,
    sayHello,
    id: Math.random()
  };
}
```

## 🔢 方法的简洁写法
对象字面量初始化的时候，方法可以省略冒号和`function`关键字。

这也是一种语法糖，本质上没有发生任何的变化。

```js
const user = {
  loginId: 'admin',
  loginPwd: '123456',
  nickName: 'admin',
  sayHello() {
    console.log('hello', this.nickName);
  }
};
user.sayHello();
```

## 🔢 属性名表达式
某些时候初始化对象的时候，某些属性可能来自于某个表达式的值，在 ES6 中可以使用`[]`来表示改属性名使用过计算得到的。

ES5 的时候无法做到属性名来自于一个表达式，一个变量的：

```js
const prop1 = 'loginId';
const prop2 = 'loginPwd';
const prop3 = 'sayHello';

const user = {};
user[prop1] = 'admin';
console.log(user); // {loginId: 'admin'}
```

 ES6 可以直接进行使用:

```js
const prop1 = 'loginId';
const prop2 = 'loginPwd';
const prop3 = 'sayHello';

const user = {
  [prop1]: 'admin',
  [prop2]: '123456',
  nickName: 'admin',
  [prop3]() {
    console.log('hello', this.nickName);
  }
};

console.log(user); // {loginId: 'admin', loginPwd: '123456', nickName: 'admin', sayHello: ƒ}
```

`[]`底层都是通过`toString()`方法进行转换：

```js
var myObject = {};
myObject[true] = "foo";
myObject[3] = "bar";
myObject[myObject] = "baz";

console.log(myObject["true"]); // foo
console.log(myObject["3"]); // bar
console.log(myObject["[object Object]"]); // baz
consoloe.log(Object.prototype.toString.call(myObject)); // [object Object]
```

所以这样的情况会进行覆盖：

```js
const a = { a: 1 };
const b = { b: 2 };

const obj = {
  [a]: "valueA",
  [b]: "valueB",
};

console.log(obj); // {[object Object]: 'valueB'}
```

## 🔢 对象的新增静态方法
## 🔢 > Object.getOwnPropertyNames()
该方法用于遍历对象的 key。

<br/>warning
⚠️ 注意

该方法并不是 ES6 新增的，只是在 ES5 的时候官方没有明确的要求如何对对象的属性进行排序。如何排序完全由浏览器厂商来决定的，ES6 只是规定了该方法数组的排序方式，如下：

1、先排数字再排字母。

2、其他的字母按照书写顺序进行排序。

<br/>

```js
const obj = {
  a: 1,
  b: 2,
  c: 3
};

let names = Object.getOwnPropertyNames(obj);
console.log(names); // ['a', 'b', 'c']
```

```js
const obj = {
  b: 2,
  a: 1,
  c: 3,
  0: 6,
  5: 2,
  4: 1
};
console.log(Object.getOwnPropertyNames(obj)); // ['0', '4', '5', 'b', 'a', 'c']
```

## 🔢 > Object.is(param, param)
在`ES5`的时候值比较的时候有两个`bug`：

1、`NaN`不和任何值相等，包括自己

2、`-0`和`+0`相比返回真值

`Object.is()`方法就是用来比较两个值是否相等。

```js
console.log(Object.is(NaN, NaN)); // true
console.log(Object.is(-0, +0)); // false
console.log(Object.is({}, {})); // false
console.log(Object.is(false, 0)); // false
console.log(Object.is(undefind, null)); // false
```

## 🔢 > Object.assign(target, sources)
该方法用于将多个对象进行合并，返回目标对象。

```js
const obj1 = {
    a: 123,
    b: 345,
    c: 678
};

const obj2 = {
    a: 'abc',
    b: 'efg'
};

// 会把 obj2 的值会覆盖到 obj1 ，并且会对 obj1 产生改动，然后返回 obj1
const obj3 = Object.assign(obj1, obj2);
console.log(obj3, obj1); // { a: 'abc', b: 'efg', c: 678 } {a: 'abc', b: 'efg', c: 678}
console.log(obj3 === obj1); // true
```

进行巧妙的处理，为了避免改动`obj1`对象，可以添加一个空对象`{}`，这样改动的就是`{}`空对象:

```js
const obj4 = Object.assign({}, obj1, obj2);
console.log(obj4);
```

## 🔢 > Object.getOwnPropertyDescriptors(target, prop)
ES5 的`Object.getOwnPropertyDescriptor()`方法会返回某个对象属性的描述对象。

```js
var obj = Object.defineProperty({}, "a", {
  value: 1,
  writable: true,
  configurable: true,
  enumerable: true,
});

console.log(Object.getOwnPropertyDescriptor(obj, "a"));
// {value: 1, writable: true, enumerable: true, configurable: true}
```

ES2017 引入了`Object.getOwnPropertyDescriptors()`方法，返回指定对象{所有自身属性}（非继承属性）的描述对象。

```js
var obj = Object.defineProperties(
  {},
  {
    a: {
      value: 1,
      writable: true,
      configurable: true,
      enumerable: true,
    },
    b: {
      value: 2,
    }
  }
);

console.log(Object.getOwnPropertyDescriptors(obj));
// {value: 1, writable: true, enumerable: true, configurable: true}
// {value: 2, writable: false, enumerable: false, configurable: false}
```

## 🔢 > Object.setprototypeOf(target, proto)
在 ES5 中可以通过`Object.getprotoOf()`来获取一个对象的原型：

```js
const obj = {};
const proto = Object.getPrototypeOf(obj);

console.log(proto); // 输出: Object.prototype
```

ES6 新增了`Object.setPrototypeOf()`方法用于给一个对象设置原型，其等同于`obj.__proto__ = proto`：

```js
const user = {
  name: '张三',
  age: 20
};
Object.setPrototypeOf(user, {
  say() {
    console.log('hello');
  }
});
console.log(user); // {name: '张三', age: 20}
```

## 🔢 > Object.values(target) / Object.entries(target)
ES5 引入了`Object.keys()`方法，返回一个数组，值是对象自身的（不含继承的）所有可遍历属性的键名。

```js
var obj = { foo: 'bar', baz: 42 };
console.log(Object.keys(obj)); // ["foo", "baz"]
```

ES2017 引入了跟`Object.keys()`配套的`Object.values()`和`Object.entries()`，作为遍历一个对象的补充手段，供`for...of`循环使用。

```js
let {keys, values, entries} = Object;
let obj = { a: 1, b: 2, c: 3 };

for (let key of keys(obj)) {
  console.log(key); // 'a', 'b', 'c'
}

for (let value of values(obj)) {
  console.log(value); // 1, 2, 3
}

for (let [key, value] of entries(obj)) {
  console.log([key, value]); // ['a', 1], ['b', 2], ['c', 3]
}
```

`Object.values()`方法返回一个数组，值是对象自身的（不含继承的）所有可遍历属性的键值。

```js
const obj = { foo: 'bar', baz: 42 };
console.log(Object.values(obj)); // ["bar", 42]
```

`Object.entries()`方法返回一个数组，值是对象自身的（不含继承的）所有可遍历属性的键值对数组。

```js
const obj = { foo: 'bar', baz: 42 };
console.log(Object.entries(obj)); // [ ["foo", "bar"], ["baz", 42] ]
```

## 🔢 > Object.fromEntries(target)
`Object.fromEntries()`方法相当于是`Object.entries()`的逆操作，用于将一个键值对数组转为对象。

```js
Object.fromEntries([
  ['foo', 'bar'],
  ['baz', 42]
])
// { foo: "bar", baz: 42 }
```

特别适合将 Map 结构转为对象：

```js
const entries = new Map([
  ['foo', 'bar'],
  ['baz', 42]
]);

console.log(Object.fromEntries(entries)); // { foo: "bar", baz: 42 }
```

## 🔢 > Object.hasOwn(target, prop)
在 ES5 中，对象实例有一个`obj.hasOwnProperty()`方法，可以判断某个属性是否为原生属性。ES2022 在 Object 对象上面新增了一个静态方法`Object.hasOwn()`，也可以判断是否为自身的属性。

```js
const foo = Object.create({ a: 123 });
foo.b = 456;

Object.hasOwn(foo, 'a') // false
Object.hasOwn(foo, 'b') // true
```
