讲迭代器之前，需要搞清楚几个概念。

什么是迭代？

迭代从一个数据集合中按照一定的顺序，不断的取出数据的过程被称为迭代。

迭代和遍历的区别？

迭代强调的是依次取数据，并不能保证取多少，也不保证所有数据取完。

遍历强调的是要把整个数据依次全部取出。

<br/>tips
迭代可以对应现实中一个产品的迭代，产品需要不断的迭代，但是最终迭代成什么样子没有人知道。

<br/>

什么是迭代器？

迭代器是对迭代过程的封装，在不同的语言中有不同的表现方式，通常为一个对象。

迭代器解决了什么问题呢？

用一个东西，这个东西帮你一个一个的拿数据，这个东西就是迭代器，就是对迭代过程的封装。

迭代模式？

迭代模式是一种设计模式，用于统一迭代的过程，并规范了迭代器的规格。

迭代器应该具有得到下一个数据的能力。

迭代器应该具有判断是否还有后续数据的能力。

## 🔢 JS 中的迭代器
JS 规定如果一个对象具有`next()`方法，且该方法返回一个对象，该对象的数据格式如下：

```js
{value: 值, done: 是否迭代完成}

// 例如
const obj = {
  next() {
    return {
      value: 1,
      done: false
    };
  }
};
```

则认为该对象就是一个迭代器。

参数的含义：

- `next()`方法，用于得到下一个数据；
- `next()`方法返回一个对象：
    - `value`属性，表示当前数据的值；
    - `done`属性，`Boolean`类型，表示是否迭代完成；

## 🔢 遍历和迭代对比
以下代码是使用`for`循环对数组进行遍历：

```js
const arr = [1, 2, 3, 4, 5];

// 但是如果数据集不一定是真数组（伪数组），换成迭代器就没有这个问题了
for (let i = 0; i < arr.length; i++) {
  const element = arr[i];
  console.log(element);
}
```

使用`for`循环遍历数组有一个缺点：一定要关心数据集`arr`，多数场景下是没有问题的。

但是如果某些数据没有`.length`属性就不知道循环的终止条件了，如果换成迭代器就不会这个问题了。

下面是使用迭代器对数组进行迭代：

```js
const arr = [1, 2, 3, 4, 5];

// iterator 是一个迭代器，用于迭代数组
const iterator = {
  i: 0, // 当前数组下标
  next() {
    return {
      value: arr[this.i++],
      done: this.i >= arr.length
    };
  }
};
```

`iterator`就是一个简单的迭代器，然后调用`next()`方法进行数据迭代：

```js
console.log(iterator.next());
console.log(iterator.next());
console.log(iterator.next());
console.log(iterator.next());
console.log(iterator.next());

// 结果如下：
/*
  {value: 1, done: false}
  {value: 2, done: false}
  {value: 3, done: false}
  {value: 4, done: false}
  {value: 5, done: true}
*/
```

`value`属性表示本次迭代的数据，`done`属性表示迭代器是否执行完成。

<br/>

我们还可以写一个循环，让其自动的调用`next()`方法：

```js
let iterator = iterator.next();
while (!iterator.done) {
  console.log(iterator.value);
  // 进行下一次迭代
  iterator = iterator.next();
}
```

虽然感觉还不如`for`循环，但是使用迭代后整个循环不需要关心数据集了，数据集和取数据进行了隔离。

## 🔢 迭代器函数
我们可以把上面创建迭代器的过程封装为一个函数：

```js
// 迭代器创建函数
function createIterator(arr) {
  let i = 0; // 当前数组下标
  return {
    next() {
      return {
        value: arr[i++],
        done: i >= arr.length
      };
    }
  };
}
```

`createIterator()`一般被称为「迭代器创建函数 iterator creator」。

<br/>

然后调用的时候传递数据集即可：

```js
const arr1 = [1, 2, 3, 4, 5];
const arr2 = [6, 7, 8, 9, 10];

const iter1 = createIterator(arr1);
const iter2 = createIterator(arr2);

console.log(iter1);
console.log(iter1);

// 结果如下：
/*
  {next: ƒ}
  {next: ƒ}
*/
```

## 🔢 可迭代协议
ES6 规定，如果一个对象具有知名符号属性`Symbol.iterator`，并且属性值是一个迭代器创建函数，则该对象是可迭代的（iterable）。

格式如下：

```js
var obj = {
  [Symbol.iterator]() {
    return {
      next() {
        return {
          value: 1,
          done: false
        };
      }
    };
  }
};
```

例如数组原型上就具有这个属性：

```js
const arr = [5, 7, 9];
console.log(arr);
```

该属性返回的是一个迭代器创建方法：

```js
const iter = arr[Symbol.iterator](); // 迭代器创建方法
console.log(iter); // 得到一个迭代器
console.log(iter.next());
console.log(iter.next());
console.log(iter.next());
console.log(iter.next());

// 结果如下：
/*
  Array Iterator {}
  {value: 5, done: false}
  {value: 7, done: false}
  {value: 9, done: false}
  {value: undefined, done: true}
*/
```

为什么要使用`[]`进行获取呢？

因为`Symbol.iterator`是`Symbol`上的一个静态属性，返回的是一个`Symbol`类型。该属性并不直接返回一个`Symbol`的值，而是作为一个属性键存在于对象中。`for...of...`的时候 JS 底层会自动调用这个方法。

简单说，就是`Symbol.iterator`返回的是一个对象的 key。

<br/>

有了这个迭代器创建方法后，就不需要再手动创建迭代器方法了，改写之前数组自动迭代的案例：

```js
const arr = [5, 7, 9];
const iter = arr[Symbol.iterator]();
let result = iter.next();

while (!result.done) {
  const item = result.value;
  console.log(item);
  result = iter.next();
}

// 结果如下：
/*
  5
  7
  9
*/
```

## 🔢 for...of...
ES6 提供了专门用于迭代可迭代对象的语法:

```js
for(const iter of iterable){
    // iter 每次迭代的得到的数据
    // iterable 可迭代对象
}
```

结合上面的案例：

```js
const arr = [5, 7, 9];
for (const iterator of arr) {
  console.log(iterator);
}

// 结果如下：
/*
  5
  7
  9
*/
```

<br/>warning
⚠️ 注意

`Object`类型的对象是没有迭代方法的！

<br/>

```js
let obj = {
  a: 1,
  b: 2
}

for (const iter of obj) { // ❌TypeError: obj is not iterable
  console.log(iter)
}
```

如果想让`Object`类型的对象进行迭代需要手动实现迭代器方法：

```js
let obj = {
  a: 1,
  b: 2,
  // 手动实现迭代器方法
  [Symbol.iterator]: function () {
    const keys = Object.keys(this);
    let i = 0;

    return {
      next: () => {
        const result = {
          // value 属性
          value: {
            propName: keys[i],
            propValue: this[keys[i]]
          },
          // done 属性
          done: i >= keys.length
        };

        i++
        return result;
      }
    };
  }
};

// 进行迭代
for (const iterator of obj) {
  console.log(iterator);
}

// 结果如下：
/*
  { propName: 'a', propValue: 1 }
  { propName: 'b', propValue: 2 }
*/
```

这样一来，迭代就不仅限于数组，任何可以迭代的数据都可以是`for...of...`进行迭代。

## 🔢 展开运算符和可迭代对象
展开运算符可以作用于可迭代对象，这样就可以轻松的将可迭代对象转化为数组。

```js
// 将迭代器转换为数组
const arr = [...obj];
console.log(arr); // [{propName: 'a', propValue: 1}, {propName: 'b', propValue: 2}]

// 将迭代器作为参数传递
test(...obj);
function test(a, b){
  console.log(a, b);
}
```
