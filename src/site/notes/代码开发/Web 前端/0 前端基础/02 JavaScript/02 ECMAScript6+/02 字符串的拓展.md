## 新增的实例方法
## includes()

判断字符串中是否存在某段字符，返回布尔值。

<br/>

```js
const str = "abcdefg";

console.log(str.includes("a")); // true
```

## startsWith() / endsWith()

判断字符串是否以某段字符开头/结尾，返回布尔值。

<br/>

```js
const str = "abcdefg";

console.log(str.startsWith("abc")); // true
console.log(str.endsWith("fg")); // true
```

## repeat()

表示将字符串重复多少次，返回一个新的字符串

<br/>

```js
const str = "abcdefg";

console.log(str.repeat(3)); // abcdefgabcdefgabcdefg
console.log(str); // abcdefg
```

特殊值：

```js
console.log("abc".repeat(2.3)); // abcabc 转换为整数2
console.log("abc".repeat(NaN)); // abc 不进行操作
```

## padStart() / padEnd()

表示将字符串进行补全，如果某个字符串不够指定长度，会在头/尾部补全，返回一个新的字符串。

参数：

- length 需要补全后的目标长度；
- str 补全的字符；

<br/>

```js
const str = "abcdefg";
console.log(str.padStart(10, "***")); // ***abcdefg 从前面补全 3 个字符
console.log(str); // abcdefg
```

```js
const str = "abcdefg";
console.log(str.padEnd(10, "*")); // abcdefg*** 从后面补全 3 个字符
console.log(str); // abcdefg
```

## 模版字符串
在 ES6 之前，我们想要处理字符串会存在两个繁琐的问题：

1、多行字符串

2、字符串的拼接

```js
var text = '\n\
    <ul>\n\
        <li>first</li>\n\
        <li>second</li>\n\
        <li>third</li>\n\
    </ul>\n\
';
console.log(text);
```

```js
var name = 'zhangsan';
var age = 20;
var info = 'name is ' + name + ', age is ' + age;
console.log(info);
```

导致我们处理字符串非常的麻烦。

ES6 提供了模版字符串的书写方式，可以非常方便的进行操作换行和拼接，只需要讲字符串中的`""`或`''`更改为````即可。

```js
var text = `
<ul>
    <li>first</li>
    <li>second</li>
    <li>third</li>
</ul>
`;
console.log(text);
```

```js
let name = 'zhangsan';
let age = 20;
// 表达式可以是任何有意义的数据
let info = `name is ${name}, age is ${age}, num is ${1 + 2 + 3}`;
console.log(info);
```

表达式可以进行嵌套：

```js
let info = `name is ${`zhang` + `san` + `${1 + 2 + 3}`}.`;
console.log(info);
```

如果想要在模版字符串中输出原`${}`需要使用`/`进行转译：

```js
let str = `在ES6中使用\${表达式}进行文本插值！`;
console.log(str); // 在ES6中使用${表达式}进行文本插值！
```

## 标签模版
例如有这么一段字符串：

```js
let love1 = '篮球';
let love2 = '足球';
let text = `张三喜欢${love1}，还喜欢${love2}`;
```

我希望对`text`字符串进行一些简单的处理，然后再输出一个新的字符串。

只要在模版字符串````的前面加上函数的名称就会自动调用函数，函数的返回值会返回赋值给`text`变量。

```js
let love1 = '篮球';
let love2 = '足球';
// 会把字符串按照 ${} 进行分割
let text = myTag`张三喜欢${love1}，还喜欢${love2}`;

function myTag(stringArr, value1, value2) {
  console.log(stringArr); // ["张三喜欢", ",还喜欢", ""]
  console.log(value1); // 篮球
  console.log(value2); // 足球

  return "喜欢：" + value1 + value2;
}

console.log(text); // '喜欢：篮球足球'
```

ES6 新增了`String.raw()`方法可以输出原始的内容，而不会将特殊的字符进行转译

```js
let text = String.raw`abc\nbcd`;
console.log(text);
/*
  abc
  bcd
*/
```

```js
let text = String.raw`abc\nbcd`;
console.log(text); // "abc\nbcd";
```

再比如：

```js
String.raw`Hi\n${2+3}!`
// 实际返回 "Hi\\n5!"，显示的是转义后的结果 "Hi\n5!"

String.raw`Hi\u000A!`;
// 实际返回 "Hi\\u000A!"，显示的是转义后的结果 "Hi\u000A!"
```
