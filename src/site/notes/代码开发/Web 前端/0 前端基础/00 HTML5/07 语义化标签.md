为了更好语义化，H5 新增了以下标签，在之前需要使用`class`属性来命名区分语义化，而现在直接使用标签就可以：

```html
<header>表示页面中内容的头部</header>
<nav>表示页面中内容的导航</nav>
<main>
  表示页面中的主要的内容
  <section>表示页面中的一个内容区块</section>
  <article>表示一块与上下文无关的独立的内容</article>
  <aside>表示页面中内容的侧边栏</aside>
</main>
<footer>表示页面中内容的底部</footer>
```

🔔 提示

`<article>`和`<section>`的区别：

- `<article>`一般表示与自身相关的内容（重点在内容），比如一篇论坛的帖子；
- `<section>`一般表示某个单独功能的聚合（重点在功能），比如一个小型地图；
