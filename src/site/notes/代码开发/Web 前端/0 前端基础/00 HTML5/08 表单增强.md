## 🔢 新的输入类型
新增了一些表单类型，具体如下：

- `type="date"`生成一个选择日、月、年的表单；
- `type="time"`生成一个选择小时、分钟的表单；
- `type="week"`生成一个选择周、年的表单；
- `type="month"`生成一个选择月、年的表单；
- `type="datetime-local"`选取时间、日、月、年（本地时间）；
- `type="number"`限制用户必须输入数字类型，无法输入其他字符；
- `type="email"`限制用户必须输入邮箱类型；
- `type="color"`生成一个颜色选择的表单；
- `type="range"`产生一个滑动条表单；
- `type="url"`限制用户必须输入网址类型；
- `type="search"`产生一个搜索的文本框，相比普通的文本框会多出一个搜索的记录；
- `type="tel"`不会对输入的内容进行格式验证，在手机设备上会触发输入号码的键盘；

```html
<form action="/testSubmit" method="get">
  <fieldset>
    <input type="date" name="date" />
    <input type="time" name="time" />
    <input type="week" name="week" />
    <input type="month" name="month" />
    <input type="datetime-local" name="datetime" />
  </fieldset>

  <fieldset>
    <input type="number" name="number" />
    <input type="email" name="email" />
    <input type="color" name="color" />
    <input type="range" name="range" min="1" max="100" step="5" />
    <input type="url" name="url" />
    <input type="search" name="search" />
    <input type="tel" name="tel" />
  </fieldset>
</form>
```

## 🔢 新的表单属性
## 🔢 placeholder
文本框处于未输入状态时文本框中显示的输入提示。

```html
<input type="text" placeholder="请输入内容" />
```

## 🔢 autofocus
给文本框、选择框、或者按钮控件加上该属性，当打开页面时，该控件自动获得光标焦点，一个页面只能有一个。

```html
<input type="text" autofocus>
```

## 🔢 required
可以应用在大多数输入元素上（除了隐藏元素和图片），在提交时如果元素内容为空白，则不允许提交，同时显示提示文字。

```html
<form action="demo-form.php">
  <input type="text" name="usrname" required>
  <input type="submit">
</form>
```

## 🔢 novalidate
取消检验，可以对`<form>`表单添加`novalidate`属性，即使`<form>`表单中的`<input>`添加了`required`，也将不进行验证。

```html
<form action="demo-form.php" novalidate>
  <input type="email" name="user_email">
  <input type="submit">
</form>
```

## 🔢 pattern
将属性值设为某个格式的正则表达式，在提交时会检查其内容是否符合给定格式。

```html
<input pattern="[0-9][A-Z]{3}" title="输入内容：一个数与三个大写字母" placeholder='输入内容：一个数与三个大写字母' />
```

## 🔢 multiple
可以输入一个或多个值，每个值之间用逗号分开，适用于`type="file"`、`<select>`等表单。

```html
<input type=“email” multiple/>
```

## 🔢 min、max、step
为包含数字或日期的`<input>`类型规定限定（约束）。

- `max`: 最大值；
- `min`: 最小值；
- `step`: 数字间隔；

```html
<input type="number" min="0" max="10" step="3" />
```
