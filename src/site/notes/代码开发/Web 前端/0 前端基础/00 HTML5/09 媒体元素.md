在 HTML5 之前如果想要在浏览器内实现媒体播放需要使用 Flash player。

Flash player 是一个私有技术，并不是浏览器自带的而是独立于浏览器的一个插件，所以使用的时候需要用户进行安装。

Flash player 的缺点：

1、浏览器本身不具有这个插件，所以需要安装，但是这个体积相对较大，安装慢

2、性能差，加载资源的时间长

3、安全性差，因为需要获取系统相关的权限

4、版本升级需要进行更新

直到 HTML5 新增了两个与媒体相关的元素，即`<audio>`和`<video>`，从而为浏览器提供了嵌入音频和视频的统一解决方案。

`<audio>`和`<video>`的优点：

1、属于浏览器的标准，不需要进行额外的安装和更新

2、性能较好

3、不接触系统层面，不涉及安全性

`<video>`支持的媒体格式：

| 格式 | MIME-type |
| --- | --- |
| MP4 | video/mp4 |
| WebM | video/webm |
| Ogg | video/ogg |

`<audio>`支持的媒体格式：

| 格式 | MIME-type |
| --- | --- |
| MP3 | audio/mp3 |
| WAV | audio/wav |
| OGG | audio/ogg |

这两个元素既支持`Web`开发者在页面中嵌入媒体文件，也支持`JavaScript`实现对媒体的自定义控制。

```html
<!-- 嵌入视频 -->
<video src="conference.mpg" id="myVideo">
  浏览器版本不支持播放
</video>

<!-- 嵌入音频 -->
<audio src="song.mp3" id="myAudio">
  浏览器版本不支持播放
</audio>
```

每个元素至少要求有一个`src`属性，以表示要加载的媒体文件。

开始和结束标签之间的内容表示在媒体播放器不可用时显示的替代内容。

由于浏览器支持的媒体格式不同，因此可以指定多个不同的媒体源。为此，需要从元素中删除`src`属性，使用一个或多个`<source>`元素代替。

```html
<!-- 嵌入视频 -->
<video id="myVideo">
  <source src="conference.webm" type="video/webm; codecs='vp8, vorbis'">
  <source src="conference.ogv" type="video/ogg; codecs='theora, vorbis'">
  <source src="conference.mpg">
  浏览器版本不支持播放
</video>

<!-- 嵌入音频 -->
<audio id="myAudio">
  <source src="song.ogg" type="audio/ogg">
  <source src="song.mp3" type="audio/mpeg">
  浏览器版本不支持播放
</audio>
```

## 标签属性
| 属性 | 描述 |
| --- | --- |
| src | 值为媒体源地址，相对和绝对均可。 |
| width | 宽度，值为具体单位。 |
| height | 高度，值为具体单位。 |
| controls | 显示控件，布尔属性，值为`controls`。 |
| controlslist | 如果指定了`controls`属性时，`controlslist`属性会帮助浏览器选择在控制面板上显示哪些控件。<br/>允许接受的值有`nodownload`, `nofullscreen`和`noremoteplayback`。如果要禁用画中画模式（和控件），请使用`disablePictureInPicture`属性。 |
| autoplay | 自动播放（不建议使用，用户体验不好），布尔属性，值为`autoplay`。 |
| preload | 预加载，和`autoplay`是互斥的，值为：<br/>+ `none`表示不应该预加载视频；<br/>+ `metadata`表示仅预先获取视频的元数据（例如长度）；<br/>+ `auto`表示可以加载整个视频文件，即使用户不希望使用它； |
| autopictureinpicture | 当前页面和另一个页面或应用程序之间来回切换时，会自动切换画中画模式，值为布尔值。 |
| loop | 表示循环播放。 |
| poster | 海报帧图片`URL`，用于在视频处于下载中的状态时显示。 |

更多内容请查看：

## DOM 属性和方法
`<audio>`和`<video>`的`DOM`都是继承来`HTMLAudioElement`和`HTMLVideoElement`构造函数。

```js
let oVd = document.getElementsByTagName("video")[0];
console.log(oVd.__proto__);
```

下面是`<audio>`和`<video>`常用的`DOM`属性和方法：

| 属性/方法 | 描述 |
| --- | --- |
| .currentTime | 当前播放的时间，单位秒。 |
| .duration | 总时长，单位秒。 |
| .paused | 是否已暂停。 |
| .muted | 是否静音，可读可写。 |
| .volume | 音量，0-1 之间的小数，可读可写。 |
| .playbackRate | 播放速度，可读可写。<br/>常用的值：0.5、1、1.25、1.5、2  |
| .buffered | 表示用户的音频/视频缓冲范围，单位秒。<br/>缓冲范围指的是已缓冲的时间范围。如果用户在媒体中跳跃播放，会得到多个缓冲范围。 |
| .buffered.start(index) | 获得某个已缓冲范围的开始位置。 |
| .buffered.end(index) | 获得某个已缓冲范围的结束位置。 |
| .load() | 重新加载。 |
| .play() | 播放。 |
| .pause() | 暂停。 |

更多请参考：

## DOM 事件
事件会监控由于媒体回放或用户交互导致的不同属性的变化

下面是`<audio>`和`<video>`常用的`DOM`属性和事件：

| 事件 | 描述 |
| --- | --- |
| onload() | 加载完成时触发。 |
| onerror() | 加载失败时触发。 |
| onended() | 可以播放的时候触发。 |
| oncanplay()  | 播放完成后触发。 |
| onplay() | 正在播放时触发。 |
| onseeked() | 拖动时间进度条后触发。 |
| onseeking() | 拖动时间进度条时触发。 |
| onratechange() | 播放倍数改变后触发。 |
| onvolumechange() | 播放音量改变时触发。 |
| onwaiting() | 由于暂时（缓冲）缺少数据，播放已停止时触发。 |

具体请参考：

## 案例：自定义媒体播放器
使用`<audio>`和`<video>`的`play()`和`pause()`方法，可以手动控制媒体文件的播放。综合使用属性、事件和这些方法，可以方便地创建自定义的媒体播放器。

```html
<div class="mediaplayer">
  <div class="video">
    <video id="player"
      src="movie.mov"
      poster="mymovie.jpg"
      width="300"
      height="200">
        Video player not available.
    </video>
  </div>
  <div class="controls">
    <input type="button" value="Play" id="video-btn">
    <span id="curtime">0</span>
    /
    <span id="duration">0</span>
  </div>
</div>
```

通过使用`JavaScript`创建一个简单的视频播放器，上面这个基本的`HTML`就可以被激活了

```js
// 取得元素的引用
let player = document.getElementById("player"),
  btn = document.getElementById("video-btn"),
  curtime = document.getElementById("curtime"),
  duration = document.getElementById("duration");

// 更新时长
duration.innerHTML = player.duration;

// 为按钮添加事件处理程序
btn.addEventListener( "click", (event) => {
  if (player.paused) {
    player.play();
    btn.value = "Pause";
  } else {
    player.pause();
    btn.value = "Play";
  }
});

// 周期性更新当前时间
setInterval(() => {
  curtime.innerHTML = player.currentTime;
}, 250);
```

## 音频对象
`<audio>`元素还有一个名为`Audio`的原生`JavaScript`构造函数，支持在任何时候播放音频。`Audio` 类型与`Image`类似，都是`DOM`元素的对等体，只是不需插入文档即可工作。

要通过`Audio`播放音频， 只需创建一个新实例并传入音频源文件：

```js
let audio = new Audio("sound.mp3");
audio.oncanplaythrough = function(event){
  audio.play();
}
```
