在 HTML 中有非常多的标签，每个标签都具有不同的含义，而标签又可以添加一些属性，属性是为了给标签提供额外的信息数据。

标签的属性一般分为以下几种类别：

1、布尔属性

布尔属性只要存在就表示启用，属性名等于属性值。

```html
<input type="checkbox" checked>
<option selected>选项1</option>
<input disabled>

<!-- 等价于 -->
<input type="checkbox" checked="checked">
<option selected="selected">选项1</option>
<input disabled="disabled">
```

2、枚举属性

枚举属性指的是只能从预先定义好的值中选择一个。

```html
<input type="text">
<input type="password">
<button type="submit">提交</button>
```

例如`type`还有其他的属性：`checkout`...

3、数值属性

```html
<input type="number" min="0" max="100">
<img width="200" height="150">
```

4、URL 属性

属性值为资源地址（相对或绝对）。

```html
<a href="https://example.com">访问</a>
<img src="images/photo.jpg">
<link href="/style/main.css" rel="stylesheet">
```

5、自定义文本属性

这类的属性值内容就比较自由了，输入任何你想输入的文本即可。

```html
<div id="header"></div>
<p class="intro highlight">欢迎访问</p>
<input placeholder="请输入用户名">
<img alt="网站图标">
<abbr title="World Wide Web">WWW</abbr>
```
