## 标签属性值类型
HTML 是由「标签」组成的，标签又分为单标签（例`<img />`）和双标签(例`<h1></h1>`)，标签上还可以书写属性，属性表示对当前标签一种功能性的设置（例`<img src="" />`）。

不同标签的属性值也不同，大致如下：

1、字符串类型

```html
<a href="https://example.com">Example</a>
<input type="text" value='user'>
```

2、布尔属性

这些属性存在即为“真”，不需要指定值或可以显式地将值设置为属性名

```html
<input type="checkbox" checked>
<button disabled="disabled">Submit</button>
```

3、枚举类型
属性的值在特定的选项中进行选择。值只能是枚举值中的一个。

```html
<input type="text" autocomplete="on">
<form method="post">
```

4、数值类型

属性的值是数字或数值范围。

```html
<input type="number" min="1" max="100">
<progress value="50" max="100"></progress>
```

5、事件处理类型

这些属性通常与 JavaScript 事件处理器相关联，值通常是 JavaScript 代码或函数。

```html
<button onclick="alert('Hello!')">Click me</button>
```

## 实体字符
HTML 文档内有时候不能解析一些特殊字符，所以我们需要用实体字符进行表示。

- `&lt;`表示空格箭头`<`；
- `&gt;`表示空格箭头`>`；
- `&nbsp;`表示空格；
- `&copy;`表示备案中图标版权 ©；

```html
<body>
  <div>
    这是一个&lt;div&gt;标签
    <p>这是内容1&nbsp;&nbsp;&nbsp;这是内容2</p>
    这是备案号&copy;
  </div>
</body>
```

## 图片标签
图片标签`<img />`。

属性：

- `src`：表示要加载的资源地址，可以是网络或者本地相对路径；
- `width`：标签图片的宽度（默认单位是像素，一般标签属性定义宽高时都不加单位）；
- `height`：表示图片的高度；
- `alt`：表示图片加载失败后对图片的说明；
- `title`：表示鼠标悬浮后对图片的说明；

```html
<body>
  <img
       src="https://img1.baidu.com/it/u=2154229925,157114706&fm=253&fmt=auto&app=138&f=PNG?w=500&h=288"
       alt="web前端"
       title="web前端"
       />
  <img src="https://img1.baidu.com.png" width="100" alt="web前端1" title="web前端" />
</body>
```

## 超链接/锚点标签
超链接`<a>`标签原本是定义锚点的链接，而现在`<a>`标签多数用于链接跳转。

属性：

- `href`: 表示要链接的地址（或链接的内容）；
- `target`：标签以什么形式打开地址（默认是`_self`表示当前窗口，可选`_blank`等）；
- `download`：
    - 如果`download`没有设置值，浏览器会将`href`的链接和文件名进行下载。如果设置了，将作为`href`的文件名下载；
    - 只在同源 URL 或 `blob:`、`data:` 协议下起作用，详见：[MDN](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Element/a#download)；

```html
<body>
  <a target="_blank" href="https://www.baidu.com">点击访问百度</a>
  <a href="/images/logo.png" download="logo.png">
</body>
```

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/00%20HTML5/_assets/1659339211664-9c44b4eb-f31a-4a16-b527-46ffb038f009.png)

有时候我们不希望点击`<a>`标签跳转可以设置伪协议限定符：

```html
<a href="javascript:;">点击不会进行跳转页面</a>
```

`<a>`标签还可以直接唤起移动端的一些操作：

```html
<a href="tel:18801120693">拨打电话</a>
<a href="mailto:2501869423@qq.com">发邮件</a>

<!-- 锚点定位 -->
<a href="#title">标题</a>
<div id="title">标题</div>
```

## 序列列表
`<ol>`表示有序列表。

属性：

- `type`：表示序列号的类型，默认是 1 2 3，可选 1、`a`、`A`、`i`、`I`;
- `start`：表示从哪里开始，只有数字有效;
- `reversed`：表示反转（可选值`reversed`）;

`<li>`表示列表项。

```html
<body>
  <ol start="2">
    <li>项目1</li>
    <li>项目2</li>
    <li>项目3</li>
    <li>项目4</li>
    <li>项目5</li>
  </ol>
  <ol type="a" reversed="reversed">
    <li>项目1</li>
    <li>项目2</li>
    <li>项目3</li>
    <li>项目4</li>
    <li>项目5</li>
  </ol>
</body>
```

## 表格标签
`<table>`表示表格；

属性：

- `border="1"` 表示边框宽度；
- `cellpadding="10" `表示单元格内边距；
- `cellspacing="10"` 表示单元格之间的间距；

`<caption>`表示表格的标题；

`<tr>`表示表格的行;

`<th>`表示表格的列头;

`<td>`表示表格的行列单元格;

属性：

- `colspan="2"`表示单元格的跨列的列数;
- `rowspan="2"`表示单元格的跨行的行数;
- `align="left/center/right"`表示水平对齐方式左 、中 、右;
- `valign="top/middle/bottom"`表示垂直对齐方式：上 、中 、下;

## 表单标签
`<form>`标签是表单标签，没有任何的样式，主要用于包裹整个表单内容，该标签是块级元素。

属性：

- `method`: 表示表单提交的方式，可选`get`、`post`；
- `action`：表示表单提交的地址；

```html
<form method="get" action="www.baidu.com"></form>
```

`<label>`标签用于和表单标签进行联动，该标签是内联元素。

属性：

- `for`：填入和表单相同的`id`值就可以实现关联

```html
<form method="get" action="www.baidu.com">
  <label for="username">用户名：</label>
  <input id="username" type="text" name="text1" value="1" placeholder="请输入账号" maxlength="5" />
</form>
```

`<input>`是一个重要的标签，通过`type`属性可以设置为多种文本类型，该标签是内联块元素。

属性：

- `name`：表示文本框提交时的`key`；
- `value`：表示文本框提交时的`value`；
- `type`：表示文本框类型，可选`text`、`password`、`submit`、`reset`、`button`、`radio`、`file`；
- `maxlength`：表示文本框可输入的最大长度（`type='text|password'`可用）；
- `readonly`：表示文本框的是只读的，该属性为布尔值；
- `disabled`：表示文本框的是禁用的，该属性为布尔值；
- `checked`：表示选中，该属性为布尔值（`type='radio｜checkbox'`可用）；
- `accept`：上传文件时可选的文件类型，如需规定多个值，请使用逗号分隔（比如`accept="audio/*,video/*,image/*,.png,.gif"`）（`type="file"`可用）；

> [!tip]
>
> `readonly`和`disabled`的区别：`disabled`的文本框的值无法进行提交，`readonly`是可以提交的。


示例：

```html
<form method="get" action="www.baidu.com">
  <input type="text" name="text1" value="1" placeholder="请输入账号" maxlength="5" />
  <input type="text" name="text2" value="2" placeholder="请输入账号" readonly />
  <input type="text"  name="text3" value="3"  placeholder="请输入账号" disabled />

  <label for="male">男</label>
  <input type="radio" id="male" name="sex" value="male" checked />
  <label for="fem">女</label>
  <input type="radio" id="fem" name="sex" value="fem" />

  <input type="submit" value="提交" />
</form>
```

`<textarea>`标签表示一个文本域，内联块元素。

属性：

- `name`：表示文本框提交时的`key`；
- `cols`表示宽度可输入字数；
- `rows`表示高度可输入字数；

> [!warning]
>
> 该标签是个双标签，且没有`value`属性，标签之间的内容就是它的`value`（`JS`操作的时候仍然可以获取到`.value`属性），这也表示你不可以在标签之间存在空格或者换行！！！


```html
<form method="get" action="www.baidu.com">
  <label for="introduction">自我介绍：</label>
  <textarea id="introduction" name="introduction"></textarea>
  <input type="submit" value="提交" />
</form>
```

`<select>`&`<option>`是一组标签，用于展示下拉框，内联块元素。

`<select>`的属性：

- `name`：表示文本框提交时的`key`；

`<option>`的属性：

- `value`：表示文本框提交时的`value`；

> [!warning]
>
> 如果`option`没有`value`属性，默认就去找`option`标签中间的内容，如果`option`的`value`值是空则取空，一般来说`option`第一项都是提示内容没有值！！！


```html
<form method="get" action="www.baidu.com">
  <label for="lang">选择语言：</label>
  <select id="lang" name="lang">
    <option value="">请选择</option>
    <option value="HTML">HTML</option>
    <option value="CSS">CSS</option>
    <option value="javascript">javascript</option>
  </select>
</form>
```

`<fieldset>`和`<legend>`是一组标签，表示对表单进行分组包裹，块级元素。

```html
<form method="get" action="www.baidu.com">
  <fieldset>
    <legend>用户登录</legend>
    <div>
      <label for="username">用户名：</label>
      <input type="text" id="username" name="username" value="" />
      <label for="password">密码：</label>
      <input type="password" id="password" name="password" value="" />
    </div>
  </fieldset>
  <fieldset>
    <legend>用户介绍</legend>
    <label for="lang">选择语言：</label>
    <select id="lang" name="lang">
      <option value="">请选择</option>
      <option value="JavaScript">JavaScript</option>
      <option value="Java">Java</option>
      <optionF value="Java">Java</optionF>
      <option value="PHP">PHP</option>
    </select>
    <label for="introduction">自我介绍：</label>
    <textarea id="introduction" name="introduction"></textarea>
  </fieldset>
  <input type="submit" value="提交" />
</form>
```

`<button>`标签用于显示一个按钮。

```html
<button>这是一个按钮</button>
```

> [!tip]
>
> `submit`是提交按钮起到提交信息的作用，`type`类型是`button`只起到跳转的作用，不进行提交。
