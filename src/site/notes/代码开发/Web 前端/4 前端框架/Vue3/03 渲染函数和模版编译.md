## 🔢 渲染函数

Vue`h()`渲染函数文档：

[Vue.js](https://cn.vuejs.org/guide/extras/render-function.html)

渲染函数`h()`调用后会返回一个虚拟 DOM 节点。

实际上，Vue 中的单文件组件 SFC （也就是 .vue 文件）是会被一个「模版编译器」进行编译的，编译后结果并不存在模版语法，而是会把「模版」编译为「渲染函数」的形式。

这意味着，我们完全可以使用纯 JS 来书写组件，在文件的内部直接调用「渲染函数」来描述你的视图。

> Vue 提供单文件组件是为了让开发者写代码更加的方便。
>

下面是使用「渲染函数」的形式描述原本在模版中所描述的视图结构：

```js
import { h, defineComponent } from 'vue';

const UserCard = defineComponent({
  name: 'UserCard',
  props: {
    name: String,
    email: String,
    avatarUrl: String
  },
  setup(props) {
    // 返回一个渲染函数
    return () =>
      h(
        'div',
        {
          class: 'user-card'
        },
        [
          h('img', {
            src: props.avatarUrl,
            class: 'avatar'
          }),
          h(
            'div',
            {
              class: 'user-info'
            },
            [h('h2', props.name), h('p', props.email)]
          )
        ]
      );
  }
});

console.log(UserCard);
```

甚至可以使用 Options API 的语法：

```js
import { h } from 'vue';

const UserCard = {
  name: 'UserCard',
  props: {
    name: String,
    email: String,
    avatarUrl: String
  },
  render() {
    return h(
      'div',
      {
        class: 'user-card'
      },
      [
        h('img', {
          src: this.avatarUrl,
          class: 'avatar'
        }),
        h(
          'div',
          {
            class: 'user-info'
          },
          [h('h2', this.name), h('p', this.email)]
        )
      ]
    );
  }
};
```

得到`UserCard`组件，我们就可以使用这个组件了：

```js
createApp({
  template: `
    <div class="app-container">
      <UserCard name="张三" email="zhangsan@163.com"  />
    </div>`,
  components: {
    UserCard
  }
}).mount('#app');
```

可以看到，使用「渲染函数」描述的组件视图是完全可以使用的。

到此，我们知道 Vue 之所以提供模版的方式是为了让开发者描述视图的时候更加的轻松。Vue 在运行的时候本身是不需要什么模版的，它只需要「渲染函数」，更精确说应该是调用这些「渲染函数」后所得到的虚拟 DOM。

## 🔢 模版编译

在单文件组件中所书写的模版对于模版编译器来说就是普通的字符串。

Vue 的模版语法：

```vue
<template>
  <div>
    <h1 :id="someId">Hello</h1>
  </div>
</template>
```

对于模版编译器来说只是一段字符串：

```js
'<template><div><h1 :id="someId">Hello</h1></div></template>'
```

模版编译器会对上面的字符串进行操作，最终生成的结果如下：

```js
function render() {
  return h('div', [h('h1', { id: someId }, 'Hello')]);
}
```

模版编译器在对模版字符串进行编译的时候是一点一点转化而来的，这个过程：

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/4%20%E5%89%8D%E7%AB%AF%E6%A1%86%E6%9E%B6/Vue3/_assets/1725931928633-93cb7773-f7f7-476b-99b4-aaed95e712ff.png)

从图片可以看到模版是经过编译器，最终变为了渲染函数。编译器的内部又分为 3 块：

- 解析器：负责将「模版字符串」解析为对应的「抽象语法树（模版 AST）」；
- 转换器：负责将「模版 AST」转化为「JS AST」；
- 生成器：负责将「JS AST」生成最终的「渲染函数」；

以上每一个步骤都是依赖于上一个步骤的结果。

例如使用下面这段模版进行举例：

```html
<div>
  <p>Vue</p>
  <p>React</p>
</div>
```

对于模版编译器来说就是一段字符串：

```js
'<div><p>Vue</p><p>React</p></div>';
```

首先是解析器，拿到这段字符串后对这段字符串进行解析，解析得到一个一个的 token：

```js
[
  { type: 'tag', name: 'div' },
  { type: 'tag', name: 'p' },
  { type: 'text', content: 'Vue' },
  { type: 'tagEnd', name: 'p' },
  { type: 'tag', name: 'p' },
  { type: 'text', content: 'React' },
  { type: 'tagEnd', name: 'p' },
  { type: 'tagEnd', name: 'div' }
];
```

<br/>tips
这里的 token 表示的是模版字符串被解析器分解后成的基本构成单位，表示模版中各个元素。

Vue 模板中的 token 可以分为以下几类：

1. 文本 Token: 用于表示纯文本内容。比如模板中的普通字符串`"Vue"`。
2. 标签 Token: 表示一个 HTML 元素的开始或结束标签。比如`<div>`和`</div>`会分别被解析成开始标签和结束标签 token。
3. 属性 Token: 包含在标签内的属性和它们的值。例如`<input>`中的`type="text"`就是一个属性 token。
4. 注释 Token: 表示模板中的注释部分，例如`<!-- This is a comment -->`。
5. 指令 Token: 解析器识别 Vue 指令（如`v-if`、`v-for`、`v-bind`等）并将它们解析成对应的 token。
6. 表达式 Token: 用于标识模板中的 JavaScript 表达式，例如`{{ message }}`或`:class="dynamicClass"`中的表达式部分。

<br/>

解析器还需要根据所得到的 Token 生成一个 AST（模版的 AST），转化后的 AST：

```js
{
  "type": "Root",
    "children": [
    {
      "type": "Element",
      "tag": "div",
      "children": [
        {
          "type": "Element",
          "tag": "p",
          "children": [
            {
              "type": "Text",
              "content": "Vue"
            }
          ]
        },
        {
          "type": "Element",
          "tag": "p",
          "children": [
            {
              "type": "Text",
              "content": "React"
            }
          ]
        }
      ]
    }
  ]
}
```

到此，解析器的工作就完成了。

接下来是转换器登场，它需要将模版的 AST 转化为 JS AST：

```js
{
  "type": "FunctionDecl",
    "id": {
    "type": "Identifier",
      "name": "render"
  },
  "params": [],
    "body": [
    {
      "type": "ReturnStatement",
      "return": {
        "type": "CallExpression",
        "callee": {"type": "Identifier", "name": "h"},
        "arguments": [
          { "type": "StringLiteral", "value": "div"},
          {"type": "ArrayExpression","elements": [
            {
              "type": "CallExpression",
              "callee": {"type": "Identifier", "name": "h"},
              "arguments": [
                {"type": "StringLiteral", "value": "p"},
                {"type": "StringLiteral", "value": "Vue"}
              ]
            },
            {
              "type": "CallExpression",
              "callee": {"type": "Identifier", "name": "h"},
              "arguments": [
                {"type": "StringLiteral", "value": "p"},
                {"type": "StringLiteral", "value": "React"}
              ]
            }
          ]
          }
        ]
      }
    }
  ]
}
```

最后就是生成器，根据 JS AST 生成具体的 JS 代码：

```js
function render() {
  return h('div', [h('p', 'Vue'), h('p', 'React')]);
}
```

下面是一个「模版编译器」的大致代码结构：

```js
function compile(template) {
  // 1. 解析器
  const ast = parse(template);
  // 2. 转换器：将模板 AST 转换为 JS AST
  transform(ast);
  // 3. 生成器
  const code = genrate(ast);

  return code;
}
```

最后 Vue 的「渲染器」会将执行「渲染函数」得到一个「虚拟 DOM」，然后渲染器会将虚拟 DOM 转化为真实的 DOM 并挂载到页面上：

## 🔢 编译的时机

在 Vue 中编译整体会有两种情况：

1、运行时编译；

2、预编译；

## 🔢 运行时编译

Vue 是支持使用 CDN 的方式使用 Vue 的，例如下面的案例：

```html
<body>
  <!-- 书写模板 -->
  <div id="app">
    <user-card :name="name" :email="email" :avatar-url="avatarUrl" />
  </div>

  <template id="user-card-template">
    <div class="user-card">
      <img :src="avatarUrl" alt="User avatar" class="avatar" />
      <div class="user-info">
        <h2>{{ name }}</h2>
        <p>{{ email }}</p>
      </div>
    </div>
  </template>

  <!-- 引入 Vue CDN -->
  <script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
  <script>
    const { createApp } = Vue;

    const UserCard = {
      name: 'UserCard',
      props: {
        name: String,
        email: String,
        avatarUrl: String
      },
      template: '#user-card-template'
    };

    // 创建 Vue 应用并进行挂载
    createApp({
      components: {
        UserCard
      },
      data() {
        return {
          name: 'John Doe',
          email: 'john@example',
          avatarUrl: './yinshi.jpg'
        };
      }
    }).mount('#app');
  </script>
</body>
```

以上的代码也会涉及到「模版代码」和「模版的编译」，此时的模版编译就是在「运行时编译」，也就是在浏览器运行的时候才开始进行编译。

## 🔢 预编译

预编译一般发生在工程化的环境下，所谓预编译就是在「打包的过程中」完成了模版的编译工作，浏览器拿到的打包后的代码是完全没有模版的。

Vue 如何才能看到 SFC 编译后的结果呢？

我们可以使用 Vite 来搭建一个 Vue 的工程项目。

```bash
$ npm create vite@latest demo-build -- --template vue
```

![](/img/user/%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/4%20%E5%89%8D%E7%AB%AF%E6%A1%86%E6%9E%B6/Vue3/_assets/1725934863677-690f936b-95a2-4f31-bbb8-c39b566809c2.png)

然后安装一个 Vite 的插件：vite-plugin-inspect。

```bash
$ npm install vite-plugin-inspect --save-dev
```

并在 Vite.config.js 文件中使用这个插件：

```js
import { fileURLToPath, URL } from 'node:url'

import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import pluginInsapect from "vite-plugin-inspect"

// https://vitejs.dev/config/
export default defineConfig({
  plugins: [
    vue(),
    pluginInsapect(),
  ],
  resolve: {
    alias: {
      '@': fileURLToPath(new URL('./src', import.meta.url))
    }
  }
})
```

最后当我们在终端运行项目的时候就会出现两个 URL：

```bash
$ npm run server
```
