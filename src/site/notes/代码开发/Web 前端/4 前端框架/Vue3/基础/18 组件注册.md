在 Vue3 中通过`createApp`方法来创建 Vue 的应用（一般一个项目就是一个 Vue 应用），最后使用`mount`方法把 Vue 应用挂载到真实的 DOM 节点上。

`createApp`方法的参数一定是一个组件，Vue 创建时组件的本质就是一个对象，所以`createApp`内可以直接传入一个对象，而这个对象就是「根组件」。

```js
import { createApp } from "vue";

createApp({
  // 根组件的内容
}).mount("#app")
```

根组件内还可以注册其他的子组件：

```js
import { createApp } from "vue";

const MyTitle = {}

const MySearch = {}

const App = {
  template: `
  	<div>
     	<MyTitle />
      <MySearch />
    </div>`,
  components: {
    MyTitle,
    MySearch
  }
}

createApp(App).mount("#app")
```

## 🔢 组件注册

组件的注册分为「全局组件注册」和「局部组件注册」两种：

1、全局组件：全局组件需要在`app`的应用实例对象上调用`component`方法进行注册

```js
import { createApp } from "vue";

const TestComponent = {
  // ...
}

const App = {
  template: `
  	<div>
     	<TestComponent />
    </div>`,
}

const app = createApp(App)
app.component("TestComponent", TestComponent)
app.mount("#app");
```

全局注册的`TestComponent`结构和`App`根组件结构是一样的！

我们在项目开发的时候如果一个组件在很多的地方都需要被调用，那么就可以考虑抽离为一个全局的组件。同样的相反，如果该组件有明确的父子依赖关系，那么就不需要全局注册！

2、局部组件：全局注册的组件不再需要单独的进行注册，而局部注册的组件需要在你每一个使用的组件内都进行注册！

```js
const MyCommonComponent = {
  // ...
}

const MyTitle = {
  template: `
  	<div>
     	<MyCommonComponent />
    </div>`,
  components:{
    MyCommonComponent
  }
}

const MySearch = {
  template: `
  	<div>
     	<MyCommonComponent />
    </div>`,
  components:{
    MyCommonComponent
  }
}
```

以上代码，我们通过`components`对象来注册组件，`components`就是一个对象，是键值对的格式，ES6允许键和值相同的时候进行简写，而完整的形式是：

```js
const MyCommonComponent = {
  // ...
}

const MyTitle = {
  template: `
  	<div>
     	<test-component></test-component>
    </div>`,
  components:{
    "test-component": MyCommonComponent
  }
}

const MySearch = {
  template: `
  	<div>
     	<MyCommonComponent />
    </div>`,
  components:{
    "MyCommonComponent": MyCommonComponent
  }
}
```

## 🔢 name 属性

每个组件内部都会有一个`name`属性，例如：

```js
export default{
  name:"xxx"
}
```

而在全局注册组件的时候也需要提供一个`name`值，例如：

```js
app.component("name", {
  // ...
})
```

我们就要讨论一下`name`属性该如何设定？调用组件的时候该如何使用呢？

在 Vue 中推荐「组件名」和「使用组件时」所使用的标签名，尽量保持一致的原则！

例如全局注册：

```js
// 注册时使用 kebab-case 的格式
app.component("my-title", MyTitle);
```

```html
<template>
  <!-- 使用的时候也要保持 kebab-case 的格式  -->
  <my-title></my-title>
</template>
```

在比如局部注册：

```js
const MyTitle = {
  // 使用 PascalCase 的格式定义
  name: "MyTitle",
  template: "<div>This is my title.</div>"
}

const App = {
  template: `
    <div>
      <!-- 使用 PascalCase 方式进行注册调用 -->
      <MyTitle />
    </div>`,
  components:{
    MyTitle
  }
}
```

结合上面的两个案例，这仅仅是理论上的一种推荐，并不是一个定数，其实这两种方式在 Vue 中都是能够支持的！

但是这两种方式都有自己的优缺点：

<br/>color2
优点：

- PascalCase
    - 有利于代码编辑的补全
    - JSX 是使用 PascalCase 格式进行标签书写的
- kebab-case
    - 符合 W3C 对标签使用的规范，也就是 XHTML 的规范（所有的都小写）
    - “-”是可以避免现有或将来的 HTML 标签冲突（如果未来出现了一个标准的标签名为`mytitle`，`my-title`可以避免这样的冲突）
    - 避免又一些大小写不敏感的文件系统，解析可能出现问题
    - 另外像这样的`<my-title></my-title>`也是为了符合 W3C 的规范，因为标准的 HTML 标签大多数都是双标签

<br/>

<br/>color3
缺点：

- PascalCase
    - 我们的组件是可以直接使用在 DOM 上的（也就是 .html 文件内），如果组件名是 PascalCase 的格式 HTML 是不会正常处理的，详见下面的案例 1！

<br/>

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <link rel="icon" type="image/svg+xml" href="/vite.svg" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title></title>
  </head>
  <body>
    <div id="app">
      <!-- 控制台警告 -->
      <MyTitle />
      <MyTitle></MyTitle>
      <!-- 正常 -->
      <my-title></my-title>
    </div>
    <script type="module" src="/src/main.js"></script>
  </body>
</html>
```

```js
import { createApp } from "vue";

const app = createApp({
  // ...
})
app.component("MyTitle", {
  data() {
    return {
      title: "This is my Title."
    };
  },
  template: "<h1>{{ title }}</h1>"
});
app.mount("#app");
```

总结：

在 Vue 中定义的时候两种书写方式都可以。如果你有点乱，那么请记住：在定义组件名称的使用统统使用 PascalCase 的格式（`app.component`方法除外！），在使用组件的时候统统使用 kebab-case 的格式就可以了！

组件的名称一律使用 PascalCase，是因为在 Vue 当中组件被看作一种一个类的模式，当作一个类来完成功能的，因为类的名称就是 PascalCase 的方式！

<br/>

说了一堆`name`属性的格式，那么`name`属性到底有什么作用呢？

组件内部的`name`属性一个很重要的作用就是「递归组件」，通过`name`属性组件就可以调用自己！

```vue
<template>
  <!-- 这将是一个死循环 -->
  <TestComponent />
</template>

<script>
  export default{
    name: "TestComponent"
  }
</script>
```

## 🔢 应用实例上的属性和方法

`Vue`的`createApp`方法返回一个应用实例对象，该对象上有很多的属性和方法，我们先来混个脸熟：

```js
import { createApp } from "vue";
import App from "./App.vue";

const app = createApp(App);
console.log(app);
app.mount("#app");
```

- `component`: 注册全局组件
- `config`: 应用配置
- `directive`: 注册全局自定义指令
- `mixin`: 全局注册混入器
- `mount`: 挂载组件
- `provide`: 注入全局跨组件层级的属性
- `use`: 使用插件
