React 起源 Facebook 的内部项目，后来开源供开发者使用。React 实质上是一个用于构建用户界面的 JavaScript 库，主要用于构建 UI 视图。由于 React 框架的设计思想独特，属于革命性的创新，性能出众，所以得到越来越多的关注和使用。

[React 官方中文文档](https://zh-hans.react.dev/)

React 的特点：
- 声明式
- 组件化
- 单向数据流
- 虚拟 DOM
- Diff 算法 搭建 React 项目的环境：

[Create React App](https://create-react-app.dev/)

```bash
$ npx create-react-app my-app $ cd my-app $ npm start
```

使用 Vite 搭建一个 React 项目的环境：

[开始](https://cn.vitejs.dev/guide/#scaffolding-your-first-vite-project)

```bash
$ npm create vite
```
