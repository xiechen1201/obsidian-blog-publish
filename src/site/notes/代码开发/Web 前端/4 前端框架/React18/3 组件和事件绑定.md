## 🔢 React 中的组件

在 React 中可以使用一个类来声明一个组件：

```jsx
class App extends React.Component {
  render() {
    return (
      // 一段 JSX
    );
  }
}
```

还可以使用函数来创建一个组件，同样需要返回一段 JSX：

```jsx
function App(){
	return (
		// 一段 JSX
	);
}
```

「早期」的函数式组件被称为「无状态组件」，一般仅仅用来纯 UI 的展示，里面不做复杂的逻辑。

自 React16.8 推出 Hooks 后，现在更多的是使用函数式组件，这也标志着 React 编程思想的转变。

## 🔢 为组件绑定事件

JSX 语法如下：

```jsx
function Form() {
  function handleSubmit(e) {
    // do something
  }

  return (
    <form onSubmit={handleSubmit}>
      <button type='submit'>Submit</button>
    </form>
  );
}
```

事件名称需要使用「小驼峰」的方式书写。

在 React 中无法通过`return false`来阻止默认的行为，所有需要使用`event.preventDefault()`来阻止默认的行为。

```jsx
function Form() {
	function handleSubmit(event) {
		// 无效
		// return false;
	
		// 正确
		event.preventDefault();
	}

	return (
		// ...
	);
}
```

如果是类组件，则需要把事件处理函数写成一个类的方法：

```jsx
class Welcome extends React.Component {
  // 事件处理函数
  eventHandler(e) {
    window.alert("Hello");
    e.preventDefault();
  }

  render() {
    return (
      <a href="https:// www.baidu.com/" onClick={this.eventHandler}>
        this is a test
      </a>
    );
  }
}

```

==需要注意的是，这里的`evnet`对象不是原始的「事件对象」，而是一个「合成事件」，要想获取原生的事件需要使用`event.nativeEvent`:==

```jsx
function onClick(event) {
	// event 不是原始的事件对象，是一个合成事件
	console.log(event);
	// 获取原生的事件对象
	console.log(event.nativeEvent);
}
```

> [!info] 信息
> 什么是合成事件？
> 本质上就是 React 对浏览器事件的上一层封装。在早期，不同的浏览器对事件的处理行为不一致，React 为了消除这些差异，因此包装为合成事件。

## 🔢 this 的指向

`this`的指向主要指的是在类组件中的指向问题，事件处理函数中的`this`并不会指向当前的组件，而是`undefined`，这就需要我们进行`this`的修正。

```jsx
class App extends React.Component {
  constructor() {
    super();
  }
  onClickBtn() {
    console.log(this);
  }
  render() {
    return (
      <>
        <button onClick={this.onClickBtn}>Click</button>
      </>
    );
  }
}
export default App;
```

有三种方式可以进行修正：
- 将事件处理函数修改为箭头函数；

```jsx
// ...
onClickBtn = () => {
	console.log(this);
};
```

- 将事件绑定修改为箭头函数；

```jsx
// ...
render() {
	return (
		<>
			<button onClick={() => this.onClickBtn()}>Click</button>
		</>
	);
}
```

- 使用`bind()`更改`this`的指向；

```jsx
render() {
	return (
	<>
		<button onClick={this.onClickBtn.bind(this)}>Click</button>
	</>
	);
}
```

## 🔢 传递参数

如果要传递参数可以通过下面的两种方式进行传递：
- 通过`bind`方法在绑定`this`指向的时候向事件处理函数进行传参；

```jsx
render() {
	return (
		<>
			<button onClick={this.onClickBtn.bind(this, id)}>Click</button>
		</>
	);
}
```

- 绑定事件时，通过书写箭头函数的形式传参；

```jsx
render() {
	return (
		<>
			<button
			onClick={
				(e)=>{ this.onClickBtn.bind(id, e) }
			}>
				Click
			</button>
		</>
	);
}
```

以上两种方式是等价的，在这两种情况下，React 的事件对象`event`会作为第二个参数被传递。剪头函数必须显式的进行传递，而`bind`方法事件对象会被隐式的进行传递。
