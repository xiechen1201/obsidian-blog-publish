## 🔢 什么是生命周期？

所谓生命周期指的是一个组件从诞生到销毁所经历的一系列过程，这个过程被称为生命周期。

React 在组件的的生命周期中提供了一系列的钩子函数（类似于事件），可以让开发者在函数中注入代码，这些代码在组件执行的某个时机触发！

生命周期函数是类组件独有的东西，从 React16.8 推出 Hook 后，整体已经开始以函数组件为主了。

## 🔢 常用的生命周期钩子函数

官网再介绍的时候也把钩子函数分为了「常用」和「不常用」两类。

### > constructor()

- 该钩子函数主要是做一些初始化的状态；
- 同一个组件对象只会创建一次；
- 不能在第一次挂载页面之前，调用`setState()`，为了避免问题，构造函数中严禁使用`setState（）`

```jsx
class App extends React.Component {
  constructor() {
    super();

    this.state = {
      value: ''
    };

    // ❌错误
    // this.setState({
    //   value: 1
    // });
  }

  render() {
    return (
      <>
        <span>{this.value}</span>
      </>
    );
  }
}
```

### > render()

- `render()`是整个类组件中必须要书写的函数；
- 该函数返回一个虚拟 DOM。会被挂载到虚拟 DOM 树中，最终渲染到页面的真实 DOM 中；
- `render()`可能不只运行一次，只要`state`数据更新触发试图更新，那么该函数就会被执行；
- 严禁使用`setState`，因为会导致无限的递归；

```jsx
class App extends React.Component {
	constructor() {
		super();

		this.state = {
			value : 1
		}
	}

	clickHandle=()=>{
		this.setState({
			value: this.state.value + 1
		})
	}

	render() {
		console.log("render");

		// ❌这样会导致 render() 无限的执行！
		// this.setState({
		//   value: this.state.value + 1
		// })

		return (
			<div>
				<div>{this.state.value}</div>
				<button onClick={this.clickHandle}>+1</button>
			</div>
		)
	}
}
```

### > componentDidMount()

- 该钩子函数类似于 Vue 中的`mounted()`;
- 该函数只会在调用组件渲染完成后时执行一次；
- 函数内可以使用`setState()`;
- 一般情况下，会将一些网络请求、启动定时器等业务初始化的操作写在该函数内；

```jsx
class App extends Component {
	constructor() {
		super();

		this.state = {
			value: ''
		};
	}

	componentDidMount() {
		console.log('componentDidMount');
	}

	onClickBtn() {
		this.setState({
			value: new Date()
		});
	}

	render() {
		return (
			<>
				<span>{this.value}</span>
				<button onClick={this.onClickBtn.bind(this)}>change value</button>
			</>
		);
	}
}
```

> [!info]
> 钩子函数执行的顺序：组件被调用=>`constructor()`=>`render()`=>`componentDidMount()`。

### > componentWillUnMount()

- 该钩子函数类似于 Vue 中的`beforeUnmount()`;
- 该函数只会在调用组件即将卸载前执行一次；
- 一般情况下，该函数内部会做一些销毁的资源，例如定时器等；

```jsx
class App extends Component {
	constructor() {
		super();

		this.state = {
			value: ''
		};
	}

	componentDidMount() {
		console.log('componentDidMount');
	}

	componentWillUnmount() {
    console.log('componentWillUnmount');
  }

	onClickBtn() {
		this.setState({
			value: new Date()
		});
	}

	render() {
		return (
			<>
				<span>{this.value}</span>
				<button onClick={this.onClickBtn.bind(this)}>change value</button>
			</>
		);
	}
}
```

### > componentDidUpdate(prevProps, prevState, snapshot)

- 该钩子函数类似于 Vue 中的`updated()`;
- 该函数会在组件状态更新后被立即调用，首次渲染不会执行该方法；
- 组件状态更新的时候会先执行`render()`再执行`componentDidUpdate()`;

```jsx
class App extends Component {
	constructor() {
		super();

		this.state = {
			value: ''
		};
	}

	componentDidMount() {
		console.log('componentDidMount');
	}

	componentWillUnmount() {
    console.log('componentWillUnmount');
  }

	componentDidUpdate(prevProps, prevState, snapshot) {
		/**
		 * prevProps 表示更新之前的 props
		 * prevState 表示更新之前的 status
		 * snapshot 表示快照，主要配合 getSnapshotBeforeUpdate() 钩子函数使用
		 * 详见：https://www.jianshu.com/p/0907be5c051c
		 */
    console.log('componentDidUpdate');
  }

	onClickBtn() {
		this.setState({
			value: new Date()
		});
	}

	render() {
		return (
			<>
				<span>{this.value}</span>
				<button onClick={this.onClickBtn.bind(this)}>change value</button>
			</>
		);
	}
}
```
