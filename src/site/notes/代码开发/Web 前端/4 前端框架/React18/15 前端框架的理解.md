什么是前端框架？
首先我们要划分界限，什么是框架（framework）？什么是库（library）？

无论是 React 还是 Vue 它们的核心是“构建 UI 的库”，都提供了以下的能力：
- 基于状态的声明式渲染
- 组件化开发

当一个简单的应用拓展到 SPA 页面，前端又需要路由方案，随着应用原来越庞大，组件数量越来越多，状态也就越来越难管理，因此就需要状态管理库。

我们发现，除了上面提到的这些功能，还有其他的一些功能（构建、数据流、文档等等）React 和 Vue 本身是不支持的。所以说 React 和 Vue 本身就是一个专注于 UI 的渲染，我们可以将包含库本身以及其他附加功能的解决方案称谓框架。

例如：
- UmiJS，基于 React、内置路由、构建、部署等功能；
- NextJS，基于 React、支持 SSR、SSG 两个功能的服务端框架；

我们平时说的 React 框架或者 Vue 框架，其实是指 React、Vue 本身以及他们周边的生态，这也算一种约定俗成的说法。

现代前端框架至少包含以下几个方面：
- 基于状态的声明式渲染；
- 支持组件化开发（复用）；
- 前端路由方案；
- 状态管理方案；
