通常情况下对数据库的库和表的新增、删除频率并不高，更多的是操作表中的数据。

1、新增数据

语法：

```latex
INSERT INTO 表名(字段名, ...) VALUES (字段值...);
```

示例：

```plsql
INSERT INTO student(`name`, `sex`, `address`, `classId`) VALUES ("小红", 0, "北京市丰台区", 3);
```

```plsql
-- 新增多条
INSERT INTO student(`name`, `sex`, `address`, `classId`) VALUES
("小吴", 0, "北京市昌平区", 1),
("小哈", 0, "北京市朝阳区", 2);

-- 或者
INSERT INTO student(`name`, `sex`, `address`, `classId`) VALUES ("小吴", 0, "北京市昌平区", 1);
INSERT INTO student(`name`, `sex`, `address`, `classId`) VALUES ("小哈", 0, "北京市朝阳区", 2);
```

2、修改数据。

语法：

```latex
UPDATE 表名 SET 字段名=值;
```

示例：

```plsql
UPDATE student SET name="小红update";
```

注意，这样会导致把所有的用户名全部更改为“小红update”，所以我们需要添加一个条件。

```plsql
-- 只更改 id 为 11 的数据的 name 字段
UPDATE student SET name="小红update" WHERE id=11;
```

3、删除数据。

语法：

```latex
DELETE FROM 表名;
```

示例：

```plsql
DELETE FROM student;
```

注意，这样会导致把所有 student 表中的所有数据全部删除，所以我们需要添加一个条件。

```plsql
-- 之删除 id 为 11 的数据
DELETE FROM student WHERE id=11;
```
