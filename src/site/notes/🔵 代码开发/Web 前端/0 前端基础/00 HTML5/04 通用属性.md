## 🔢 contenteditable
该属性可以让普通的标签具有编辑的能力：

```html
<div style="border: 1px solid #333;" contenteditable="true">
    youlixiang
    <span contenteditable="false">child</span>
</div>
```

![](/img/user/%F0%9F%94%B5%20%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/00%20HTML5/_assets/1718182791069-72bd7fce-ed99-4811-98bd-7de0f54d1468.png)

注意：

1. 该属性是可以被继承的；
2. `contenteditable='false'`表示内部的东西不能被编辑，但是整个标签可以作为一个整体被删除；

## 🔢 hidden
`hidden`属性相当于给元素直接设置样式为`display: none;`样式进行隐藏：

```html
<p hidden>这是一段文字</p>
```

## 🔢 data-*
给标签添加自定义的属性，并使用 JS 通过`dataset`对象来获取：

```html
<div id="box" data-name="test">这是一段文字</p>
```

```js
let str = document.getElementById("box").dataset.name;
console.log(str); // test
```

## 🔢 draggable
`draggable`属性可以让元素具有拖拽的功能：

```html
<div class="box" draggable="true"></div>
<div class="target"></div>
```

注意：

1. 默认开启`draggable`属性的元素有`<a>`、`<img>`；
2. 使用该属性需要明确两个要素：
    1. 被拖拽物体（`.box`元素）；
    2. 目标区域（`.target`元素）；
