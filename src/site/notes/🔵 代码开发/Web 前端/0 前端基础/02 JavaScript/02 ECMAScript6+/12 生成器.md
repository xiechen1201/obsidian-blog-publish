生成器 Generator 最初的目的是为了更加方便的书写迭代器。后续，生成器还增强了功能，所以生成器和迭代器存在一些联系，但是又具有一些独特的点。

## 🔢 什么是生成器？
生成器是一个通过构造函数`Generator()`创建的对象。但是，开发者是无法创建这个对象的，只能是 JS 引擎内部使用。生成器即是一个迭代器，同时又是一个可迭代对象。

## 🔢 如何创建生成器？
生成器的创建必须使用生成器函数（Generator Function）。

## 🔢 生成器函数的书写方式
```js
//
function *methodName(){} // * 号写在函数名前面
function* methodName(){} // * 号写在关键字后面
function*(){} // 匿名函数可以写在关键字的后面

const obj = {
    *methodName(){} // 对象方法可以写在方法名的前面
}
```

生成器函数一定返回一个迭代器！

<br/>

例如：

```js
function* test() {}
let t = test();
console.log(t);
console.log(t.next());
```

## 🔢 生成器函数内部是如何执行的？
```js
function* test() {
  console.log(123); // 不会运行
}
let iter = test();
console.log(iter);

// 结果如下：
/*
  Object [Generator] {}
*/
```

根据以上代码我们可以看到，直接调用`test()`函数后只是简单的得到一个生成器，而不会运行内部的代码。

函数内部是给生成器提供迭代数据的，每次调用生成器对象的`next()`方法，都将会导致生成器运行到下一个`yield`关键字的位置。

`yield`是一个关键字，该关键字只能在生成器函数内部使用，表示产生下一个迭代数据！

```js
function* test() {
  console.log("第一次运行");
  yield 1;
  console.log("第二次运行");
  yield 2;
  console.log("第三次运行");
}

let iter = test(); // 函数不运行，只是得到一个生成器
console.log(iter.next()); // 开始迭代，开始运行函数代码
console.log(iter.next());
console.log(iter.next());

// 结果如下：
/*
  // 第一次调用 iter.next()，结果如下：
  第一次运行
  { value: 1, done: false }

  // 第二次调用 iter.next()，结果如下：
  第二次运行
  { value: 2, done: false }

  // 第三次调用 iter.next()，结果如下：
  第三次运行
  { value: undefined, done: true }
*/
```

每次调用`next()`方法后都会运行一个`yield`并将后面的值返回，且暂停执行函数的执行。

当第三次运行`next()`方法的时候，后面已经没有`yield`关键字了，所以返回结果为`{ value: undefined, done: true }`。

有了生成器函数，我们可以改写一下迭代器中数组迭代的案例：

```js
const arr1 = [1, 2, 3, 4, 5];

function* createIterator(arr) {
  for (const element of arr1) {
    yield element;
  }
}

const iter = createIterator(arr1);
console.log(iter);
console.log(iter.next());
console.log(iter.next());
console.log(iter.next());
console.log(iter.next());

// 结果如下：
/*
  Object [Generator] {}
  { value: 1, done: false }
  { value: 2, done: false }
  { value: 3, done: false }
  { value: 4, done: false }
*/
```

## 🔢 生成器有哪些需要注意的细节？
1、生成器函数可以有返回值，返回值出现在第一个`done`为`true`时的`value`属性中。

```js
function* test() {
  console.log("第一次运行");
  yield 1;
  console.log("第二次运行");
  yield 2;
  console.log("第三次运行");
  return 10;
}
let iter = test();
console.log(iter.next());
console.log(iter.next());
console.log(iter.next());

// 结果如下：
/*
  第一次运行
  { value: 1, done: false }
  第二次运行
  { value: 2, done: false }
  第三次运行
  { value: 10, done: true }
*/
```

可以看到当第三次运行`next()`函数的时候，`return`出一个数字 10 结束了函数的执行，所以整个迭代也就结束了。在生成器函数内使用返回值适用于提前结束迭代的情况。

2、调用生成器`next()`方法可以传递参数，传递的参数会交给`yield`表达式的返回值。

```js
function* test() {
  console.log('第一次运行');
  let info = yield 1;
  console.log('info:', info);

  console.log('第二次运行');
  info = yield 2 + info;
  console.log('info:', info);

  console.log('第三次运行');
}
let iter = test();
console.log(iter.next());
console.log(iter.next(10));
console.log(iter.next());

// 结果如下：
/*
  第一次运行
  { value: 1, done: false }
  info: 10
  第二次运行
  { value: 12, done: false }
  info: undefined
  第三次运行
  { value: undefined, done: true }
*/
```

以上代码是一个生成器函数，下面是调用步骤的解释：

- 第一次调用`next()`方法，开始迭代数据，打印`'第一次运行'`，并得到迭代数据`{ value: 1, done: false }`，暂停函数的运行；
- 第二次调用`next(10)`方法并传递了参数 10，这个时候 10 就会作为`yield`表达式的返回值（也就是`yield 1`的返回值，并赋值给`info`变量）。接着继续执行，输出`info: 10`、`'第二次运行'`，并使用`yield`产出一个数据`{ value: 12, done: false }`；
- 第三次调用`next()`方法没有传递参数，所以`yield 2 + info`表达式就没有返回值即为`undefined`。输出`info: undefined`、`'第三次运行'`，因为后续没有`yield`迭代数据了所以迭代器也就执行完成了，得到数据`{ value: undefined, done: true }`；

<br/>warning
⚠️ 注意

第一次调用`next()`方法的时候传递参数是无效的！因为第一个`yield`之前没有`yield`表达式！

<br/>

3、生成器函数内部可以调用其他生成器函数，但是一定要加上`*`号

```js
function* test1() {
  yield 'a';
  yield 'b';
}

function* test2() {
  // test1(); // 无法得到 a，因为简单调用生成器函数不会导致内部的代码执行
  // yield test1(); // {value: test1, done: false} 得到生成器对象
  yield* test1(); // 表示函数内部也会参与迭代，{value: 'a', done: false}

  yield 1;
  yield 2;
}

const generator = test2();
console.log(generator.next());
console.log(generator.next());
console.log(generator.next());
console.log(generator.next());

// 结果如下：
/*
  { value: 'a', done: false }
  { value: 'b', done: false }
  { value: 1, done: false }
  { value: 2, done: false }
*/
```

根据代码可以看到，如果要调用其他的生成器函数必须使用`*`号，这样才能把其他生成器函数的数据进行迭代。

## 🔢 生成器的其他 API
1、`return()`方法，调用该方法后可以结束生成器函数，从而提前让整个迭代过程结束。

```js
function* test() {
  yield 1;
  yield 2;
  yield 3;
}

const generator = test();
console.log(generator.next());
// console.log(generator.return());
console.log(generator.return(20)); // return() 方法还可以传递参数
console.log(generator.next());

// 结果如下：
/*
  { value: 1, done: false }
  { value: 20, done: true }
  { value: undefined, done: true }
*/
```

2、`throw()`方法，调用该方法后可以在生成器函数中产生一个错误。

```js
function* test() {
  yield 1;
  yield 2;
  yield 3;
}

const generator = test();
console.log(generator.next());
console.log(generator.throw(new Error("出错了")));
console.log(generator.next());
```

## 🔢 生成器的应用
在 ES6 引入了 Promise API 后解决了回调函数的问题，但是又会出现`.then`回调的情景。

开发者需要一种同步书写解决的方案，直到 ES7 引入的`async/await`才得到了解决，而`async/await`实际上是基于生成器，下面是使用生成器函数模拟的`async/await`。

假如有这么一段代码，里面包含同步执行和`Promise`异步任务：

```js
function* task() {
  let d = yield 1;
  console.log(d);
  let resp = yield fetch('https://www.douyin.com/');
  console.log(resp);
  let text = yield resp.text();
  console.log(text);
}
```

关键在于，我们应该如何执行这个`task()`生成器函数。

我们可以把调用生成器函数的过程封装为一个方法：

```js
run(task);
```

下面看看`run()`方法内如何调用（以下代码需要结合`task()`生成器函数执行流程进行理解）：

```js
// run() 方法接收一个生成器函数作为参数
function run(generatorFunc) {

  // 调用生成器函数，得到生成器
  let generator = generatorFunc();

  // 开始迭代数据
  let result = generator.next();
  console.log(result); // 得到第一个迭代数据 {value: 1, done: false}

  // 调用 handleResult 方法对迭代数据进程处理
  handleResult();

  // 对 result 进行处理
  function handleResult() {
    if (result.done) {
      // 如果迭代完成，不进行处理
      return;
    } else {
      // 如果迭代未完成

      if (typeof result.value.then === 'function') {
        // 1、如果迭代的数据是一个 Promise，等待 Promise 完成后再进行下一次的迭代
        result.value.then(
          (res) => {
            // 继续迭代数据，res 为 fetch 的 response 对象
            // 传递给 yield fetch('https://www.douyin.com/');
            // 继续迭代数据，得到结果，继续使用 handleResult 进行数据处理
            result = generator.next(res);
            handleResult();
          },
          (err) => {
            result = generator.throw(err);
            handleResult();
          }
        );
      } else {
        // 2、如果迭代的数据是其他数据，直接进行下一次迭代
        // 把第一次迭代的数据传递过去，也就是 {value: 1, done: false}
        // next() 会把参数传递给上一次 yield 表达式的返回值
        // 也就是传递给 yield 1
        // 继续迭代数据，得到结果，继续使用 handleResult 进行数据处理
        result = generator.next(result.value);
        handleResult(); // 递归调用
      }
    }
  }
}
```
