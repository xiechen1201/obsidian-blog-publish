## 🔢 简介
面向对象是一种编程思想，和具体的语言没有关系，只是用面向对象的思维进行编程！

JS 也是面向对象语言，只是 ES5 之前编写起来并不方便。

面向对象与面向过程开发的对比：

1、面向过程的思考切入点是功能的步骤，也就是要考虑功能的第一步要做什么，第二步要做什么。

2、面向对象的思考切入点是对象的划分。

例如把大象装进冰箱里的案例。

面向过程的步骤：

```js
// 1、打开冰箱门
function openFrige() {}

// 2、大箱装进去
function elephantIn() {}

// 3、冰箱门关上
function closeFrige() {}
```

没有绝对的好坏，面对不同的场景和复杂度各有各的优势。面向过程适合精小的功能，面向对象适合复杂的系统。

面向对象的步骤：

```js
// 大象对象
function Elphant() {}

// 冰箱对象
function Frige() {}
Frige.prototype.open = function () {};
Frige.prototype.close = function () {};
Frige.prototype.join = function (something) {};

// 通过对象的方式把功能描述完成了
// 接下来开始调用对象
var firge = new Frige();
var elphant = new Elphant();
firge.open();
firge.join(elphant);
firge.close();
```

面向对象要思考程序中有哪些对象？根本不考虑第一步、第二步的步骤。

在上面这个大箱放入冰箱的案例中，如果要考虑项目的可维护性、可拓展性，那么面向对象是优于面向过程的！

例如冰箱要装的不是大象了，而是别的东西，这个时候只有把`join()`方法传递为其他的对象即可！

## 🔢 构造函数的语法糖
传统构造函数的问题：

1、属性和原型方法的定义是分开的，降低了代码的可读性。

2、原型成员可以被枚举。

3、默认情况下，构造函数仍然可以被当作普通函数进行调用。

```js
// 构造函数
function Animal(type, name, age, sex) {
  this.type = type;
  this.name = name;
  this.age = age;
  this.sex = sex;
}
// 中间存在其他的代码，降低了可读性，从逻辑上讲，上下的东西是一个整体
// 在面向对象中，将上下两段代码所有的对象成员的定义，统称为类
// 定义实例方法（原型方法）
Animal.prototype.print = function () {
  console.log(this.type, this.name, this.age, this.sex);
};

var dog = new Animal('dog', 'wangcai', 3, 'male');
dog.print(); // dog wangcai 3 male

// 原型成员是可以被枚举的
for (const key in dog) {
  console.log(key); // type name age sex print
}
```

ES6 对类进行了改造：

```js
// 类的名称
class Animal {
  // 构造器
  constructor(type, name, age, sex) {
    this.type = type;
    this.name = name;
    this.age = age;
    this.sex = sex;
  }

  // 实例方法（原型方法）
  // 和对象方法简写一致
  // 这样的代码类才是一个整体
  print() {
    console.log(this.type, this.name, this.age, this.sex);
  }
}

let dog = new Animal('dog', 'wangcai', 3, 'male');
dog.print(); // dog wangcai 3 male
console.log(dog); // Animal {type: 'dog', name: 'wangcai', age: 3, sex: 'male'}

for (const key in dog) {
  console.log(key); // type name age sex
}

// 不能当作普通函数进行调用
Animal(); // ❌Class constructor Animal cannot be invoked without 'new'
```

类的特点：

1、类声明不会进行提升，和`let`、`const`一样存在暂时性死区。

2、类所有的代码都在严格模式下执行。

3、类所有的方法都是不可枚举的。

4、类所有的方法都无法当作构造函数被使用。

```js
const p = new dog.print(); // 报错
```

5、类的构造函数必须使用`new`进行实例化调用。

## 🔢 属性表达式
类中成员也可以使用属性表达式：

```js
const printName = 'print';

class Person {
    constructor(name) {
        this.name = name;
    }

    // 名字不确定
    [printName]() {
        console.log(`Hello, ${this.name}`);
    }
}
var p = new Person('John');
p[printName](); // 输出 "Hello, John"
```

## 🔢 取值函数与存值函数
取值函数与存值函数对应的是 ES5 中`Object.defineProperty()`可定义某个对象属性的读取和设置，略显麻烦：

```js
class Animal {
  constructor(type, name, age, sex) {
    this.type = type;
    this.name = name;
    this.setAge(age);
    this.sex = sex;
  }

  getAge() {
    return this._age + '岁';
  }

  setAge(val) {
    if (val < 0) {
      val = 0;
    } else if (val > 100) {
      val = 100;
    }
    this._age = val;
  }

  print() {
    console.log(`${this.name} is a ${this.age} year old ${this.sex} ${this.type}`);
  }
}

console.log(new Animal('cat', 'Tom', 200, 'male')); // Animal {type: 'cat', name: 'Tom', _age: 100, sex: 'male'}
```

使用`getAge()`和`setAge()`不再是一个属性了，而是通过一个方法进行操作了。

使用`getter`和`setter`来控制一个属性的读取与设置：

```js
class Animal {
  constructor(type, name, age, sex) {
    this.type = type;
    this.name = name;
    this.age = age;
    this.sex = sex;
  }

  // 使用 getter 和 setter 控制的属性不在原型上
  // 创建 age 属性，并给他加上 getter，读取这个属性的时候会调用这个函数
  get age() {
    return this._age + '岁';
  }

  // 创建 age 属性，并给他加上 setter，给这个属性赋值的时候会调用这个函数
  set age(val) {
    if (val < 0) {
      val = 0;
    } else if (val > 100) {
      val = 100;
    }
    // this._age 用于在对象内部存储 age 的实际值，而不是直接将 age 公开
    this._age = val;
  }

  print() {
    console.log(`${this.name} is a ${this.age} year old ${this.sex} ${this.type}`);
  }
}

let dog = new Animal('cat', 'Tom', 200, 'male');
console.log(dog, dog.age); // Animal {type: 'cat', name: 'Tom', _age: 100, sex: 'male'} '100岁'
```

## 🔢 静态属性
函数本身也是对象，可以给函数本身添加一些属性。

> 构造函数本身的成员就是静态成员。
>

使用`static`定义的成员即为静态成员，只能通过构造函数来访问，不能通过实例来访问。

```js
function Animal(type, name, age, sex) {
  this.type = type;
  this.name = name;
  this.age = age;
  this.sex = sex;
}
// 静态成员
Animal.print = function () {
  console.log('Animal.print');
};
// 只能通过构造函数来使用
Animal.print();
```

在 ES6 中通过`static`来定义一个静态的属性：

```js
class Animal{
  constructor(type, name, age, sex) {
    this.type = type;
    this.name = name;
    this.age = age;
    this.sex = sex;
  }
  // 静态方法
  static print() {
    console.log('Animal.print');
  }
}

Animal.print();
```

## 🔢 字段初始化器
`static`也是字段初始化器，ES6 是支持静态方法的，但是不支持静态属性，到了 ES7 支持了静态属性。

```js
class Animal{
  constructor(type, name, age, sex) {
    this.type = type;
    this.name = name;
    this.age = age;
    this.sex = sex;
  }
  // 静态属性
  static width = 100;
  static height = 100;
  // 静态成员
  static print() {
    console.log('Animal.print');
  }
}
```

某些时候属性本身就具有默认值，又不需要在构造函数内部进行初始化赋值。

例如下面的构造函数在内部初始化了三个属性：

```js
class Test {
  constructor() {
    this.a = 1;
    this.b = 2;
    this.c = 3;
  }
}

console.dir(new Test()); // Test {a: 1, b: 2, c: 3}
```

在 ES7 中可以进行简写：

```js
class Test {
  // 是在实例对象上，而不是原型对象上
  a = 1;
  b = 2;
  c = 3;

  constructor() {
    this.d = this.b + this.c;
  }
}
console.log(new Test()); // Test {a: 1, b: 2, c: 3, d: 5}
```

如果书写的方法是箭头函数，那么方法会被添加到实例上，而不是原型上：

```js
class Test {
  a = 1;
  b = 2;
  c = 3;

  constructor() {
    this.d = this.b + this.c;
  }

  // 通过这样方式定义的 print 方法会导致定义在实例上，而不是原型上
  print = () => {
    console.log(this.a);
  };
}

const t = new Test();
console.log(t); // {a:1, b:2, c:3, d:5, p:fun}

const p = t.print;
p(); // 1
```

> [!warning]
> 1、使用`static`的字段初始化器，添加的是静态成员。
> 2、没有使用`static`的字段初始化器，添加的对象位于实例上。
> 3、箭头函数在字段初始化器位置上，指向的是实例对象。

## 🔢 私有属性和方法
私有属性和方法只能在类的内部进行访问，外部不能进行访问，早期的 ES6 并不支持这一功能，只能通过变通的方法来实现：

1、通过约定命名。

约定`_`下划线开头的属性即位类的私有属性或者私有方法。

```js
class Widget {

  // 公有方法
  foo (baz) {
    this._bar(baz);
  }

  // 私有方法
  _bar(baz) {
    return this.snaf = baz;
  }

  // ...
}
```

2、利用`Symbol`的唯一特性。

```js
const bar = Symbol('bar');
const snaf = Symbol('snaf');

export default class myClass{

  // 公有方法
  foo(baz) {
    this[bar](baz);
  }

  // 私有方法
  [bar](baz) {
    return this[snaf] = baz;
  }

  // ...
};
```

直到 ES2022 正式为类添加了私有属性的特性，只要给属性添加上`#`即可

```js
class IncreasingCounter {
  #count = 0;
  get value() {
    console.log('Getting the current value!');
    return this.#count;
  }
  increment() {
    this.#count++;
  }
  #sum() {
    return this.#count + 100;
  }
}
```

如果外部使用就会报错：

```js
const counter = new IncreasingCounter();
counter.#count // 报错
counter.#count = 42 // 报错
```

私有属性和私有方法前面，也可以加上`static`关键字，表示这是一个静态的私有属性或私有方法。

```js
class FakeMath {
  static PI = 22 / 7;
  static #totallyRandomNumber = 4;

  static #computeRandomNumber() {
    return FakeMath.#totallyRandomNumber;
  }

  static random() {
    console.log('I heard you like random numbers…')
    return FakeMath.#computeRandomNumber();
  }
}

FakeMath.PI // 3.142857142857143
FakeMath.random()
// I heard you like random numbers…
// 4
FakeMath.#totallyRandomNumber // 报错
FakeMath.#computeRandomNumber() // 报错
```

## 🔢 装饰器
什么是装饰器？

把对象进行修饰，修饰的同时并不影响实际的使用，只是新增一些功能。

例如给`class`类增加一个装饰器：

```js
function testable(target, name, descriptor) {
  // descriptor 和 Object.defineProperty 中的 descriptor 是一样的
  // 都是对属性的特性进行定义
}

@testable
class Person {}
```

给`class`的方法新增一个装饰器：

```js
function readonly(target, name, descriptor) {
	descriptor.writable = false;
}

class Person {
  @readonly
  say() {
    console.log("say function");
  }
}
```

如果装饰器后面需要跟参数，装饰器函数则需要使用闭包的形式：

```js
function readonly(str) {
	console.log(str);
  return function(target, name, descriptor){
    descriptor.writable = false;
  }
}

class Person {
  @readonly("123")
  say() {
    console.log("say function");
  }
}
```

使用装饰器给`class`方法新增日志：

```js
let log = (type) => {
  return function show(target, name, descriptor) {
    // descriptor.value 就表示属性的值，也就是函数
    let src_method = descriptor.value;

    // 重写了 descriptor.value
    descriptor.value = (...arg) => {
      src_method.apply(target, arg);

      console.log(type);
    };
  };
};

class AD {
  @log("show")
  show() {
    console.log("ad is show");
  }
  @log("click")
  click() {
    console.log("ad is click");
  }
}

new AD().show();
// ad is show
// show

new AD().click();
// ad is click
// click
```

## 🔢 类继承
在 JS 中如果两个类 A、B，如果要进行描述为 B 是 A，则 A 和 B 形成继承关系。

例如猫是动物，这样就形成了继承关系，形成继承关系后，B 就拥有了 A 中的属性和方法。

在 ES6 之前要实现一个继承是比较麻烦的：

```js
function Animal(type, name, age, sex) {
  this.type = type;
  this.name = name;
  this.age = age;
  this.sex = sex;
}
Animal.prototype.run = function () {
  console.log(this.name + ' is running');
};

Object.setPrototypeOf(Dog.prototype, Animal.prototype);

function Dog(name, age, sex) {
  // 借用父类的构造函数中的属性
  Animal.call(this, '犬', name, age, sex);
}

const d = new Dog('旺财', 3, '公');
console.log(d); // Dog {type: "犬", name: "旺财", age: 3, sex: "公"}
d.run(); // 旺财 is running
```

ES6 使用`extends`和`super`就可以实现继承：

1、`extends`继承。

2、`super`借用父类的构造函数。

2.1 如果直接当作函数调用，则表示父类构造函数

2.2 如果当作对象使用，则表示父类的原型

ES6 要求如果定义了`constructor`并且该类是子类，则必须在`constructor`的第一行手动调用父类构造函数！

如果不写`constructor`就相当于写了默认的`constructor`，改构造器的参数和父类一致，并自动调用父类构造器。

```js
class Dog extends Animal {}

// 等价于

class Dog extends Animal {
    constructor(...args) {
        super(...args); // 调用父类构造函数，并传递所有参数
    }
}

let d = new Dog('旺财', 3, '公');
```

因此实例化`Dog`的时候，默认会调用`Animal`的构造器，并把所有的参数都传递给`Animal`。

如果存在同样的方法，则优先调用子类的方法！

```js
// 父类
class Animal {
  constructor(type, name, age, sex) {
    this.type = type;
    this.name = name;
    this.age = age;
    this.sex = sex;
  }

  run() {
    console.log(this.name + ' is running');
  }
}

// 继承
class Dog extends Animal {
  constructor(name, age, sex) {
    // 使用 super 借用父类的属性
    super('犬', name, age, sex);
    this.abc = 'abc';
  }

  eat(){
    console.log(this.name + ' is eating')
  }
}

const d = new Dog('旺财', 3, '公');
console.log(d); // Dog {type: '犬', name: '旺财', age: 3, sex: '公', abc: 'abc'}
d.run(); // 旺财 is running
```

如果`super`当作对象使用，则表示父类的原型:

```js
// 父类
class Animal {
  constructor(type, name, age, sex) {
    this.type = type;
    this.name = name;
    this.age = age;
    this.sex = sex;
  }

  print(){
    console.log(`【类型】:${this.type}
            【名字】:${this.name}
            【年龄】:${this.age}
            【性别】:${this.sex}`)
  }
}

// 继承
class Dog extends Animal {
  constructor(name, age, sex) {
    // 使用 super 借用父类的属性
    super('犬', name, age, sex);
    this.love = ['吃骨头'];
  }

  print() {
    super.print();
    console.log(`【爱好】:${this.love}`)
  }
}

const d = new Dog('旺财', 3, '公');
d.print();
```

上面代码中，`Dog`类有一个`print()`方法，父类`Animal()`也有一个`print()`方法，我可以通过`super.print()`来直接调用父类原型的方法！
