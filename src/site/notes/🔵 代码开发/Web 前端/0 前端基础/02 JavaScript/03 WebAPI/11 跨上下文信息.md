跨文档信息（XDM，cross-document messaging），是一种在「不同执行上下文之间传递信息」的能力（包括不同的工作线程和非同源页面）。

XDM 的核心就是`postMessage()`方法，该方法接收三个参数：消息、目标接收源和可选的传输对象的数组（只和工作线程相关）。

<br/>tips
`postMessage()`最初的实现只支持字符串的传递，后来支持各种的数据类型，不过并不是所有的浏览器都支持这种类型，因此最新是使用`JSON.stringify()`进行格式后再传递。

<br/>

示例：

```js
// 获取 iframe 窗口对象
let iframeWindow = document.getElementById("myframe").contentWindow;
iframeWindow.postMessage("A secret", "http://www.wiley.com");
```

以上代码表示向 iframe 窗口发送一条信息，而且指定了源地址。如果源匹配则会进行数据发送，否则什么也不做。如果源地址传递为`"*"`，则表示不对接收目标进行限制（不推荐）。

当接收到 XDM 的信息后，iframe 的 window 对象会触发`message`事件，事件的`event`对象有三个重要的信息：

- `data`接收到的字符串数据；
- `origin`发送信息的文档源地址；
- `source`发送信息的文档中的`window`对象的「代理」，因此不能访问来源窗口的所有信息。如果发送信息的窗口是相同的源，则等同于`window`对象。这个对象主要是为了对来源窗口回传信息。

通常来说，在接收到事件后对发送源进行校验是必要的：

```js
window.addEventListener("message", (event) => {
  // 确保来自预期发送者
  if (event.origin == "http://www.wiley.com") {
    // 对数据进行一些处理
    processMessage(event.data);
    // 可选：向来源窗口回传一条消息
    event.source.postMessage("Received!", "http://p2p.wiley.com");
  }
});
```
