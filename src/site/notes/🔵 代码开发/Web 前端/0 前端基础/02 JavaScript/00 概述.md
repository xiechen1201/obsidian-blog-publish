ECMAScript、JavaScript、NodeJS 的区别？

ECMAScript（ES）是一种由 Ecma 国际组织制定的脚本语言标准，它规定了脚本语言的语法、类型、语句、关键字等基本特征，旨在提供一种跨平台、跨浏览器的标准化脚本语言环境。ES 本身并不是一种具体实现，而是一种规范或标准。

JavaScript 是一种基于 ECMAScript 标准的脚本语言，最初被设计用来在浏览器中实现交互式的网页功能。JS 包含了 ECMAScript 标准中定义的语法和特性，同时还包括了浏览器提供 WebAPI，也就是 ES + WebAPI = JavaScript。

NodeJS 是一个基于 Chrome V8 引擎的 JavaScript 运行时环境，使 JavaScript 可以脱离浏览器环境运行在服务器端。NodeJS 和 JS 一样使用了 ECMAScript 标准作为核心内容，同时还提供了自己的 API，可以理解为 ES + NodeAPI = NodeJS。

所以，可以理解为 JavaScript 和 NodeJS 是 ES 的超集，它们都在 ES 的基础上扩展了功能，分别适用于浏览器端和服务器端的不同环境需求。

ES 有哪些关键的版本？

- ES3 1999 年发布，定义了现代的 JavaScript 的基本特性；
- ES5 2009 年发布，增加了一些新特性，是的 JS 更加规范和可靠；
- ES6 2015 年发布，增加了许多重要的新特性和语言的增强，成为 JS 发展史中一个重要的里程碑；
