## 🔢 transition 过渡
CSS3 的`transition`属性允许`CSS`的属性值在一定的时间区间内平滑地过渡。这种效果可以在鼠标单击、获得焦点、被点击或对元素任何改变中触发，并圆滑地以动画效果改变 CSS 的属性值。

1、设置需要参与过渡的属性。

语法：

```latex
transition-property: value；
```

属性值：

- value：`all`或者具体属性值；

2、设置过渡的持续时间。

语法：

```latex
transition-duration: value；
```

属性值：

- value：具体的数值 + 单位（`s`或者`ms`）；

3、设置过渡的延迟时间。

语法：

```latex
transition-delay: value；
```

属性值：

- value：具体的数值 + 单位（`s`或者`ms`）；

4、设置过渡的动画类型。

语法：

```latex
transition-timing-function: value；
```

属性值：

- value 可选：
    - `linear`匀速；
    - `ease`逐渐变慢；
    - `ease-in`加速；
    - `ease-out`减速；
    - `ease-in-out`先加速后减速；
    - ![贝塞尔曲线](/img/user/%F0%9F%94%B5%20%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1584866174957-8c37cf00-7210-43b6-b4f5-6cfbc68433e7.png)

5、设置复合属性，语法：

```plain
.box{
  transition: 具体属性值  运动时间  延迟时间  动画类型;
}
```

也可以定义多个属性的过渡，用逗号分隔：

```plain
transition: 属性值1 运动时间 延迟时间 动画类型,
						属性值2 运动时间 延迟时间 动画类型;
```

示例，鼠标悬浮`<div>`更改宽度：

```html
<!DOCTYPE html>
<html>
  <head>
    <title>CSS过渡</title>
    <style type="text/css">
      .content {
        width: 200px;
        height: 200px;
        background-color: rosybrown;
        transition: all 1s linear;
      }

      .content:hover {
        width: 300px;
      }
    </style>
  </head>
  <body>
    <div class="content"></div>
  </body>
</html>
```

## 🔢 animation 动画
首先需要先介绍一下`@keyframes`关键帧。关键帧就是用来定义动画从 0 到 100% 之间所经历的样式变化的，语法如下：

```css
@keyframes mymove{
  from{
    /* 初始状态的样式属性 */
  }
  to{
    /* 结束状态的样式属性 */
  }
}

/* 或者 */

@keyframes mymove{
  0%{
    /* 初始状态的样式属性 */
  }

  /* 中间再可以添加其他关键帧 */
  /* 20%{ ... } */
  /* 60%{ ... } */

  100%{
    /* 结束状态的样式属性 */
  }
}
```

接着我们来看`animation`动画：

1、设置所应用的关键帧名称。

语法：

```latex
animation-name: keyframesName;
```

2、设置动画的持续时间。

语法：

```latex
animation-duration: value；
```

属性值：

- value：具体的数值 + 单位（`s`或者`ms`）；

3、设置动画的过渡类型。

语法：

```latex
animation-timing-function: value;
```

属性值：

- value 可选：
    - `linear`线性过渡，等同于贝塞尔曲线`(0.0, 0.0, 1.0, 1.0)`；
    - `ease`平滑过渡，等同于贝塞尔曲线`(0.25, 0.1, 0.25, 1.0)`；
    - `ease-in`由慢到快，等同于贝塞尔曲线`(0.42, 0, 1.0, 1.0)`；
    - `ease-out`由快到慢，等同于贝塞尔曲线`(0, 0, 0.58, 1.0)`；
    - `ease-in-out`由慢到快再到慢，等同于贝塞尔曲线`(0.42, 0, 0.58, 1.0)`；

4、设置动画的延迟时间。

语法：

```latex
animation-delay: value;
```

属性值：

- value：具体的数值 + 单位（`s`或者`ms`）；

5、设置动画循环次数。

语法：

```latex
animation-iteration-count: value;
```

属性值：

- value 可选：
    - `infinite`无限循环；
    - 具体的数值；

6、设置动画在循环中是否反方向运动。

语法：

```latex
animation-direction: value；
```

属性值：

- value 可选：
    - `normal`正常方向；
    - `reverse`反方向运行；
    - `alternate`动画先正常运行再反方向运行，并持续交替运行；
    - `alternate-reverse`动画先反运行再正方向运行，并持续交替运行；

7、设置动画在延时执行之前和执行之后将样式应用于其目标。

语法：

```latex
animation-fill-mode: value；
```

属性值：

- value 可选：
    - `none`正常；
    - `forwards`执行完成后的保留最后一帧样式；
    - `backwards`延迟执行前保留第一帧样式；
    - `both`相当于同时设置`forwards`和`backwards`；

8、设置动画的状态。

语法：

```latex
animation-play-state: value;
```

属性值：

- value 可选：
    - `running`运动；
    - `paused`暂停；

9、`animation`是以上属性的复合属性。

示例，实现一个动画效果：

```css
@keyframes mymove {
  from {
    transform: translate(0, 0)
  }
  to {
    transform: translate(300px, 200px);
  }
}

.keyframes-box {
  width: 300px;
  height: 300px;
  background-color: darkkhaki;
  animation: mymove 5s ease-in-out 0 infinite alternate;
}
```

## 🔢 transition 和 animation 的区别
相同点：

- 都是随着时间改变元素的属性值；

不同点：

- `transition`需要触发一个事件（`hover`事件或`click`事件等）改变元素的某个属性才会生效；
- `animation`在不需要触发任何事件的情况下也可以显式的随着时间变化来改变元素 CSS 的属性值，从而达到一种动画的效果，CSS3 的`animation`就需要明确的动画属性值；
