## 🔢 背景图
`CSS3`对背景图新增了两个属性：

1、设置背景图片原点（或相对位置）。

语法：

```latex
background-origin: value;
```

属性值：

- value:
    - `border-box`背景图相对边框；
    - `padding-box`背景图相对填充框，默认值；
    - `content-box`背景图像相对内容；

示例：

```css
.box {
  width: 300px;
  height: 300px;
  padding: 30px;
  border: 30px solid rgba(0, 0, 0, .3);
  background: url(./imgs/images.jpeg) no-repeat;
  background-origin: border-box;
}
```

2、设置背景图裁剪。

语法：

```latex
background-clip: value;
```

属性值：

- value:
    - `border-box`背景图相对边框，默认值；
    - `padding-box`背景图相对填充框；
    - `content-box`背景图像相对内容；

示例：

```css
.box {
  width: 300px;
  height: 300px;
  padding: 30px;
  border: 30px solid rgba(0, 0, 0, .3);
  background: url(./imgs/images.jpeg) no-repeat;
  background-origin: border-box;
  background-clip: content-box;
}
```

```latex
background: url(路径) 重复 滚动 定位/尺寸 原点 裁剪;
```

## 🔢 边框图片
1、设置边框图片路径，语法：

```latex
border-imgage-source: url(边框图片的路径);
```

示例：

```css
.box {
  width: 300px;
  height: 300px;
  padding: 30px;
  border: 30px solid rgba(0, 0, 0, .3);
  border-image-source: url(./imgs/images.jpeg);
}
```

![](/img/user/%F0%9F%94%B5%20%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1666233560189-870531ae-2175-4b69-b710-c918f3adc94f.png)

默认在占在 4 个角！

2、设置边框图片切割，语法：

```latex
border-imgage-slice: value;
```

属性值：

- value：
    - 具体的数值 + 单位；

Tip

和`padding`一样，这是一个复合属性，当有 4 个、3 个、2 个、1 个值表示的意义不同。

该属性会将图片进行切割 4 次划分为九宫格。

<br/>

示例：

```css
.box {
  width: 300px;
  height: 300px;
  padding: 30px;
  border: 30px solid rgba(0, 0, 0, .3);
  border-image-source: url(./imgs/zwEbB.jpeg);
  border-image-slice: 30%;
}
```

![](/img/user/%F0%9F%94%B5%20%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1666233686715-1ae6a2ea-8b86-4bd5-8964-d673078e550b.png)

3、设置边框图片平铺，语法：

```latex
border-image-repeat: value;
```

属性值：

- value：
    - `stretch`，默认值，拉伸图像来填充区域；
    - `repeat`，平铺图像来填充区域；
    - `round`，类似`repeat`值。如果无法完整平铺所有图像，则对图像进行缩放以适应区域；
    - `space`，类似`repeat`值。如果无法完整平铺所有图像，扩展空间会分布在图像周围；

示例：

```css
.box {
  width: 300px;
  height: 300px;
  padding: 30px;
  border: 30px solid rgba(0, 0, 0, 0.3);
  border-image-source: url(./imgs/zwEbB.jpeg);
  border-image-slice: 30%;
  border-image-repeat: stretch;
}
```

![使用两个角切割后中间的部分进行平铺](/img/user/%F0%9F%94%B5%20%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1666235028367-5a6ab955-4a8b-4c10-9734-8173668cd097.png)

4、设置边框图片的宽度，语法：

```latex
border-image-width：value;
```

属性值：

- value:
    - 具体的数值 + 单位；

<br/>warning
Warning

该属性会覆盖`border-width`。

<br/>

示例：

```css
.box {
  width: 300px;
  height: 300px;
  padding: 30px;
  border: 30px solid rgba(0, 0, 0, 0.3);
  border-image-source: url(./imgs/zwEbB.jpeg);
  border-image-slice: 30%;
  border-image-repeat: repeat;
  border-image-width: 40px;
}
```

![](/img/user/%F0%9F%94%B5%20%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1666235294000-4dd1a60c-6412-4630-a89f-61364c651401.png)

5、设置边框图片向外拓展，语法：

```latex
border-image-outset: value;
```

属性值：

- value:
    - 具体的数值 + 单位；

示例：

```css
.box {
  width: 300px;
  height: 300px;
  padding: 30px;
  border: 30px solid rgba(0, 0, 0, 0.3);
  border-image-source: url(./imgs/zwEbB.jpeg);
  border-image-slice: 30%;
  border-image-repeat: repeat;
  /* border-image-width: 40px; */
  border-image-outset: 10px;
}
```

6、`border-image`属性是以上 5 个属性的复合写法，语法：

```plain
border-imgage: url(路径) 切割大小/边框图宽度/边框图拓展 平铺;
```

## 🔢 边框圆角
语法：

```latex
/* 单个方向 */
border-top-left-radius: value;      /* 左上角 */
border-top-right-radius: value;     /* 右上角 */
border-bottom-right-radius: value;  /* 右下角 */
border-bottom-left-radius: value;   /* 左下角 */

/* 简写 */
border-radius: 10px 20px 30px 40px;	/* 四值：左上 右上 右下 左下（顺时针方向） */
border-radius: 10px 20px 30px;			/* 三值：左上 (右上和左下) 右下 */
border-radius: 10px 20px;						/* 两值：(左上和右下) (右上和左下) */
border-radius: 10px;								/* 单值：统一四个角 */
```

<br/>warning
⚠️ 注意

每个圆角的值都是由两个值决定的，左边是四个圆角的水平半径，右边是四个圆角的垂直半径

按顺时针的顺序，斜杠左边是四个圆角的水平半径，右边是四个圆角的垂直半径，但是通常我们很少写右边的参数，那就是默认右边等于左边的值

<br/>

基本用法：

![](/img/user/%F0%9F%94%B5%20%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1666235825879-dc5b35bc-0d1b-43dc-8d65-8fca49613629.png)

```css
.box {
  width: 200px;
  height: 200px;
  padding: 5px;
  border-radius: 10px;
  border: 1px solid #000;
}
```

`border-radius`原理：

```css
.box {
  width: 200px;
  height: 200px;
  padding: 5px;
  border: 30px solid #000;
  border-top-color: orange;
  border-right-color: green;
  border-bottom-color: gray;
  border-left-color: chocolate;
  border-radius: 20px 20px 20px 100px / 100px 100px 100px 100px;

```

## 🔢 拉伸大小
语法：

```latex
resize: value;
```

属性值：

- value：
    - `none`不容许拉伸
    - `both`容许水平垂直拉伸
    - `horizontal`水平拉伸
    - `vertical`垂直拉伸

<br/>tips
Info

该属性主要是给`textarea`标签设置拉伸大小的，但是当块元素、`table`、内联块元素设置了`overflow: auto/scroll;`的情况下，`resize`也会生效。

<br/>

示例：

```css
textarea {
	/*  只能水平拉伸  */
  resize: horizontal;
}
.box {
  width: 200px;
  height: 200px;
  border: 1px solid red;
  overflow: auto;
  resize: both; /* 水平垂直都能拉伸 */
}
```

## 🔢 盒子阴影
语法：

```latex
box-shadow: [inset] offset-x offset-y blur-radius spread-radius color;
```

属性值：

- `inset`：可选，如果指定则阴影出现在元素内部，未指定则出现在元素外部；
- `offset-x`：水平方向的偏移量，正数是向右偏移，单位为`px`；
- `offset-y`：垂直方向的偏移量，正数是向下偏移，单位为`px`；
- `blur-radius`：模糊半径，值越大越模糊，最小为 0，单位为`px`；
- `spread-radius`：拓展半径（有点像灯光从上面照出来的影子），值越大越半径越大，可以为负数，单位为`px`；
- `color`：模糊的颜色，值为具体颜色值；
