## 🔢 什么是 CSS？
CSS，全称为 Cascading Style Sheets（层叠样式表），是一种用来描述 HTML 或 XML 文档外观和布局的样式语言。

通过使用 CSS，开发者可以控制网页元素的样式，如颜色、字体、排版、布局、动画效果等，从而使网页内容更加美观和易于阅读。

CSS 的概念：

1、层叠性 (Cascading)：
层叠性意味着样式可以叠加应用，浏览器根据优先级规则来决定哪个样式对元素生效。优先级通常取决于选择器的特殊性、样式声明的位置以及`!important`标记；

2、样式表 (Stylesheet)：
CSS 的样式通常存放在外部的 .css 文件中，也可以通过`<style>`标签放在 HTML 文档中，或者通过`style`属性直接在 HTML 元素上定义（内联样式）；

3、选择器 (Selector)：
选择器用于指定要应用样式的 HTML 元素。常见的选择器包括元素选择器、类选择器、ID 选择器、伪类选择器等；

## 🔢 加载 CSS 样式
1、内联样式（或行内样式）。

直接在标签上书写`style`属性，然后进行样式的书写。

```html
<div style="width: 100px; height: 100px;"></div>
```

2、内部样式表。

`<style>`标签放在`<head>`标签下，其中`type="text/css"`表示内部的内容类型。

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Document</title>
    <style type="text/css">
      div {
        width: 100px;
        height: 100px;
      }
    </style>
  </head>
  <body></body>
</html>
```

3、外部样式表。

使用外部样式表的方式分为两种：

1）在`<style>`标签内使用`@import`来加载一个外部的 CSS 文件。

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Document</title>
    <style type="text/css">
      @import url("./index.css");
      /* 或者（现代化写法，新浏览器都支持，本质上还是对上面的语法糖） */
      @import "./index2.css";
    </style>
  </head>
  <body></body>
</html>
```

2）`<link>`标签写在`<head>`标签下，其中`rel="stylesheet"`用于定义文档关联，表示关联样式表，`href`表示加载的 CSS 路径。

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Document</title>
    <link rel="stylesheet" type="text/css" href="./index.css" />
  </head>
  <body></body>
</html>
```

以上三种使用 CSS 方式的优先级：内联 > 内部 > 外部。

<br/>tips
Info

`href`和`src`的区别？

- `href`表示指向一个资源的地址，如`<a>`、`<link>`元素的`href`属性等；
- `src`表示嵌入一个资源，用于替换当前标签的内容，例如`<img>`、`<script>`元素的`src`属性；

<br/>

Tip

`<link>`与`@import`引入 CSS 样式表的区别？

- 从属关系不同：`<link>`属于 HTML 的标签。`@import`属于 CSS 的关键字。`<link>`除了引入 CSS 文件还可以引入其他的资源。`@import`只能引入 CSS；
- 加载顺序不同：页面遇到`<link>`标签后直接引入 CSS 异步加载，不影响 HTML 的正常解析。`@import`页面加载完毕后才会被加载；
- 兼容性：`<link>`不存在兼容。`@import`是在 CSS2.1 提出的，IE5 以上的浏览器才支持；
- `DOM`操作：`<link>`可以被 DOM 操作。`@import`则不行；
