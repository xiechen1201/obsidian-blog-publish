## 🔢 线性渐变色
渐变可以让你在两个或多个指定的颜色之间显示平稳的过渡，语法：

```plain
background: linear-gradient(方向, 颜色, [其他颜色]);
```

`linear-gradient()`是一个函数，该函数属于背景图片类型的一种，所以设置在`background`下，参数有：

- 方向：
    - 默认为`to bottom`，即从上向下的渐变，可选`top right`/`to bottom`/`to left`/`to top`；
    - ![](/img/user/%F0%9F%94%B5%20%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1666528953793-13ef2f3d-44e5-4c57-b4f3-28d686d30948.png)
    - 也可以将上面的值进行组合：`to right bottom`/`to right top`/`to left bottom`/`to left top`；
    - ![](/img/user/%F0%9F%94%B5%20%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1666529018437-470b06f4-2d50-4bfe-b7e8-cf23eb15b016.png)
    - 也可以是具体角度，是指水平线和渐变线之间的角度，顺时针方向计算，单位是`deg`。换句话说，`0deg`将创建一个从下到上的渐变，`90deg`将创建一个从左到右的渐变。
    - ![](/img/user/%F0%9F%94%B5%20%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1666529089811-47165612-54b7-4285-8a24-122aa0d9e40d.png)
- 颜色：颜色值+百分比。百分比表示到百分之多少高度的位置是该颜色渐变开始，可选；

示例：

```css
.box {
  width: 200px;
  height: 200px;
  border: 1px solid #000;
  /* 从下到上，从蓝色开始渐变、到高度 20% 位置是黄渐变开始、最后以红色结束 */
  background-image: linear-gradient(to bottom, green, rgb(225, 255, 0) 20%, red);
}
```

## 🔢 径向渐变色
`radial-gradient()`和`line-gradient()`函数大同小异，该函数同样作用在`background`下，语法：

```plain
background: radial-gradient(形状, 圆的半径, 渐变的大小, 渐变的起始点, 颜色, [其他颜色]);
```

`radial-gradient()`参数如下：

- 形状
    - `ellipse`椭圆形/`circle`圆形。默认为`ellipse`，如果元素形状为正方形的元素，则`ellipse`和`circle`显示一样。
    - ![](/img/user/%F0%9F%94%B5%20%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1666529873798-1e5f6386-fed5-41b4-b02d-3d1144627d9c.png)
- 渐变的大小（即渐变到哪里停止）
    - `closest-side`最近边/`farthest-side`最远边/`closest-corner`最近角/`farthest-corner`最远角（默认）；
    - ![](/img/user/%F0%9F%94%B5%20%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1666529864470-08791eb0-31c5-466b-89c2-7e27f1e03f8c.png)
- 渐变起点的位置
    - `at X Y`轴的位置；
    - 或为具体的位置`at center`默认是图形的正中心/`at top`/`at bottom`；
- 颜色
    - 颜色值+百分比。百分比表示到百分之多少高度的位置是该颜色渐变开始，可选；

示例：

```css
.box {
  width: 200px;
  height: 200px;
  border: 1px solid #000;
  background: radial-gradient(
    closest-corner 100px 200px at 30% 50%,
    green,
    rgb(225, 255, 0) 10%,
    red
  );
}
```

## 🔢 重复性渐变
1、重复性线性渐变，使用的是`repeating-linear-gradient()`方法，在`linear-gradient`前面加上`repeating-`就表示线性重复渐变，其余参数一致。

示例：

```css
background-image: repeating-linear-gradient(
  red,
  yellow 10%,
  green 20%
);

/* 10% 的位置为 yellow，
   20% 的位置为green，
   然后按照这 20% 向下重复 */
```

![](/img/user/%F0%9F%94%B5%20%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/0%20%E5%89%8D%E7%AB%AF%E5%9F%BA%E7%A1%80/01%20CSS3/_assets/1666697874320-96472078-8992-40cf-af37-eecdf6155eff.png)

2、重复性径性渐变使用的是`repeating-radial-gradient()`方法，在`radial-gradient`前面加上`repeating-`就表示径性重复渐变，其余参数一致。

示例：

```css
background: repeating-radial-gradient(
  red,
  yellow 10%,
  green 20%
);
```
