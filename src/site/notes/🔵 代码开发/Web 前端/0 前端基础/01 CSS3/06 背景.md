## 🔢 背景色
语法：

```latex
background-color: value;
```

属性值：

- `value`可选：同`color`属性；

示例：

```css
.box{
  background-color: red;
}
```

## 🔢 背景图
<br/>warning
⚠️ 注意

背景图具有缓存的特性！！！

<br/>

设置背景图的资源路径，语法：

```latex
background-image: url(图片路径);
```

设置背景图是否重复，语法：

```latex
background-repeat: value;
```

属性值：

- `value`可选：
    - `repeat`默认值，重复；
    - `no-repeat`不重复；
    - `repeat-x`沿X轴重复；
    - `repeat-y``沿Y轴重复`；

设置背景图的滚动行为，语法：

```latex
background-attachment: value;
```

属性值：

- `value`可选：
    - `scroll`默认值，背景图随着页面的滚动而滚动；
    - `fixed`背景图片不会随着页面的滚动而滚动；
    - `local`背景图片会随着元素内容的滚动而滚动；

设置背景图的位置，语法：

```latex
background-position: value;
```

属性值：

- `value`可选：
    - `center`；
    - `top`；
    - `right`；
    - `bottom`；
    - `left`；
    - X 和 Y 轴数值；

设置背景图的大小，语法：

```latex
background-size: value;
```

- `value`可选：
    - `cover`表示无论页面如何改变，都会占满整个容器（宽高比例会改变）；
    - `contain`表示无论页面如何改变，都会按照等比例显示（宽高比例不会变）；
    - 具体的数值；

`background`属性是一个复合属性，语法：

```latex
background: 颜色 图片路径 重复 滚动 位置/大小;
```

示例：

```css
.box1 {
  width: 500px;
  height: 500px;
  border: 1px solid #000;
  background-image: url(imgs/images.jpeg);
  background-repeat: no-repeat;
  background-attachment: fixed;
  background-position: center;
  background-size: 100%;
}

.box2 {
  width: 500px;
  height: 500px;
  border: 1px solid #000;
  background: url(imgs/images.jpeg) no-repeat fixed center/100%;
}
```
