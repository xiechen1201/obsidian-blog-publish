## 🔢 表格
设置`<caption>`标题的位置，语法：

```latex
caption-side: top/bottom;
```

设置表格边框合并的样式，语法：

```latex
border-collapse: separate/collapse;
```

设置表格单元格的布局，[详见](https://developer.mozilla.org/zh-CN/docs/Web/CSS/table-layout)，语法：

```latex
table-layout: auto/fixed;
```

示例：

```css
table {
  width: 300px;
  height: 300px;
  border: 1px solid #000;
  caption-side: top;
  border-collapse: separate;
}
```

## 🔢 光标
语法：

```latex
cursor: value;
```

属性值：

- `value`可选：
    - `pointer`手指；
    - `not-allowed`禁用；
    - `help`问号；
    - `resize`缩放；
    - ...

示例：

```css
.div:hover{
  cursor: pointer;
}
```

## 🔢 轮廓
设置元素轮廓的颜色，语法：

```latex
outline-color: color;
```

设置元素轮廓的样式，语法：

```latex
outline-style: 同 border-style 属性;
```

设置元素伦敦的宽度，语法：

```latex
outline-width: 具体数值;
```

`outline`属性是以上三个属性的复合属性，示例：

```css
p {
  outline: #00FF00 dotted thick;
}
```

BFC（Block Formatting Context，块级格式化上下文）是 CSS 中的一个概念，用于决定块盒子布局的规则和行为。它的作用主要在于影响元素的浮动定位、清除浮动、外边距折叠等布局问题。
