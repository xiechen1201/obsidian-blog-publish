面试中最常考的一道题就是“在浏览器地址栏中输入一个 URL 并按下回车键后，发生了什么？”，本文将以这个过程为例，逐步讲解网络中的知识。

![](/img/user/%F0%9F%94%B5%20%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/5%20%E6%B5%8F%E8%A7%88%E5%99%A8%E4%B8%8E%E7%BD%91%E7%BB%9C/%E7%BD%91%E7%BB%9C/_assets/1740019789826-2ead090c-9eb4-48e3-8313-41cff38f047c.png)

1. 例如用户输入的是 www.baidu.com 这个网址；
2. 首先浏览器会补全这个域名的协议和端口号；
    1. HTTP 协议是 80，HTTPS 443；
3. 浏览器根据 URL 地址在本地查找是否具有缓存信息，如果判断缓存可以使用，则直接使用缓存信息；
4. 向 DNS 服务器发起域名解析的请求，并得到一个 IP 地址；
5. 浏览器和服务器建立 TCP 链接；
6. 如果是 HTTPS 协议还会建立 SSL 链接，建立加密通道；
7. 浏览器在本地中查看哪些 Cookie 符合条件，并将匹配的 Cookie 携带在请求头中；
8. 设置其他请求头、协议版本，并发出 GET 请求；
9. 服务器处理请求，并返回 HTTP 报文；
10. 浏览器根据 Content-type 字段对数据进行相关的处理；
11. 浏览器根据响应头的内容决定是否要设置数据缓存和设置 Cookie；
12. 浏览器从上到下开始解析 HTML，如果遇到外部资源，则进一步请求资源；
13. 渲染页面，过程中触发对应的 JS 加载事件；
14. 浏览器根据 HTTP 的版本和 Connection 字段，判断是否要关闭 TCP 链接；
