在 npm 的注册表中有非常多的包，可以让其他开发者通过 npm CLI 进行下载使用。

那么什么是包呢？

包是一个由 package.json 文件描述的目录，因此每个 npm 包必须都含有一个 package.json 的文件。

一个 npm 包可以是（以下都必须含有 package.json 文件）：

- 压缩包；
- 可以解析为压缩包的 URL 地址；
- 一个 Git 仓库的地址，下载后得到一个含有 package.json 文件的目录；

npm 的包又分为两大类：

1、有范围的包。

当注册 npm 账户后，自动获得一个以用户名为前缀的范围。这个范围可以给 npm 包作为命名空间，防止和其他用户的同名包产生冲突。

例如用户名是 xiechen，那么获得的范围是 xiechen@。以后自己编写一个新的 npm 包的时候，就可以使用 xiechen@ 作为包的范围。

例如 xiechen@package 和 zhangsan@package 是两个不同的包。

默认情况下，有范围的包总是私有的（也可以设置成公开）。

2、无范围的包。

总是公开的。

在一个 npm 包内会有非常多的文件，而每一个文件都可以被视为一个模块。

一个包是可以被加载的，通常是通过 package.json 文件的`main`属性来指定包的入口模块。
