在 Vue 中插槽「使用层面」的本质就是：父组件向子组件传递模版的内容。

- 默认插槽：具有默认的一些内容；
- 具名插槽：通过`name`属性指定插槽的名称；
- 作用域插槽：数据来自于子组件，将通过插槽的形式传递给父组件进行使用；

## 🔢 父组件传递内容

下面是 App.vue 文件使用子组件并在插槽中传递内容：

```vue
<template>
  <CardComponent>
    <!-- 具名+作用域插槽 -->
    <template v-slot:header="slotProps">
      <div>卡片标题，{{ slotProps.title }}</div>
    </template>

    <!-- 默认插槽 -->
    <div class="card-content">
      <img src="./assets/logo.svg" alt="Beautiful landscape" class="card-image" />
      <p>探索未知的自然风光，记录下每一个令人惊叹的瞬间。加入我们的旅程，一起见证世界的壮丽。</p>
    </div>
    <div>
      <button>了解更多</button>
    </div>
  </CardComponent>
</template>
```

```vue
<template>
  <div class="card">
    <slot name="header"></slot>
    <slot name="body"></slot>
    <slot name="footer"></slot>
  </div>
</template>
```

对于父组件来说，传递给子组件 CardComponent.vue 的就是一个对象，对象的属性的值就是一个函数，函数的返回值就是插槽的内容。

```js
{
  default: function(){ ... },
  xxx: function(){ ... },
  xxx: function(){ ... },
}
```

结合上面的案例，父组件传递过去的其实就是下面的对象：

```js
{
  default: function(){
    // 注意：返回值是对应结构的虚拟 DOM，这里只是简化版
    return (
    	 <div class="card-content">
        <img src="./assets/landscape.jpeg" alt="Beautiful landscape" class="card-image" />
        <p>探索未知的自然风光，记录下每一个令人惊叹的瞬间。加入我们的旅程，一起见证世界的壮丽。</p>
      </div>
    )
  },
  header: function(){
    return (
    	<div>摄影作品</div>
    )
  }
}
```

所以，父组件向子组件传递过去的东西本质上是函数，通过调用这些函数，能够得到对应结构的虚拟 DOM。

## 🔢 子组件设置插槽

子组件设置插槽的本质其实就是对父组件传递过来的对象方法进行调用，然后得到相应的虚拟 DOM：

```js
// 该对象是父组件传递过来的对象
const slots = {
  default: function(){ ... },
  xxx: function(){ ... },
  xxx: function(){ ... },
};

slots.default(); // 得到要渲染的虚拟 DOM
slots.header(); // 得到要渲染的虚拟 DOM
slots.xxx(); // 得到要渲染的虚拟 DOM
```

最后，只需要完善一下整个 CardComponent 的返回的虚拟 DOM 结构即可：

```js
import { defineComponent, h } from 'vue'
import styles from './CardComponent.module.css'

export default defineComponent({
  name: 'CardComponent',
  setup(_, { slots }) {
    // 调用方法，得到虚拟 DOM
    // 给父组件传递数据
    let headerSlotVNode = slots.header({ title: '子组件传递的标题' })
    let defaultSlotVNode = slots.default()

    return () => {
      return h('div', { class: styles.card }, [
        h('div', { class: styles['card-header'] }, headerSlotVNode),
        h('div', { class: styles['card-body'] }, defaultSlotVNode)
      ])
    }
  }
})
```

到这里，页面就可以正常显示这个组件了～

## 🔢 插槽默认值

因为插槽是可以设置默认值的：

```vue
<template>
  <div class="card">
    <slot name="header">默认标题</slot>
    <slot></slot>
  </div>
</template>
```

对应的如果调用的时候没有使用`name`为`header`的插槽，则会显示默认值：

```vue
<template>
  <div>
    <CardComponent>
      <!--  -->
      <!-- <template v-slot:header="slotProps">
        <div>卡片标题，{{ slotProps.title }}</div>
      </template> -->
      <div class="card-content">
        ...
      </div>
      <div>
        ...
      </div>
    </CardComponent>
  </div>
</template>
```

![](/img/user/%F0%9F%94%B5%20%E4%BB%A3%E7%A0%81%E5%BC%80%E5%8F%91/Web%20%E5%89%8D%E7%AB%AF/4%20%E5%89%8D%E7%AB%AF%E6%A1%86%E6%9E%B6/Vue3/_assets/1727602275575-b134841f-d26f-4e15-a5e2-03340153310e.png)

对应 CardComponent 的 JS 文件，我们可以手动的处理一下并复制一个默认值：

```js
export default defineComponent({
  name: 'CardComponent',
  setup(_, { slots }) {

    let headerSlotVNode = null
    let defaultSlotVNode = slots.default()

    if (slots.header) {
      headerSlotVNode = slots.header({ title: '子组件传递的标题' })
    } else {
      headerSlotVNode = h('div', null, '默认标题')
    }

    return () => {
      return h('div', { class: styles.card }, [
        h('div', { class: styles['card-header'] }, headerSlotVNode),
        h('div', { class: styles['card-body'] }, defaultSlotVNode)
      ])
    }
  }
})
```

我们只需要判断一下`slots`对象中是否存在`header`方法，如果不存在则调用`h()`创建一个默认的标题即可！
